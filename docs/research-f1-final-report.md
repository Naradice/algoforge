## 2. 設計(要点)
USDJPY M1(2016-08-31〜2022-08-31)、60 本ブロック、原点はブロック最終行、h ∈ {1, 4, 12, 24}、M=1000 標本、fair CRPS。
推定 2016-08-31〜2020-08-31、検証 2020-09-01〜2021-08-31(モデル選択のみ)、final 2021-09-01〜2022-08-31(部分的に既知のホールドアウト、単回使用)。
統計モデルは B0〜B8、B4s を月次の拡張窓で再推定。DDM の写像のみ推定期間で凍結し、バケットごとに 1000 本・独立 3 seed のパスを使った。
モデル選択はホライズンごとの検証 CRPS 最小(0.5% 以内は単純な方を優先)。結果は h=1, 4, 12 が B7N、h=24 が B4。
判定は週ブロック bootstrap による同時 95% 帯(max-t、臨界値 2.419)に ±2% を適用した。

被覆率(DDM、50/80/90/95%): h=1: 0.401/0.706/0.850/0.927、h=4: 0.379/0.668/0.808/0.889、h=12: 0.406/0.733/0.854/0.917、h=24: 0.422/0.800/0.890/0.948。
h=1〜12 では名目値を下回り、特に h=4 は狭すぎる(過度に自信のある)分布。h=24 は 80/90/95% 区間が名目値に近い(0.800/0.890/0.948)が、50% 区間は 0.422 で名目値を大きく下回り、分布全体の較正が良好とは言えない。これらの被覆率は事後的な診断で、事前登録した主比較の判定(§1)とは別に扱う。過小分散・中心のずれ・裾の形状・局面依存のどれが原因かは、この結果だけでは区別できない。PIT の KS 距離は DDM が 0.078〜0.115 で、B0 の h=1, 4(0.046, 0.060)より大きい。

## 5. 解釈上の制限(必ず併記する)
1. final 期間は部分的に既知のホールドアウトで、判定はこの評価期間限定の事前規則による分類。未知期間への確証的主張ではない。
2. DDM の予測は初期状態から始めたパスの分布で、定常化した状態からの分布とは限らない(limit 8)。burn-in 版は追加の感度分析にとどめ、主アンサンブルは変えない。
3. スコア配列(`scores_*.npz`)の独立再計算は行っていない。ゲート通過は再計算の代わりではない。
4. DDM 写像は凍結、統計モデルは月次再推定という非対称がある。
5. M1 ベースの GARCH(B3m、B4m)は未実施。
6. 3 seed の DDM は seed 間ばらつきを示すが、写像の推定サンプル(バケットあたり最大 300 窓)に由来する不確かさは含まない。
