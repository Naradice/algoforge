## 3. 仮説

**H:** トレンド参照を「直近 η 秒の約定」にした DDMv3 では、持続性のある自己変調時計を与えると、20 約定足の絶対収益の自己相関(ラグ 2〜10 の平均)が、**同じ間隔を順序だけ並べ替えた時計**より 0.03 を超えて大きい。

- 約定数基準の足で測るので、時刻の割り当てだけでは差は出ない。差が出るのは、時計が時間窓を通して価格生成に入る場合である。
- 式からの予想(未検証): 間隔が長い時間帯は窓内の約定が少なく、平均が粗くなってトレンド項が大きくぶれる。その場合、**値動きの大きさは活動の少なさと結びつき、実市場の一般的な向きと逆になる可能性がある**。§6 の副次指標で向きを報告する。

## 4. モデルの仕様(実行前に固定)

本番のシミュレータは変更しない。研究コード内でサブクラスを作る。

| 項目 | 値 |
|---|---|
| 価格生成 | `DDMv3`、`num_agent` = 300、`max/min_volatility` = 0.02 / 0.01、`dealer_sensitive` ∈ [−3.5, −1.5]、`spread` = 1、ショックなし |
| 時計 | M2-S2: `log T_k = log F_k + (1−λ)·mean_n(log T) + λ·log m0`。`F_k` は T1 と同じ作り方のプール(Model-1 の間隔、seed 9001〜9003)。平均 3.0 秒/約定になる m0 を、T1 と同じ手順(seed 8001〜8020)で時計ごとに較正 |
| 時計 K-short | n = 16、λ = 0.1(T1 で検査済み) |
| 時計 K-long | n = 50、λ = 0.03(T0-E で定常を確認。T1 の検査は未実施で、S0 で行う) |
| 結合 | 時計は価格と独立に生成し、約定 k に時刻 `t_k = t_{k−1} + T_k` を与える。**一方向(時計 → 価格)** |
| 時間窓 | 約定 k の後、`t_k − t_j < η` を満たす約定 j の価格差の**等加重平均**(k 自身は必ず含む)。次の約定まで一定。η = **15 秒**(平均間隔 3 秒 × 現行の 5 約定) |
| 窓の開始直後 | 時刻 `t_k` が η に達するまでトレンド項は 0(間隔が一定なら、現行の「価格差が `wma` 個そろうまで 0」と一致する) |
| 長さ | 1 run = burn 5,000 約定 + 100,000 約定。足は 20 約定 = 1 本(5,000 本) |

時計の記憶の長さは、線形化した近似で K-short が約 80 約定(約 4 本)、K-long が約 800 約定(約 40 本)である。**この機構が成功しても、実市場のような数百本以上の持続は期待できない。**

## 6. 指標と判定

**主指標 P:** run ごとに、20 約定足の絶対対数収益の自己相関(その run の平均を引く)を求め、ラグ 2〜10 を平均する。ラグ 1 は約定の仕組みによる相関が混じるため除く。

**主比較:** D_S = P(S-ord) − P(S-shuf)、D_L = P(L-ord) − P(L-shuf)。seed で対にした差の平均。seed を単位とするブートストラップ 10,000 回(乱数 seed 20261128)。2 比較なので、各 **97.5% 区間**。

| 判定(時計ごと) | 条件 |
|---|---|
| 伝播を支持 | 区間の下端 > +0.03 |
| 実質的な伝播なし | 区間全体が (−0.03, +0.03) の内側 |
| 逆向き | 区間の上端 < −0.03 |
| 判定保留 | 上のどれでもない |
| 評価不能 | S0 の検査に不合格、または有効な対が 20 のうち 18 未満 |

全体の結論は時計ごとの判定を並べて書き、まとめて 1 つの判定にしない。δ = 0.03 は、USDJPY のラグ 5 の値 0.29(別の定義)の約 1 割という目安で、理論的な根拠はない。

**副次(判定しない。結果を見て主指標に昇格させない)**

1. 絶対収益の自己相関のラグ 1・5・20・60・240(run 内の定義と、#32 の定義の両方)
2. 将来変動の HAR R²(run 内の平均を引く。seed 201〜214 で推定、215〜220 で評価)
3. 足の所要時間と値動きの大きさの順位相関(§3 の予想の向き)
4. 60 秒の固定時間の足(空の足を含む)の絶対収益の自己相関
5. 時間窓内の約定数の分布、収益のラグ 1 自己相関、尖度

どのパラメータも実市場の統計量に合わせていないので、合わせ込みに使う統計量はない。**S0・S1 では実市場データを読まない。**#32 の USDJPY の値は参考として引用するだけで、定義が違うため直接比べない。示せる不確かさは seed 間のものだけで、実市場の期間間の変動は扱わない。

| 6 | 陽性対照: B0 の 1 約定ごとの対数収益に `exp(h_k)` を掛ける(h は AR(1)、時定数 200 約定、定常 SD 0.5、seed = 70000 + 価格 seed) | P(陽性) − P(B0) の 95% 区間の下端 > 0.05 | 全体を停止 |

検査 5・6 は B0 の本実験の run(seed 201〜220)を使う。B0 は主比較に入らない。陽性対照は**測り方の検査**で、持続は作り方から当然であり、機構の成功に数えない。

**失敗の定義:** 例外や約定の停止、非有限の価格、価格が [50, 200] の外(初期値 100)。1 run の実行時間の上限は 10 分。失敗した seed は補充しない。

## 9. 対象外と、言えないこと

**対象外(それぞれ別の計画と承認):** η = 150 秒(原論文の値)、時計の他の設定、原論文の `d` の範囲と追随者/逆張りの混在、価格 → 時計の向きの結合、戦略の切り替え、エージェントごとの時間幅、実市場との比較、転移研究や異常検知への利用。

**言えないこと**

- 支持されても、この変更モデルで時計の持続が価格の持続に伝わる、という範囲に限る。**実市場の仕組みの再現ではない。**
- 支持されなくても、原論文の Model-4 の否定にはならない(時計、`d`、窓、結合の向き、エージェント数が違う)。
- 時計の持続は M2-S2 の式で与えたもので、ディーラーの行動から生じた持続ではない。調べるのは伝わり方である。
- 長いラグの持続(長期記憶)は、この設計では判定しない。
