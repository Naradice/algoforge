## 実装不具合かどうかの切り分け(計画 §6 の規則 (a)/(b))
コードも基準も変えずに、ケース 1 の予測標本だけを変えた診断(`p2_synth_diag.py`、各 1,000 試行、棄却率):

| 変種 | FA90 | FB | FC | FE |

| V0 計画どおり(M=1000 の乱数アンサンブル、バケットごとに約 150 原点が共有) | 0.088 | 0.067 | 0.081 | 0.081 |
| V1 標本誤差なし(予測分位点の格子、M=1000) | 0.054 | 0.049 | 0.064 | 0.072 |
| V2 M=20,000 の乱数アンサンブル | 0.055 | 0.044 | 0.061 | 0.071 |

解釈: 過剰な棄却は、有限のアンサンブル(M=1000)の標本誤差が、同じバケットの原点間で共有され、週ブロック bootstrap では捕捉されないことによる。実装の誤りではなく、検定の設計(と実データの構造)の性質と判断する。仕様どおりの実装で、基準に届かなかった。V1/V2 でも FC・FE は 5% をやや上回る(B=1000 の bootstrap と推定の有限性による)。

## 整合的な証拠の整理(因果は断定しない。計画の判定規則 1〜7 に対応)
- 規則 1: 条件 A は再現された(先へ進んでよい前提を満たした)。
- 規則 2(B): 経験分布を条件とした帰無仮説の下では、棄却率は 4 検定すべて事前基準内に収まった(FC の上限は 0.081、FE は 0.087 までが信頼区間)。A との差は、FA90 では信頼区間が 0 を含まないが、FB・FC・FE では 0 を含む。理想分布と経験分布の違いが過剰棄却に寄与するという仮説と整合するが、寄与の大きさや唯一の原因であることは確定しない。
- 規則 3(C): 共有なし(原点ごとに独立のアンサンブル)で、4 検定すべて基準内。A との差は 4 検定とも信頼区間が 0 を含まない(−0.016〜−0.023)。共有構造の寄与と整合する。ただし、独立に生成すると標本誤差の相関構造も変わる。
- 規則 4(D): M を増やしても(4000、20000)、4 検定すべて基準内で、A との差は FA90・FB・FC で信頼区間が 0 を含まない。有限 M の影響と整合する。M 増加に伴い、分位点の近似やタイも変わる。なお、M=4000 と 20000 の間では棄却率はほぼ同じで、M の増加による単調な低下は見られない。
- 規則 5(E): B_test=10000 でも基準外(FA90 0.084、FC 0.085)。A との差は信頼区間が 0 を含み、B_test の増加では解消しない。週ブロック bootstrap 自体が原因とは確定しないが、調査対象。
- 規則 6: 条件 B、C、D のいずれでも棄却率が低下しており、複数の要因(帰無の違い、共有・有限 M を含むアンサンブルの標本誤差)が寄与し得る。寄与の割り当ては断定しない。
- 規則 7: 該当しない(B、C、D とも基準内)。ただし、基準内の意味は設定した基準(0.08 以下)内であり、名目 5% の保証ではない。FC、FE は、B・C・D のいずれでも 0.06〜0.07 で、名目 5% をやや上回る。
- 条件 A の差(0.088 と 0.08 の差は約 8 試行)は、境界付近の結果で、信頼区間(約 ±0.017)と同程度。

## 注意(計画での指示)
- FE の有限標本効果: `mean(E2) − mean(E1)²` は有限標本でわずかな下方バイアスを持ち得る。全列挙では母数(帰無値)のみを計算し、標本推定量の期待値とは区別している。
- 対応比較の差の信頼区間が 0 を含まなくても、特定の原因を確定したとは扱わない(アンサンブルの生成方法が条件間で複数変わる)。
