## 1. 問いと、今できる理由

問いは A1 と同じ。予測分布から見て直前の 1 時間がどれだけ外れていたかを、価格だけの単純な基準に足すと、次の 1 時間の急変動の始まりを、同じ警報率でより多く検出できるか。

- A1 の評価期間(2026-12〜2030-05)はまだ存在せず、結果は 2030-06 以降になる。
- 履歴として取得した 2022-09〜2026-10 は、A1 の設定を凍結した後に取得した。この研究ではまだ価格を読んでおらず、スコアも件数も計算していない(取得の照合は日付と時刻の列だけ。`research-anomaly-a1-collection-log.md`)。
- 設定はすべて 2016-08〜2021-08 で決まっているので、この期間は**設定にとって標本外**である。

### 前向き評価より弱い点

| 点 | 内容 |
|---|---|
| 期間は使用済み | 他の研究と運用が、この期間の USDJPY を日足・5 分足・1 分足で使っている(`research-anomaly-a1-data-acquisition.md` §2) |
| 出来事を知っている | 研究者とアシスタントは、期間内の大きな相場の出来事を一般の知識として知りうる |
| 事後の計画 | 評価できる期間があると分かった後に立てた計画である |

軽くする事情: 閾値・スコア・基準・係数・判定規則は A1 で固定済みで、この計画で新しく決めるのは期間、年ごとの内訳、結果の扱いだけである。

## 2. 設定

**A1 v0.3 の §2(ラベル、イベント、検出、除外)、§4(スコア)、§5(組み合わせ・指標・判定)をそのまま使う。** 当てはめ直しも選び直しもしない。凍結値は `results/frozen.json`(基準 `rv24_tod`、係数、参照値)。

| 項目 | 内容 |
|---|---|
| 評価期間 | **2022-09-01〜2026-10-31**。台帳に記録済みの完全な 50 か月で決めた。件数を見て延長・短縮しない |
| 2026-11 | 使わない(取得が途中) |
| 系列 | 主系列(SHA-256 `c25eb572…a828`)の後ろに、台帳の 50 本から作る 1 分足(各分の最後の ASK)を足す |
| 予測モデルの状態 | 各月の開始より前のすべてのデータ(A1 と同じ) |
| 乱数 | A1 と同じ(予測の標本、PIT、ブートストラップ seed 20261301) |
| 主比較 | Δ = 検出率(B+S)− 検出率(B)、警報率 0.05、週ブロックの 95% 区間 |
| 判定 | 支持: Δ の下限 > 0.05 かつ Δ−Δc の下限 > 0。±0.05 内なら上乗せなし。他は保留。イベント 100 未満は保留 |
| 感度(判定しない) | 警報率 0.02・0.10、日曜の行を除かない場合 |
| 年ごとの内訳(判定しない) | 2022-09〜2023-08、2023-09〜2024-08、2024-09〜2025-08、2025-09〜2026-10。各区間の原点だけで警報を選び直し、イベント数、検出率、Δ、Δc の点推定を出す |

A1 §8 の副次分析は含めない。

## 3. 結果の扱い(実行の前に固定)

- 判定の呼び名は「後ろ向きの支持」「後ろ向きの上乗せなし」「後ろ向きの保留」。
- **どの結果でも、A1 の設定・閾値・δ_A・N_min・期間は変えない。**
- この結果だけで仮説 #896 と Goal #887 の状態は変えない。
- 年ごとの内訳や感度が主比較と違っても、判定は主比較だけで決める。
- A1 は原則として続ける。結果を理由に利用者が中止を決める場合は、中止の理由と、この結果を見た後の判断であることを記録する。

| 結果 | 言えること | 言えないこと |
|---|---|---|
| 支持 | この 50 か月では、定めた上乗せがあった | 前向きの確認、他の通貨ペア・時間幅、市場異常一般の検知 |
| 上乗せなし | この 50 か月では、上乗せは ±0.05 内だった | 今後も上乗せがないこと |
| 保留 | 区別できなかった | 上乗せがある、またはない |

- 結果を見た後に、別の閾値・スコア・期間を試す場合は、この計画の外の事後の探索とし、別の承認を得る。

## 4. 精度の見込み(仮定による計算。件数は数えていない)

A1 §6 と同じ式と発生率の想定。

| 発生率の想定 | 50 か月のイベント | 半幅(d = 0.05・0.10・0.20) | 支持に必要な Δ の点推定 |
|---|---|---|---|
| 年 67 | 約 279 | ±0.026・±0.037・±0.052 | 約 0.08〜0.10 |
| 年 30 | 約 125 | ±0.039・±0.055・±0.078 | 約 0.09〜0.13 |

- 固定の絶対閾値なので、発生率は想定の範囲を超えて上下しうる。大幅に多い場合、「急変動」は 2016〜2020 年より頻繁な出来事になり、解釈が変わる。陽性の原点の割合を必ず併記する。
- 効果が小さければ、件数が足りても保留になる。
