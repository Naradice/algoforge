## 1. 目的と位置づけ

目的は、`volclust_50` を改善する仕組みを探すことではなく、**観測された差が再現性のあるものかを検証する**こと。順序を固定する。

1. 差の再現性・頑健性(推定の仕方、データ、別の説明)。
2. 到達可能な窓の偏りによる影響の切り分け。
3. **差が確認された場合に限り**、差を生む DDM 内部の機構の分析(コードと保存済みの系列)。
4. 追加機構・パラメータ探索は、改訂計画の承認後に別途判断する。

統計量が一致・不一致のどちらでも、DDM の市場生成機構が実市場を再現した、またはできないとは結論しない。

## 3. 前回の所見の弱点(本計画で直す)

1. **非対称な比較。** 事後分析の「窓の 62〜65% は `volclust_50` の範囲だけで届かない」は、**1 つの実市場の窓**を、**DDM の点平均**(最大 50 窓の平均、前回は SA の 25 窓)の範囲と比べている。点平均の範囲は、個々の窓の範囲より狭い。保存済みの seed 間 SE からの粗い換算では、DDM の 1 窓のばらつきは約 0.029(A0: 5 seed 平均の SE の中央値 0.013 × √5)で、caliper 0.022 より大きい。**「DDM がその窓の値を生成できない」とは読めない。**マッチングの判定(窓 対 点平均)としての値であり、窓単位の到達可能性は推定ノイズの影響が大きい。
2. **先行結果の未引用。** 前回の計画 v0.6 は Phase 8b の結果ファイルを参考に挙げたが、報告と所見 #1122 は引用していない。
3. DDM の上限 0.015 は、136 個のノイズのある平均の最大値で、上に偏っている可能性がある。

報告と #1122 への注記は、**本計画の承認事項**(§10)とし、まだ変更していない。

## 5. 主な量と判定規則(事前に固定)

- **推定量(変えない)**: 既存の `volclust_50`(対数収益の絶対値の ACF、ラグ 50)。窓は 1,000 本、重複なし、1 取引週内(前回の B の規則)。DDM は TPC=20。
- **実市場の量** `μ_real`: 窓の値の平均(感度: 中央値)。
- **DDM の量** `μ_DDM*`: 一方の seed 組(選択側)の点平均で上位 5 点を選び、**他方の seed 組(評価側)の点平均の最大値**を使う。選んだ 5 点の中の最大を取るため、その 5 点に対しては上に偏り、「差あり」には不利な向き。ただし、真の最大の点が上位 5 点に入らない可能性は残る。対象は全 10 seed が成功した 136 点。選択側と評価側は **SA→SB と SB→SA の両方向**を計算する。
- **差**: `Δ = μ_real − μ_DDM*`。
- **不確実性(合算しない 2 層)**: 実市場層 = 取引週のブロック再標本化。DDM 層 = run 単位の再標本化(再標本ごとに上位点を選び直す)と、パラメトリック t の併記。B = 2,000。90% 区間。
- **実質的な幅 δ = 0.022**: 前回、DDM と比較する前に凍結した caliper(実市場の窓間 SD の 0.5 倍)。感度: 0.010、0.030。**生の差がおよそ 0.035 になりそうなことは既に見えているため、生の差の合格は独立な確認にならない。**情報があるのは、未使用データと、季節性を除いた差。
- **3 区分の判定**(両層、両方向のすべてで満たすこと):
  - **差あり**: 90% 区間の下限 > δ
  - **差は小さい**: 90% 区間の上限 < δ
  - **判定保留**: それ以外(方向や層で食い違う場合を含む)
- **窓単位の補助量**(§3 の非対称を直す): `μ_DDM*` の点の**個々の DDM 窓**の分布と、実市場の個々の窓の分布を同じ推定量で比べる。報告するのは、実市場の窓が DDM の窓の 95% 点を超える割合(差がなければ約 5%)と、`P(実市場の窓 > DDM の窓)`。上位 5 点をまとめた分布も併記。記述であり、判定には使わない。

### V0 — 判定規則の動作確認と前提の点検

前回、SA/SB の基準が seed のばらつきだけで約半分不合格になる設計だった。**規則を使う前に、動作特性を確認する。**

1. 擬似データ 1,000 組(内側の再標本化 B = 500)で、真の差が δ の境界にあるときに、§5 の規則(両層・両方向)が「差あり」と出る割合を調べる。**10% 以下**であること。擬似データは、DDM 側は保存済みの SA の点平均を真値とし、run 間のばらつきを保存済みの run 値から与える。実市場側は R-A の窓の値を、平均が境界になるようにずらして週ブロックで再標本化する。真の差が δ + 0.01 のときの検出割合も報告する(低くても規則は変えない)。
2. `a1_stats.pkl` の SHA-256 と、価格系列の欠損がないことの確認。
3. 実市場データの出所の特定: 主データ(`usdjpy_1min_volatility.parquet`)と HistData の USDJPY を、同じ期間で照合する。同じ窓の `volclust_50` の差の平均の絶対値が δ/2 を超える場合は、「出所の影響がある」と報告し、V1 の独立データの判定を止めて確認する。

中止: 1 が基準を満たさない場合は、規則を直さずに停止して報告する。

### V2 — 別の説明(実市場側の構造)

**主の調整(1 つだけ)= 日中季節性の除去。** 時刻はニューヨーク時間(米国の夏時間を反映)、15 分刻み。各刻みの規模(絶対収益の平均)を、**同じ期間・同じ出所の、その窓の週を除く週**から推定し、収益を割ってから `volclust_50` を計算する。調整後の差 `Δ_adj` に §5 の 3 区分(V1 の追加条件を含む)を適用する。**主の判定は独立データ(主)で行う**。R-A と検証期間の調整後の値は記述。

- **対照(注入)**: 評価側の DDM の窓に、実市場の窓の時刻に対応する季節性の規模を掛け、季節性だけでどれだけ `volclust_50` が生じるかを測る。
- 季節性で説明される割合 `1 − Δ_adj / Δ` と区間を報告する(記述)。
- 感度(記述): 固定 EST の時刻、曜日 × 30 分、窓内の絶対収益を 99% 点で打ち切り、ゼロ収益の割合が 0.10 以下の窓のみ、日ごとの水準で割る場合(クラスタリングの一部も除くため、分解の参考)。
- **V2-T(任意・別の確認事項)**: 時計の違い。MT5 のティックデータから、一定ティック数の足を作り、同じ量を計算する。実市場の活動量の変動が差の原因かを調べる。読み込みの実装と費用が別に要る。

### V3 — 到達可能な窓の偏り(記述・副次)

- 前回の主分割は `volclust_50` をマッチングに使ったため、**到達可能な窓の `volclust_50` が DDM に近いのは選び方の帰結**で、DDM の再現の証拠にならない。
- V3a(記述): 到達可能な窓と不能な窓を、`volclust_50`(生・調整後)、時刻、ATR 群、年、ジャンプの数、ゼロ収益の割合で比較する。
- V3b(条件付きの差): **評価する量をマッチングから外す**規則で、`M' = (acf_1, 尖度)`、`E = volclust_50`(生・調整後)。caliper、ノイズ床 `τ`・`f_0` は、前回と同じ手順で R-A・R-B から作り、**DDM との比較の前にコミットする**。判定は前回の `g = f − f_0`(閾値 0.05)を両層・両方向で適用する。
  - 到達可能な割合は、前回の「`volclust_50` の caliper を外す」で **20.2% と既に見えている**。M' はこの値を見て選んだのではなく、E を M から除く規則で決まるが、独立ではないことを明記する。
  - マッチング資格(主)と、資格を外した場合(感度)の両方を出す。SA→SB と SB→SA で判定が違えば、条件付きの結果は結論に使わない。
  - 尖度の caliper が緩いため、分位点比に置き換えた感度分析を併記する。
- V3 は、V4 に進むかの判定には使わない。

### V4 — 機構の分析(V1・V2 が「差あり」の場合のみ)

- **コードの読解**: 1 run の間に固定される量(各エージェントの `tend`、`dealer_sensitive`、WMA の重み、帰還なしのスプレッド)と、時間変化する量(注文価格、ポジション、価格履歴)を一覧にする。仮説の出発点: **ゆっくり変わる状態がないため、絶対収益の相関が短いラグで消える**。これはコード読解にもとづく仮説で、確認済みではない。
- **保存済みの系列**: 約定単位の価格から、絶対収益の ACF のラグ形状と、delta・wma との関係を記述する。
- 成果物: 機構の候補ごとの、反証できる予測と、それを調べる最小の実験の案。**実験は実行しない。**内部状態は保存していないため、観察には新しい run が必要で、別の承認とする。

## 11. 本計画で言えないこと

- DDM が原理的にクラスタリングを生成できない、ということ(探索したのは 300 体、delta × wma、ショックなしの格子。Phase 8b の変種も限定的)。
- 差の原因(V4 は整合的な仮説の列挙まで)。
- 時計の対応(TPC 20 と 1 分足は慣習)。V2-T をしない場合、時計の違いの寄与は未解明のまま残る。
