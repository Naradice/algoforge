# DDM のボラティリティの持続: DP1〜DP3 のまとめ

- 作成: 2026-11-28。利用者の指示(「まとめて区切る」)で、**この研究はここで区切る。**
- 対象: DP1(#1150/#1151)、DP2(#1152/#1153)、DP3(#1154/#1155)。いずれも Study Manager の Goal #874 の下。
- このまとめは各報告の値を並べたもので、新しい計算や再解析はしていない。

## 1. 出発点と、到達したところ

**出発点:** 試した DDM の変種には、値動きの大きさ(ボラティリティ)の持続がなかった(#32)。持続を生む機構を入れられるかを調べた。

**到達したところ:** 持続する時計(自己変調の式)を与えると、DDM の足に持続が現れる条件はあった。ただし小さく、短い範囲にとどまり、**持続の源は時計の式であって、ディーラーの行動から生まれたものではない。実市場のような持続を持つモデルはできていない。**

## 2. 3 つの実験

指標はどれも、足の絶対収益の run 内自己相関(ラグ 2〜10 の平均)について、「持続する時計」と「同じ間隔を並べ替えた時計」の差である。DP1 の主指標は 20 約定の足、DP2・DP3 は 60 秒の足を使う。seed は実験ごとに別である。

| 実験 | 問い | 主な結果 | 事前の規則での判定 |
|---|---|---|---|
| **DP1** | トレンドを見る範囲を時間にすると、時計の持続が価格に伝わるか | 20 約定足: 記憶の長い時計(約 40 本)+0.056 [+0.048, +0.065]、短い時計(約 4 本)+0.009 [+0.004, +0.014] | 長い時計は「伝播を支持」、短い時計は「実質的な伝播なし」 |
| **DP2** | 60 秒足では、どの段階で持続が失われるか | 約定間の依存がない基準 0.165、結合なし 0.043、結合あり 0.006。失われた割合は、依存 0.74 [0.70, 0.77]、結合 0.22 [0.19, 0.26] | 依存は「主な原因」、結合は「判定保留」 |
| **DP3** | 打ち消しは逆張りのトレンド項によるか(結合なし) | 残る割合: 現行 0.29、項なし 0.65、逆張りと追随が半々 0.59。差 +0.36 [+0.30, +0.42]、+0.30 [+0.23, +0.36] | 「打ち消しが大きく減る」。仮説は「支持」 |

区間は DP1・DP2 の割合・DP3 の差が 97.5%。

## 3. 分かったこと

1. **約定数の足と固定時間の足で結果が違う。** DP1 の機構(時間窓と時計の結合)は 20 約定足に持続を生んだが、60 秒足ではほぼ出なかった(0.006。別の seed の DP2 でも 0.006)。
2. **60 秒足の持続は、結合なしの方が大きかった**(0.043 対 0.006)。ただし結合による損失の割合は判定保留である。
3. **結合なしの 60 秒足の持続は、時計が与える約定数の持続が値動きに現れたものである**(価格は時計に依存しない)。
4. **足の中の打ち消しが、持続を大きく減らす。** 逆張りの項はその大きな原因の 1 つで、項を取ると、残る割合は 0.29 から 0.65、持続は 0.045 から 0.105 になった(DP3)。
5. 項を取っても、割合で 0.35 の損失が残る。DP3 の仮説の文(「主な原因」)は判定の規則より強く、**「大きな原因の 1 つ」と読むのが妥当**である。

## 4. 言えないこと、残った問い

| 項目 | 状態 |
|---|---|
| 項を取っても残る打ち消しの原因(売買の成立の仕組みなど) | 特定していない |
| 項なし・半々と、時計との結合の組み合わせ | 調べていない |
| 60 秒より長い足 | 調べていない。項なし・半々でも価格の動く範囲は狭い |
| 長いラグの持続(長期記憶) | 作れていない。DP1 の長い時計でも、20 約定足のラグ 60 でほぼ 0 |
| 将来の変動の予測可能性(HAR R²) | DP1 の結合あり・20 約定足で 0.074(副次)。DP2・DP3 では測っていない |
| ディーラーの行動から生まれる持続(戦略の切り替えなど) | 調べていない |
| 実市場との比較 | していない。#32 の USDJPY の値は定義が違う |
| 最初に挙げた利用先(転移の問い、異常検知の検査台) | 再開できるモデルはできていない |

DDMv3 の設定(300 エージェント、ショックなし)と、M2-S2 の時計に限った結果である。原論文 Model-4 の再現ではなく、原論文の否定でもない。不確かさは seed 間のものだけである。

## 5. 進め方の記録

- 各実験は、版ごとに承認を得て、装置の検査と本実験を 1 回ずつ実行した。結果を見た後の実行し直しと、基準の変更はない。
- DP1 は、検査の定義の書き漏らし 2 点を実行前に確認して確定した。
- DP3 は、準備の検査で本物のシミュレータを実験外の seed で短く動かした(軽い逸脱)。
- DP2 と DP3 の仮説は、前の実験の結果を見た後に立てた。それぞれ新しい seed で調べた。
- DP1・DP2 は、判定と Study Manager の状態の対応を事前に定めていなかった(各報告に理由を記録した)。DP3 は仮説の結論の決め方を事前に定めていた。
- 付随して分かったこと: #32 のスクリプト(`ddm_variant_vol_screen.py`)は、`DDMv3` が使う Python の乱数に seed を与えておらず、同じ run を再現できない(コード読解。#32 の記録は変えていない)。
