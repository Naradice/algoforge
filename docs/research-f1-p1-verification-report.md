## 2. V9c の不一致の原因と影響
- 不一致: DDM3、final 期間、h=12、原点 j=32050 で、`pit_w` が独立再計算では 0.001、保存値では 0.0。
- 原因: 実現値 y の浮動小数点表現の違い。
  - 独立実装は `y = log(C1 / C0)`、本番は `y = log C1 − log C0` で、計算順序が異なる(V1 の許容 1e-14 内の差)。
  - この原点では、DDM アンサンブルの 1 標本が `log(C1/C0)` の表現と**ちょうど一致**し(値 −0.00047539815490077095)、本番の表現とは絶対差 5.9e-17 で一致しない。独立側だけがタイ(`pit_w = 1/M`)と判定した。
  - 診断(`p1_v9c_diag.py`)では、本番と同じ y の式(差の対数)で再計算すると、同原点の `pit_w` は 0.0 で保存値と一致し、全 132,477 原点スコアで不一致が 0 件になる。
- 診断の位置づけ: 事前登録した基準の置き換えではない。原因の切り分けのための追加の検査。
- 影響: 乱択 PIT(`pit = pit_lo + u × pit_w`)のタイの扱いのみ。CRPS、被覆率、分位損失、Δ、DM、同時帯、分類には影響しない。
- 参考: タイの総数は、独立の y で 425 件、本番の y で 424 件。2 つの定義で y が完全に同じ値になるのは 132,477 件中 486 件にとどまる(多くはタイを起こさない)。

## 3. 補足
- **V5**: 検証期間の最小 CRPS は、全ホライズンで B7T(h=1: 3.4535、h=4: 7.2166、h=12: 12.7788、h=24: 18.0371、×1e-4)。1.005 倍以内の候補と選択は次のとおり。
  - h=1、4、12: B7N、B7T の 2 つが入り、順序の上で先の B7N を選ぶ。
  - h=24: B4、B7N、B5、B6、B7T の 5 つが入り、順序の上で先の B4 を選ぶ。
  - 閾値との相対差が最小の候補は、h=24 の B5(最小値の +0.4834%、閾値との差 0.0165 パーセントポイント)。ただし B4 より順序が後なので、選択には影響しない。B4 自体は +0.4718% で、閾値まで 0.28 パーセントポイントの余裕がある。
  - 候補は 9 つで、B8 と B4s は候補外であることを確認した。
- **V6**: 検定統計量 t は h=1、4、12、24 でそれぞれ 13.14、8.96、4.38、0.69。本番の p 値は `2(1 − cdf(|t|))` で、倍精度の丸めにより |t| ≳ 8.292 で 0 になる。h=1 と h=4 の本番 p は 0.0 で、別実装の対数 p は log10 p = −38.70 と −18.47(Holm 調整後は −38.10 と −18.00)。丸めのない h=12、24 は rtol 1e-6 以内で一致した。報告書の表の「p=0」は、厳密な 0 ではなく、この丸めによる表記。
- **V7**: 週の総数は 53。V7a の臨界値は 2.4193450745698(本番 2.4193450745698、相対差 1.9e-14)。V7b(seed 1〜20、t = 3.5794)は c と se_h の 5 量すべてが予測区間内で、追加検証は発動しなかった。c の平均は 2.4182(区間 [2.3725, 2.4639])、本番値は 2.4193。

## 4. 範囲と限界(計画 §1、§8 の再掲)
- 対象は評価処理で、予測分布の生成(サンプラー、DDM の経路生成)の正しさは対象外。V3 と V9b ではサンプルの再生成に本番サンプラー(コミット db0926f)を使ったため、サンプラーに共通する不具合は検出できない。
- V9c は、保存済みアンサンブルから標本を取り出す処理を、本番が使った配列(バケット → 1000 標本)のまま使った。バケットの割り当て(ATR とバケット境界)は独立に実装して照合し、完全に一致した。
- V9a は集計の照合で、各値の算出処理の独立検証ではない。統計モデルの全原点の被覆率・分位損失は、V9b の標本(各セル 200 原点)以外は、保存値の集計の照合にとどまる。
- V7a は本番の乱数手順の算術の再現で、設計の独立検証ではない。
- 抽出された原点(V3)は、期間の先頭と末尾、月次再推定の境界、ギャップ近傍を優先して含む。
