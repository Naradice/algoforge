## 2. 探索的検定(補助。名目 5% の保証なし)
Holm 調整後 p < 0.05 のセル数(8 セル中): FA90 は 7(final h24 以外)、FE は 7(final h24 以外)、FC は final の 4 セルすべて(調整後 p 0.0008〜0.0135)で検証は 0、FD(75%)は final の 4 セルと検証 h1 の計 5、FD(99%)は final の 3 セル、FB は 0。FD(1%)の検証 h24 は超過が 0 件で se = 0 のため「判定不能」。FF(max-t)は ATR・時間帯とも h24 以外の多くで棄却(p < 0.01)、h24 は検証・final とも非有意(final h24: ATR p = 0.14、時間帯 p = 0.44)。ATR の最高群 − 最低群の事前指定の対比(90% 被覆率)は h1 で −0.131(検証)、−0.100(final)、他のホライズンの多くは 0 を含む。これらの p 値は、合成実験で名目より大きい棄却率が確認された検定による補助情報である。

## 3. 観測された特徴の記述と、仮説との整合(原因は確定しない)
**(1) 中心のずれと区間幅の不足のどちらに強く整合するか**
- final 期間では、h1・h4 で `k_c` が上側・下側ともに 1 を超え(h4 の `k_90` は上側 1.37、下側 1.44)、両側の外れ率がともに名目(5%)を上回る(h4: 0.084、0.106)。**対称な幅の不足(H1 と整合的な兆候)**が主要な特徴に見える。
- 同時に、final 期間では `P(y>m)` が 0.52〜0.58 に上がり、h4・h12・h24 の信頼区間は 0.5 を含まず、75% 分位点の超過率の差が −7〜−10 ポイント、PIT 平均が 0.52〜0.55 と、**上方向の中心のずれ(H2 と整合的な兆候)**がある。上側の外れ率が下側より大きい(h4: 0.106 対 0.084)。ただし FB(上下の外れ率の差)の Holm 後 p は 0.38 以上で、非対称の大きさは対称な不足より小さい。
- h24 の final は、90% 被覆率 0.892、`k_90` 1.04 とほぼ較正されているが、50% の被覆率は 0.424(`k_50` 1.22)で、75% 分位点の差は −9.5 ポイント。**内側の区間だけが不足し外側は不足しない**形(H3 と整合的な兆候)で、上方向の中心のずれと同時に存在する。
- 検証期間は異なる: h1 は弱い不足(90% 被覆率 0.884)、h4 は不足(0.864)、h12(0.925)・h24(0.972)は**過剰被覆**(`k_90` 0.90、0.72)で、予測区間が広すぎる。PIT 分散は h24 で 0.063(1/12 未満)。**符号が期間とホライズンで変わる**ので、単一の「分散不足」では説明できない。

**(2) ホライズン・局面・期間による変化**
- 不足は ATR・時間帯に強く依存する。final の h1・h4 では、最も低い ATR 群は過剰被覆(h1 0.956、`k_90` 0.83)、中〜高 ATR 群で不足が大きく(h1 の ATR 3: 0.741、`k_90` 1.59)、UTC 08–16(h4: 0.742)で最も不足し、16–24 は 0.90 付近で名目に近い。h24 は群間でほぼ均一。検証期間にも同様の ATR 依存がある。ATR 群の内側でも `k_90` が 1 を超える群があり(h1・h4 の ATR 1〜3)、プールした結果が局面の混合だけによるとは言えない。
- 期間の差: final は検証より、90% 被覆率が全ホライズンで 3〜8 ポイント低く、`P(y>m)` が高い(中心のずれ)。検証 → final の悪化は h12・h24 で最も大きい(0.925 → 0.856、0.972 → 0.892)。

**(3) 推定期間でも不足か、P3 で検証すべきこと**
- 推定期間(標本内)でも、h1(0.839)、h4(0.805)、h12(0.856)で 90% 被覆率が名目を下回り、final と近い。**標本内ですでに不足がある(H5 と整合的)**。写像に使った窓の原点とそうでない原点で差がないため、写像の過学習というより DDM の予測分布そのものの特徴を示唆する。ただし、使われなかった原点も写像の窓に近接しており、独立な評価ではない。h24(0.915)は名目付近。
- 検証期間の h1・h4(0.884、0.864)と、検証だけ過剰被覆の h12・h24 の違いが、期間ドリフト、局面の構成、初期状態の影響のどれによるかは、この診断では切り分けられない。P3(burn-in 感度分析)で検証する候補: (a) h1・h4 の対称な幅の不足が burn-in で変わるか、(b) ATR 局面別の不足、(c) h12・h24 の期間差(検証の過剰被覆と final の中心のずれ)。

## 4. 方法上の限界(再掲)
- 探索的な診断。final 期間は部分的に既知で、F1 の判定に使った期間である。
- p 値は名目 5% の保証がない(合成ケース 1 で最大 0.088)。週ブロック bootstrap の信頼区間も、アンサンブルの標本誤差の共有と週をまたぐ依存のため、妥当性が保証されない。
- D3 以降は、保存済みの標本がないため DDM のみ。D5 の標本内被覆率は独立な汎化性能ではない。DDM の予測分布は初期状態から始めたパスの分布(F1 の解釈上の制限 8)で、D5 はこの影響の一部を示唆するのみ。
- 統計モデル(B0・B4・B7N・B8)との比較は、保存済みの PIT・`hit`・pinball の範囲(JSON の `stat_models`)。
- ATR・時間帯・月の交絡のため、局面別の結果から因果的な原因は特定できない。
- DDM の再較正、モデル変更、F1 の再評価、P3 の実行は含まない。
