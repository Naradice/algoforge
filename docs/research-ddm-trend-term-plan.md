## 2. 仮説

**H:** 固定時間の足で持続を打ち消す約定間の依存は、逆張りのトレンド項が主な原因である。したがって項を取ると、持続が残る割合が 0.2 を超えて増える。

## 3. 条件

DP2 の結合なしモデル(`DDMv3`、300 エージェント、直近 5 約定の等加重、ショックなし)で、エージェントごとの係数 `d_i` だけを変える。本番のシミュレータは変更しない(`d_i` は引数で渡せる)。

大きさ `m_i` は U[1.5, 3.5] から引き、同じ seed の 3 条件で共有する(乱数 seed = 100000 + 価格 seed)。

| 条件 | `d_i` | 意味 |
|---|---|---|
| **base** | `−m_i` | 現行と同じ分布(全員逆張り) |
| **zero** | 0 | トレンド項なし |
| **mix** | `s_i·m_i`、`s_i` は +1 と −1 が 150 ずつ(同じ乱数で並べる) | 追随と逆張りが半々 |

全員追随(`+m_i`)は含めない。元のノートに一方向の動きの記録があり、安定性が定まっていないためで、必要なら別の計画にする。

- 価格は時計に依存しないので、条件ごと・seed ごとに 1 回シミュレーションし、時刻を後から割り当てる(順序あり / 並べ替え)。
- 各条件 X に、その約定ごとの対数収益(burn 後)を並べ替えた基準系列 **RW_X** を作る(DP2 と同じ方法)。
- burn 5,000 + 100,000 約定、時計 K-long の較正値とプールは DP1 の値。時計の並べ替えは burn 後の間隔だけ。
- seed: 価格 401〜420(パイロット 391〜395)、時計 = 価格 seed + 1000、時計の並べ替え = 50000 + 価格 seed、収益の並べ替え = 90000 + 価格 seed。

## 4. 指標

足と指標は DP2 と同じ(60 秒の連続格子。F = run ごとの |足の対数収益| の自己相関、ラグ 2〜10 の平均)。

- `G_X` = F(X, 順序あり) − F(X, 並べ替え) の seed 平均
- `G_RWX` = 同じものを RW_X で計算
- **持続が残る割合** `ρ_X = G_X / G_RWX`(DP2 の `1 − L_A` にあたる)
- **主比較** `Δ_X = ρ_X − ρ_base`(X = zero、mix)

## 5. 判定(実行前に固定)

区間はすべて、価格 seed を単位とするパーセンタイル・ブートストラップ 10,000 回(乱数 seed 20261130)。割合は、再抽出した seed で `G` の平均を取ってから比を計算し、`Δ_X` は同じ再抽出で base と X を対にする。使う seed は、base と X の両方が有効な seed。

**前提(比較ごと):** `G_RWX` と `G_RWbase` の 95% 区間の下端がどちらも 0.03 を超える。満たさない比較は割合を判定せず、値を記述する。

**`Δ_X` の判定**(2 比較なので各 97.5% 区間)

| 条件 | 判定 |
|---|---|
| 下端 > +0.2 | 打ち消しが大きく減る |
| 区間全体が (−0.2, +0.2) の内側 | 大きな変化なし |
| 上端 < −0.2 | 打ち消しが大きく増える |
| 上のどれでもない | 判定保留 |

**仮説の結論は `Δ_zero` で決める。**「大きく減る」なら支持、「大きな変化なし」「大きく増える」なら不支持、それ以外は保留とする。`Δ_mix` は並べて報告し、仮説の結論には使わない。0.2 は DP2 と同じ目安で、理論的な根拠はない。

割合が増えても、固定時間の持続そのもの `G_X` が増えるとは限らないので、`G_X` と区間(95%)を必ず並べて報告する。

**副次(判定しない。run ごとに計算して平均)**

1. F(順序あり)、F(並べ替え)の各値。並べ替えでも残る持続は、時計によらない持続である
2. 60 秒足の分散比 `Σr² / ΣQ`(全体と、約定数の四分位ごと)
3. 約定ごとの収益の自己相関(ラグ 1〜5)、20 約定足の収益のラグ 1 自己相関
4. 60 秒足の収益の尖度、価格の最小値と最大値
5. `ρ_base` と DP2 の値(約 0.26)の比較

### S0

| # | 検査 | 合格の条件 | 不合格のとき |

| 1 | プールの SHA-256 が DP1 と一致。係数の渡し方の一致検査(seed 7〜9 × 20,000 約定): 現行モデルの内部で引かれた `d_i` を引数で渡しても、価格列が同じ | 一致、bit 単位で一致 | 停止 |

## 8. 言えないこと、対象外

- 分かるのは、結合なしのこのモデルで、係数の符号の構成を変えたときの打ち消しの変化である。**参照期間の長さ、重み、結合ありの場合は調べない。**
- 不支持でも、打ち消しの原因がマッチングの仕組みだとは特定しない(仕組みを変えた条件がない)。
- 係数の大きさは [1.5, 3.5] だけで、他の大きさには広げない。
- 合成データだけで、実市場の値は使わない。
- 対象外(それぞれ別の計画と承認): 全員追随、参照期間と重み、係数の大きさ、結合との組み合わせ、マッチングの仕組みの変更、実市場との比較。
