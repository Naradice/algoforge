## 1. 出発点

## 2. 考えられる理由と切り分け方

固定時間の足の収益は、その 60 秒に入る約定の価格変化の和である。時計が持続すると足の約定数は持続するが、次の 2 つがあると、足の値動きの大きさには現れにくい。

| 段階 | 理由の候補 | 比べるもの |
|---|---|---|
| A: 約定間の依存 | 価格変化が打ち消し合い(平均回帰など)、約定数が多くても足の値動きが大きくならない | 約定ごとの値動きを並べ替えた系列 対 結合なしの DDM |
| B: 結合 | 約定が少ない時間帯ほど 1 約定の値動きが大きくなり、約定数の多少と打ち消し合う | 結合なしの DDM 対 結合ありの DDM |

どちらも候補であり、確かめていない。

## 3. 系列と条件

DP1 のコード(`backend/research/ddm_persist/`)を再利用する。DDMv3 の設定(300 エージェントなど)、burn 5,000 + 100,000 約定、時計 K-long の較正値とプール(DP1 の `s0.json` の値。プールは SHA-256 で一致を確認)は同じ。本番のシミュレータは変更しない。

| 系列 | 価格の作り方 | 時計 |
|---|---|---|
| **RW** | U の burn 後の約定ごとの対数収益 100,000 個を並べ替えて累積(burn の部分はそのまま) | 順序あり / 並べ替え |
| **U**(結合なし) | `DDMv3`、`wma` = [1,1,1,1,1](直近 5 約定の等加重)。価格は時計に依存しない。順序ありと並べ替えで**同じ価格列**を使う | 同上 |
| **C**(結合あり) | DP1 の時間窓モデル(η = 15 秒)。時計ごとに別の価格列 | 同上 |

- U は、間隔が一定のときの C と一致する(DP1 の一致検査)。
- 並べ替えの時計は、DP1 と同じく burn 後の間隔だけを並べ替える。
- seed: 価格 301〜320、時計 = 価格 seed + 1000、時計の並べ替え = 50000 + 価格 seed、RW の並べ替え = 90000 + 価格 seed。
- シミュレーションは U 20 run、C 40 run。RW は U から作る。

## 4. 指標

**足:** 60 秒の連続した格子(約定のない足を含み、終値は直前の値)。DP1・T1 と同じ作り方。境界ちょうどの約定は後の足に入れる。

**主指標 F:** run ごとに、60 秒足の |対数収益| の自己相関(run の平均を引く)を求め、ラグ 2〜10 を平均する。

系列 X ごとの時計の順序の効果: `G_X` = F(X, 順序あり) − F(X, 並べ替え) の seed 平均(seed で対にする)。

**失われた割合**(RW を基準にする):

- `L_A = (G_RW − G_U) / G_RW` : 約定間の依存で失われた割合
- `L_B = (G_U − G_C) / G_RW` : 結合でさらに失われた割合
- 残り `R = G_C / G_RW`。`L_A + L_B + R = 1`

RW は、値動きの分布を U と同じにして約定間の依存をすべて除いた系列である。したがって A は平均回帰だけでなく、**約定の順序に関する依存全体**を指す。

## 5. 判定(実行前に固定)

区間はすべて、価格 seed を単位とするパーセンタイル・ブートストラップ 10,000 回(乱数 seed 20261129)で求める(S0 の検査 4 も同じ)。

**前提:** `G_RW` の 95% 区間の下端が **0.03** を超える。

- 超えない場合: 「約定間の依存がなくても、この時計の持続は 60 秒の足にほとんど出ない」と報告し、`L_A`、`L_B` は判定しない。

**`L_A`、`L_B` の判定**(各 97.5% 区間。再抽出した seed で `G` の平均を取ってから比を計算する)

| 条件 | 判定 |
|---|---|
| 下端 > 0.5 | 主な原因 |
| 0.2 < 下端 ≤ 0.5 | 寄与あり |
| 上端 < 0.2(負を含む) | 小さい |
| 上のどれでもない | 判定保留 |

`L_A` と `L_B` の判定は並べて書き、まとめた 1 つの判定にしない。`R` は値と区間を記述する。0.5 と 0.2 は目安で、理論的な根拠はない。0.03 は DP1 と同じ値である。

**副次(判定しない)**

系列 × 時計ごとに、次を run ごとに計算して平均し、記述する。

1. 足の約定数 N の自己相関、約定ごとの値動きの 2 乗和 Q の平方根の自己相関(どちらもラグ 2〜10 の平均)
2. F のラグ 1・5・20
3. N の四分位ごとの分散比 `Σr² / ΣQ`(N ≥ 1 の足。1 より小さいほど足の中で打ち消し合う)
4. N と 1 約定あたりの 2 乗値動き `Q/N` の順位相関(負が大きいほど、約定が少ない足で 1 約定の値動きが大きい)
5. 足あたりの約定数の平均、空の足の割合

読み方の目安(判定にはしない): A の仕組みなら、U で N が多い四分位ほど分散比が小さい。B の仕組みなら、C の順位相関が U より負になる。

### S0

| # | 検査 | 合格の条件 | 不合格のとき |
|---|---|---|---|
| 1 | プールの SHA-256 が DP1 と一致。一致検査(seed 4〜6 × 20,000 約定): 間隔一定の時間窓(η = 5)と U の設定 | 一致、bit 単位で一致 | 停止 |

## 8. 言えないこと、対象外

- 分かるのは、この変更モデルと時計で、持続がどの段階で失われるかまでである。**どう直せば固定時間の足に出るかは調べない。**
- A が大きくても、原因が逆張りのトレンド項だとは特定しない(項を変えた条件がない)。
- 合成データだけで、実市場の値は使わない。実市場の仕組みについての主張はしない。
- 足の幅は 60 秒だけで、他の幅には広げない。
- 対象外(それぞれ別の計画と承認): トレンド項の符号や追随者の混在、時計の記憶を長くする、価格 → 時計の結合、他の足の幅、実市場との比較。
