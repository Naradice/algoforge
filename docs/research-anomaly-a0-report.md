# A0 結果報告: 異常の操作的定義・時間スケール選定・評価設計(Study Manager #897)

## 要約

- **A1 の対象は「次の 1 時間(M1 60 本)の急変動の始まりの事前予測」(分類 4、候補 C-M1、F1 の予測分布を使う)。** 事前に固定した規則を適用した結果。
- **この選定はラベルの定義に依存する。** 99% 点、または最小間隔 1,440 本にすると、どの候補も下限 100 に届かず「対象なし」になる。
- **余裕は小さい。** 評価期間のイベントの見込みは 114(下限 100)。A1 の案では δ_A = 0.05 で判定保留になる可能性が高い(仮定による計算)。
- 外部ラベル(経済指標・市場介入)は、手元に対象期間のデータがなく不合格。取得はしていない。
- 評価期間には、推定期間にほとんどない**市場の開始前の日曜の足**がある。
- **A0 では検知スコアを計算・比較していない。** 検知性能については何も分かっていない。

## 4. データの確認(A0-3)

### 主系列(`usdjpy_1min_volatility.parquet`、SHA-256 照合済み)

| 期間 | 行数 | 重複・逆行 | 300 秒超の間隔 | 週の開始が月曜 00:00〜00:29 |
|---|---|---|---|---|
| 推定 | 1,490,151 | 0 | 262 | 205 / 209 週 |
| 検証 | 373,054 | 0 | 126 | 42 / 52 週 |
| 評価 | 376,079(2022-08-31 17:59 まで) | 0 | 242 | 3 / 52 週 |

- **評価期間の時刻の基準:** 変換した HistData との相関は、53 週すべてで時差 0 が最良、中央値 0.976。事前の基準を満たし、ニューヨーク時間 + 7 時間と扱える。
- **日曜の足(事後の確認、時刻のみ):** 2021-06-27 以降、毎週ほぼ日曜 22 時から行がある。評価期間で 2,393 行(22・23 時)、推定期間は 11 行。ニューヨークの日曜 15・16 時で市場の開始前にあたる。中身は調べていない。F1 の最終期間とその後の分析もこの行を含む。影響は評価していない。
- **原点数:** 時刻だけで数えた評価期間の原点は、C-M1 6,123、C-M4 5,943、C-D 4,750 で、F1 の記録と一致した。検証期間の C-M1 は 6,079(F1 の記録は 6,076。F1 は値の条件を加えている)。C-S は 24,858、C-R は 257。
- C-M1 の評価期間で、直前の原点が有効かつ日曜の行を含まないのは 6,049(見込みは約 113 イベント)。

## 5. 検知の評価設計(A0-4)と選定(A0-5)

- 評価の型は手順書の §6。A1 への当てはめは[A1 の計画案](research-anomaly-a1-plan.md)。
- 必須条件を満たすのは C-S と C-M1。どちらも L2 なので優先 (1) では差がなく、優先 (2) の既存の予測分布で **C-M1** を選んだ。
- 「検証済み」の限界: F1 はリーク検査と事後監査を通っている。独立検証(P1)は事前の完全一致の基準に PIT の同値 1 件(DDM)で不合格だった。推定期間の分布はない。この扱いを認めない場合、優先 (3) でイベントの多い C-S が選ばれ、新しい予測モデルが必要になる。
- C-S は次の候補として残る。日・週以上の状態変化は、今回のデータ量では扱えない。
