## 0. 要約

1. **事前ゲートはすべて通過した**(§1)。T0g(格子表現)と T0(標本表現)の CRPS の相対誤差は最大 3.9×10⁻⁴ で、許容値 1×10⁻³ を超えたセルはない。
2. **A(分位点の比較)**: 推定期間で、DDM は E1a に対して**位置のずれがほとんどない**(中心のずれは E1a の IQR の 0.06〜0.08 倍以内、h24 のみ 0.20)。一方、**尺度は ATR バケットに強く依存**する。バケット 0〜16 で DDM/E1a の尺度比は、ATR が高いほど系統的に小さくなる(h1 の r−(0.05) は 1.45 から 0.45、バケット番号との順位相関 −0.99、h4 は −0.97。記述のみ)。低 ATR では DDM の方が広く、高 ATR では狭い。**バケット 0〜16 の形状指標は中央値が 0.87〜1.13 とほぼ 1** で、**ATR 最上位の 3 バケット(17〜19)だけ形状が大きくずれる**(内側は狭く裾は相対的に広い。形状指標 1.1〜2.2)。
3. **B(ホライズン方向)**: DDM の 90% 幅の対数をホライズンの対数に対して見た傾きは、**ATR 群・期間によらずほぼ同じ**(h1→h4 は 0.40〜0.50、h4→h12 は 0.58〜0.75、h12→h24 は 0.65〜0.85)。実現値の傾きは h1→h4 が 0.47〜0.72、以降は 0.43〜0.74 で、**DDM は h1→h4 で遅く、h4 以降で速く広がる**。
4. **C(簡単な変換)**: final の h1・h4 で、E1a との CRPS の差のうち、**共通尺度(T1)は 27%/52%、バケット別尺度(T2)は 77%/75%、共通 PIT(T3)は 14%/20%、バケット別 PIT(T4)は 97%/97% を閉じる**。共通の尺度や共通の PIT 再較正は、全群を同じ向きに広げるため、ATR 群間のずれを揃えられない(final h1 の群別被覆率は T1 で 0.84〜0.98)。バケット別尺度(T2)で群間の被覆率はほぼ揃う(0.89〜0.95)。検証期間では T1・T3 は過剰に広がり、CRPS が悪化する(h1 +0.6%、h4 +0.8%)。
5. **D(候補)**: 推定期間のみで選んだ**単一候補**は、final の CRPS を 8 候補混合より h1 で 1.78%、h4 で 1.86% 改善した(E1a は 2.17%、2.45%)。**ただし、バケット 11〜16 の h1 では 8 候補すべてが E1a より狭く**、混合の重みを変えても E1a の幅に届かない。選択の seed 間の一致率は単一で 0.25〜0.40(偶然の一致は 0.125)。
6. **S5(記述)**: h1 の DDM/E1a の幅の比は、マッピングの `best_std_ratio` と順位相関 +0.82(n = 20)。低 ATR バケット(0)では M1 の標準偏差を合わせたときのシミュレーション側の標準偏差が実現値の 1.8 倍で、DDM の 60 分足の幅も広い。`best_std_ratio` が約 1.0〜1.1 のバケット 12〜16 と 18 では DDM の幅は E1a の 0.5〜0.7 倍と狭い(バケット 17 は例外で 0.98)。
7. **E(P3 変種)**: C2(60) も C3 も、同じ型(バケット別尺度で大半が閉じ、共通尺度や共通 PIT では閉じない)を示した。C3 は T1・T2 の係数が格子の上限(2.0)に達したため、結果の解釈を限定する。
8. **仮説との整合(§6)**: S1(尺度)は**バケット依存の尺度**として整合的、S2(形状)は**最上位の ATR バケットで整合的**、S3(ホライズン方向)は整合的、S4(候補の混合)は**部分的**(単一候補の選択で final の E1a との差の 76〜82% は閉じるが、バケット 11〜16 では候補集合自体が狭い)、S5 は整合的(記述のみ)。**ただし、E1a が DDM より良いことは DDM の構造的な限界の確定ではない。**

## 1. 実行の記録

- 事前ゲート(`results/gates.json`)すべて PASS: 1 生データのハッシュ、DDM(C0s)の指標が P3 の保存値を、E1a の指標が P4 の保存値を 1e-12 で再現。2a 分位点の比・形状・位置の実装を既知分布(対称、非対称、未定義)で検証、T1 は `s=1` のとき元のアンサンブルを返し CRPS が一致、T1 は中央値を固定。2b 恒等 PIT 変換が T0g の格子と一致、格子が単調、同じ表現での CRPS が総当たりと一致(1e-12)。2c T0g と T0 の CRPS の相対誤差は最大 3.9×10⁻⁴(許容値 1×10⁻³)で、超過なし。3 候補の復元(生成式が F1・P3 のコードに存在、バケットごとに 8 候補、試行 ID が単調で記録の範囲内、先頭 150 件が生成式と一致、候補別の経路数が 0.10〜0.15)。4 推定期間のみでの当てはめ(非推定セルへのアクセスで例外を投げるガード下で実行でき、検証・final を乱数で置き換えても T1〜T4 の係数と候補選択が変わらない)。5 T3・T4 の変換後の分位点関数が単調。
- 実装上の判断(計画の趣旨の範囲内):
  - DDM の分位点は C0s の 3 seed をプール(3,000 点)。CRPS・被覆率は seed ごとに評価して平均(P4 と同じ)。
  - T1・T2 は、各 seed のアンサンブルの中央値のまわりに拡大・縮小。T3・T4 は、推定期間の PIT(中点 PIT)の経験分布の逆関数で分位点関数を置き換えた 1,000 点の格子(T0g も同じ表現)。T3・T4 の「差が閉じた割合」は T0(標本表現)に対して計算し、近似誤差は 2c で確認した。
  - ATR 群の分位点は、各バケットの原点数で重みづけた混合(重み付き ECDF の中点補間)。実現値 y の分位点は numpy の線形補間。バケット別・群別の週ブロック bootstrap(B = 2,000)は、同じ期間のすべてのホライズンで同じ週の重複度を共有(傾きの区間のため)。
  - D の評価は、3 seed をプールした表現(8 候補混合は 3,000 点)で統一した。P4 の seed 平均の DDM とは CRPS が厳密には同じではない(表 D3 の「8 候補混合」の被覆率は DDM とほぼ一致。例: 検証 h1 で 0.885 対 0.883、推定 h1 で 0.836 対 0.836)。
  - S5 の記述子には、計画に例示された `best_std_ratio`、`out_of_range`、`n_windows_available` に加え、実現値の統計量(標準偏差、尖度、自己相関、ボラティリティ・クラスタリング)とバケット番号を含めた。`out_of_range` は全バケットで False(定数)のため相関を計算していない。

## 3. 分析 B: ホライズン方向の関係(S3)

- **バケット別(推定期間)**: 傾きの中央値(20 バケット)は、DDM が h1→h4 で 0.48、h4→h12 で 0.75、h12→h24 で 0.84。E1a(実現値)は 0.58、0.55、0.53。
- **群別・期間別**(表 B1): DDM の傾きは群・期間にかかわらずほぼ同じ(h1→h4 0.40〜0.50、h4→h12 0.58〜0.75、h12→h24 0.65〜0.85)。実現値は final で h1→h4 が 0.47〜0.72、h4→h12 が 0.52〜0.63、h12→h24 が 0.43〜0.74。**DDM は h1→h4 で実現値より遅く広がり(final の群 0〜2 で差 −0.14〜−0.24)、h4 以降は速く広がる(差 +0.06〜+0.40)**。
- 実現値の傾きは検証期間の高 ATR 群で大きく変わる(群 4 の h1→h4 は 0.23)。**ホライズン方向の不一致には、DDM の時間スケールの問題と、期間による市場分布の違いが混ざる**ため、推定期間(標本内)と検証・final を分けて表 B1 に示した。DDM の傾きの形(0.48 → 0.75 → 0.84)は、推定期間のバケット別でも final の群別でも同じなので、**DDM 側の特徴として整合的**。

## 4. 分析 C: 簡単な変換による診断(推定期間のみで固定した係数)

## 7. 限界

- E1a は推定期間の標本内の経験分布であり、E1a に近づくことは独立な評価ではない。期間外は検証・final のみ。
- 原点が連続して窓が重なるため、実質的な標本数は週数に近い。区間は記述的で、アンサンブルの標本誤差を含まない(DDM は seed 間の範囲を別に示した)。
- バケット単位の評価は推定期間のみ。検証・final は ATR 群単位。検証期間の高 ATR 群は原点が少ない。
- T2・T4 は自由度が高く、推定期間の CRPS の良さだけでは実証にならない。T1・T3 は共通の係数であり、期間の構成(低 ATR が多い検証期間)の影響を受ける。
- 候補の選択は 1 候補あたり約 375 経路の有限標本に基づく。選択の改善には楽観が含まれうる(final で再現はしている)。候補の生成機構そのものの適切性は判断できない。
- 診断用の変換は、DDM の構造的な原因を特定しない。特定できるのは、差の「型」に整合的かどうかまで。
- final 期間は F1 の判定に使われた期間で、部分的に既知。P5-A では final の結果で変換や基準を変更していない。
- E の C3 は、格子の上限に達した係数が多く(80 中 41)、結果の解釈を限定する。
