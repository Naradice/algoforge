# F1 後続 P3: 初期状態・過渡状態が DDM 予測分布の較正に与える影響 — 実験計画(草案 v0.1、未承認)

位置づけ: F1(#889)の後続研究。P2(#940・#941)で記述された較正不足の特徴に、**DDM の初期状態・過渡状態への依存がどれだけ寄与するか**を検証する。burn-in を導入すれば予測が改善するという前提はおかない。F1・P1・P2 の結果と Study Manager #889・#937・#938・#939・#940・#941 は変更しない。**承認前に何も実行しない**(監査の補助計測 `p3_burnin/audit_measure.py` のみ実施済み。実現値も評価も使っていない)。前提監査: `docs/research-f1-p3-ddm-audit.md`。

## 1. 問い
P2 で観測された特徴(final の h1・h4 の区間幅の不足 `k_90` 1.18/1.39 と上方向の中心のずれ、ATR 群・時間帯による不均一、推定期間でも不足、検証期間の h12・h24 は過剰被覆)のうち、**予測パスの開始直後の過渡状態(エージェント状態の未緩和と §11 の早期ショック)に由来する部分があるか**を、介入によって調べる。原因の確定や再較正は目的としない。

## 2. 監査で確認された事実(要約。詳細は監査文書)
- DDM の予測は、原点の ATR バケットだけに依存する無条件のパス分布。実観測を状態に入力する仕組みはない(本計画の範囲外)。
- 各パスは、乱数から作った初期状態から始まる。§11 のショックは経過ステップ τ = 300(≈ 10 本のローソク足)で減衰し、期待ショック数は 1 パス 0.6 回で、ほとんどが最初の約 20 本に集中する。**初期の過渡状態とショックは時間的に重なる**ため、単純にパスの先頭を捨てると両方が同時に変わる。
- したがって、条件に「先頭を捨てる長さ(burn-in)」と「ショックの扱い」の 2 軸が必要。

## 3. 範囲と固定するもの
- 固定: マッピング(`ddm_mapping.json`)、バケットの定義、候補 (delta, wma) の集合、`N_AGENT`、ショックのパラメータ(P0 = 0.002、S = 0.3、τ = 300、床 0)、パス数 1,000/バケット、seed の規則、評価原点(P2 と同じ検証・final・推定の原点集合)、実現値 `y = log C1 − log C0`、ホライズン 1/4/12/24、ゲート(P2 の入力ハッシュ照合)。
- 範囲外: DDM の改修・再較正、実観測を状態に入力する方式、新しい期間・モデル(P4)、F1 の再評価。

## 4. 条件(2 軸の要因計画)
軸 A: burn-in の長さ B(ローソク足の本数。1 本 = 20 約定。パスの先頭 B 本を捨て、その後の 1,441 本で予測値を作る)。軸 B: ショックの扱い。

| 条件 | B | ショック | 実装 | 先頭 B 本の乱数列 |
|---|---|---|---|---|
| C0(対照) | 0 | §11 あり | **F1 の保存済みアンサンブルをそのまま使う** | – |
| C3 | 0 | なし | `exogenous_shock_probability = 0` | 分岐(ショックの乱数消費なし) |
| C1(B) | 15、60、240 | あり。**時計は進む**(捨てた部分でショックは減衰) | 同じ seed でより長いパスを生成し `closes[B : B + 1441]` を使用 | **C0 と同一**(同じ乱数列の後ろの窓) |
| C2(B) | 15、60、240 | あり。**時計を 0 に戻す** | B 本の約定後に `_step_count = 0` を設定して続行 | 先頭 B 本は C0 と同一、以降は分岐 |

- B の値の根拠(監査): ショックの τ ≈ 10 本。15 本で期待ショック数の残りが 0.14、60 本で 0.002、240 本で ~0。エージェント状態の緩和時間はコードから読み取れず未知のため、3 水準で広くカバーする(B の値は審査での調整対象)。
- 読み取り方(要因計画): 「緩和済み、ショックあり」= C2(B)、「緩和済み、ショックなし」≈ C1(B)(B = 60、240。B = 15 は残りのショックが 0.14 あるため区別して扱う)、「未緩和、ショックなし」= C3、「未緩和、ショックあり」= C0。**交互作用** = (C2 − C1) − (C0 − C3)(各指標)。
- 条件の数: 新規 7(C3、C1 × 3、C2 × 3)+ 再利用 1(C0)。

## 5. 段階的な実行(計算量の管理)
- 計算量: 1 seed(20 バケット × 1,000 パス)あたり約 1.5 時間(F1 の記録)、B = 240 で +17%。
- **段階 1**: 全新規条件を seed 1(`seed_id = 1`)で生成し、C0 の seed 1 との対応比較を行う(約 12 時間)。
- **段階 2**: seed 2・3 は、段階 1 で次の「注目基準」を満たした条件のみ生成する。基準(事前固定。いずれかの期間・h ∈ {1, 4, 12, 24} のセルで、対応する C0(seed 1)と比べて): 90% 被覆率の変化 ≥ 2 パーセントポイント、または CRPS の相対変化 ≥ 0.5%、または `k_90` の変化 ≥ 0.10、または `P(y>m)` の変化 ≥ 0.03、**かつ**その変化が C0 の seed 間の最大差(seed 1〜3 の範囲。下記 §7)を超える。どの条件も満たさなければ、段階 2 は実施せず、「検出可能な効果なし」として報告する。
- 段階 1 のみで結論を出さない: 段階 2 の対象になった条件は、3 seed を揃えて主な報告にする。

## 6. 実装前のゲート(どれかが失敗すれば実行しない)
1. **C0 の再現(バイト単位)**: 同じ seed と同じコードで、バケット 0(seed 1)を再生成し、保存済みの `ddm_ens_seed1.npy` のバケット 0 と配列が一致すること(さらに、バケット 10 と 19 も)。不一致なら、環境差(乱数、ライブラリのバージョン)を調査し、先へ進まない。
2. **実装の単体テスト**(小さなパス数で。P3 のコードは `backend/research/p3_burnin/` にコミットしてから実行):
   (a) C1(B) の最初の 1,441 本が、同じ seed の C0 のパス(長さ 1,441)の先頭と一致すること(`B = 0` では全体が一致)。
   (b) C2 で、記録開始時のショック確率が P0 に戻っていること(`_step_count == 0`)と、B = 0 で C0 とバイト単位で一致すること。
   (c) C3 で、ショックのイベントが 0 であること。
   (d) ホライズンの式 `log(closes[60h] / closes[0])`(窓の先頭を 0 とする)と、失敗パスの扱い(`None`、再試行の規則)が `f1_ddm.py` と同一であること。
3. **未来情報の混入がないこと**(必須): 新規アンサンブルの生成コードが、マッピング(推定期間のみ)以外の実データを読まないこと。バケットの割り当て(原点の ATR)が P2 と同一であること(原点ごとのバケット配列のハッシュを照合)。
4. 入力ハッシュ(58 ファイルと生データ)の照合、実行コミットの記録、出力は新しい作業ディレクトリ(既存成果物は変更しない)。
5. 条件ごとに、パスの成功率(attempts に対する successes)を記録して報告する(失敗パスの除外が条件間で母集団を変えないかの確認)。

## 7. 主要な評価量と比較の方法
比較はすべて、**同じ評価原点、同じ実現値、同じホライズン、同じアンサンブル数(M = 1000/seed)**で、条件と C0 の対応(同じ seed 番号)で行う。原点集合は P2 と同一で、変わらない(除外は発生しない)。

優先順位(事前固定):
1. **CRPS(予測性能)**: 原点ごとの fair CRPS の、C0 との差(相対変化 = 条件の合計 / C0 の合計 − 1)。F1 で選ばれた統計モデルの CRPS との比(F1 の Δ_h と同じ定義)も記述として併記するが、新たな分類(統計モデルより良い/悪い)はしない。
2. **較正**: 90%・50% の被覆率、`k_90`、`k_50`(P2 と同じ定義)。
3. **中心と形状**: `P(y > m)`、PIT の平均・分散、75%・25% 分位点の超過率の差。
4. **一貫性**: ATR 群別(5 群)、期間別(検証 / final / 推定)、ホライズン別。

不確かさの評価:
- **ノイズの基準**: C0 の seed 間の差(seed 1・2・3 の保存済みアンサンブルから、すべてのセルの各指標について、最大 − 最小)。条件の効果は、この範囲との比較を主とする。
- 週ブロック bootstrap(10,000 回)による対応差の 95% 区間は、**記述的な目安**として併記する。P2 で、アンサンブルの標本誤差の共有により検定が名目より過剰に棄却されることを確認しているため、**p 値と有意性による判断は行わない**。
- 「注目基準」(被覆率 2pp、CRPS 0.5%、`k_90` 0.10、`P(y>m)` 0.03)は報告の目安であり、合否の閾値ではない。

## 8. 解釈の規則(事前固定。因果は断定しない)
- すべての条件の変化が、ノイズの範囲(C0 の seed 間の差)に収まる: この B の範囲では、初期の過渡状態(エージェント状態の未緩和と §11 のショックの時間構造)は、P2 の特徴を説明する証拠として観測されなかった。
- C3(ショックなし)が C0 から変化: ショックの存在が寄与する可能性(ショックのパラメータの経緯は §11)。
- C2(B)が C0 から変化(ショックの時間構造は同じ): エージェント状態の緩和が寄与する可能性。
- C1(B)と C2(B)の差: 緩和済みの状態でのショックの有無の効果。交互作用が大きい場合は、2 つの効果が分離できないと報告する。
- 較正が名目に近づき、CRPS も改善(ノイズ範囲を超える): 分布として改善と整合する。被覆率のみ改善して CRPS が改善しない(または悪化): 幅の拡大のみと整合し、予測性能の改善の証拠にはならない。
- P2 の特徴ごとの対応: h1・h4 の幅の不足 → `k_90`、被覆率、CRPS。中心のずれ → `P(y>m)`、75% 分位点。ATR 依存 → ATR 群別の被覆率と `k_90`。推定期間の不足 → 推定期間の被覆率。h12・h24 の期間差 → 検証と final の被覆率の差の変化。

## 10. 限界
- 実観測を状態に入力する方式は検証しない。DDM は履歴を条件としない無条件のパス分布であり、burn-in はシミュレーション内の過渡状態の影響を見る介入にとどまる。
- P2 の限界を引き継ぐ: 探索的、final 期間は部分的に既知、p 値は名目の保証なし、週ブロック bootstrap はアンサンブルの標本誤差の共有と週をまたぐ依存を捕捉しない。
- 1 候補・12 パスの監査計測は一般化できない。エージェント状態の緩和時間は未知で、B の水準が不十分な可能性がある。
- ATR・時間帯・期間は交絡しており、条件の効果の局面別の解釈に因果は主張しない。
- 計算量の制約から、段階 1 は 1 seed。seed 間のばらつきが小さい(P2 で 90% 被覆率が 1 パーセントポイント以内)ことに依拠するが、条件ごとのばらつきは段階 2 で確認する。
