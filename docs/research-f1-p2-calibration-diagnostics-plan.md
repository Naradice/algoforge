## 1. 問い
F1 の final 期間で、DDM の予測区間の実測被覆率は名目値を下回った(h=4 の 90% 区間で 0.808、50% 区間は h=1〜24 で 0.379〜0.422)。この較正不足を、複数の観測可能な特徴に分解し、**どの特徴が、どのホライズン・局面で現れるか**を記述する。
- **H1 分散不足**: 予測分布の幅が狭い。
- **H2 中心のずれ**: 予測分布の位置が系統的にずれている。
- **H3 裾の形状**: 中心部の較正に比べ、外側の裾の較正が異なる。
- **H4 局面・時間依存**: 局面(ATR バケット、時間帯、月)によって較正が変わる、または写像の推定期間と評価期間の間にドリフトがある。
- **H5 標本内の較正不足**: 推定期間の原点でも、同じ写像の被覆率が名目値を下回る。

仮説は排他的ではない。H1〜H5 のどれか一つを選ぶことは目的ではない。結果は、較正不足の特徴の記述として報告し、原因の確定、DDM の改良、再較正は目的としない。結果は P3(burn-in 感度分析)で何を変え、何を固定するかを決める入力にする。

## 4. 実現値とタイ判定の仕様(P1 の知見の反映)
- 実現値の算出式を固定する: **`y = log C1 − log C0`**(F1 の本番と同じ式。`log(C1/C0)` ではない)。本計画のすべての診断で、この式の y を使う。
- 厳密な等値判定が必要な量(`pit_w`、`hit` の境界)は、保存済みの `scores_*.npz` の値をそのまま使うか、同じ式の y で再計算する。
- 数学的に等価な式 `y = log(C1/C0)` による結果は、**数値安定性の感度分析(D8)として別に記録**し、診断の結論には使わない。
- PIT の乱択(`pit = pit_lo + u·pit_w`)は、固定 seed で 100 回繰り返す。**この反復はタイの乱択に伴う変動**を評価するもので、市場データの標本不確実性(週ブロック bootstrap、§5.2)とは**別の量として、別の列で報告する**。決定的な範囲 `[pit_lo, pit_lo + pit_w]` による境界も併記し、タイの割合(DDM は約 0.3%)を明記する。
- 近似的なタイ判定は導入しない。

## 5. 診断
### 5.1 診断項目
対象: DDM(3 seed の統合と seed 別)、h = 1、4、12、24、検証期間と final 期間(D5 は推定期間)。統計モデル(B0、B4、B7N、B8)との比較は、保存済みの PIT・hit・pinball のみ(D1、D2、D6 の一部)。B8 は DDM と同じ局面情報(ATR バケット)を使う対照。
D3 以降で使う DDM の予測分位点は、バケットごとの保存済みアンサンブルから、線形補間の分位点(P1 と同じ定義)で得る。

**D1 PIT の要約(整合的な兆候のみ)**
- PIT の平均、分散(一様分布なら 1/12)、20 ビンのヒストグラム、両端 5% の質量、KS 距離。
- ヒストグラムには、一様分布(各ビン 0.05)からの偏差と、**週ブロック bootstrap による各ビンの 95% 帯**を示す。タイの乱択の変動は別の列。
- 位置づけ: PIT の形状は H1(U 字・分散が 1/12 を上回る)や H2(平均が 0.5 からずれる)と**整合的な兆候**であって、十分条件ではない。局面によって中心が正負にずれると、中心のずれだけで全体の PIT が U 字になり得る。D1 だけで H1 や H2 を判断しない。

**D2 区間被覆率と非対称性**
- 50/80/90/95% の被覆率(F1 と同じ、境界を含む区間)。下側の外れ率(y < 下限)と上側の外れ率(y > 上限)を別々に報告する。
- 予測中央値に対する実現値の符号の偏り: `P(y > 予測中央値)`(0.5 が較正)。
- 位置づけ: H1 は「両側の外れ率がともに名目値を上回り、D3 の幅の較正係数が 1 を超える」ときの整合的な兆候。H2 は「外れ率の上下非対称、または符号の偏りが 0.5 からずれる」ときの整合的な兆候。

**D3 幅と中心の診断(分位点ベースを主、正規基準を参考)**
- 主診断(分布の形を仮定しない): 各中心区間の水準 c ∈ {50, 80, 90, 95}% で、予測中央値 m を基準に正規化した超過量 `u = |y − m| / (q_c側 − m)`(y が m より上なら上側の分位点、下なら下側の分位点)。**幅の較正係数 `k_c` = u の c 分位点**(`k_c = 1` なら較正、`k_c > 1` なら予測区間が狭い)。上側と下側を別々にも計算する(`k_c^上`、`k_c^下`)。
- 中心の診断: D2 の `P(y > 予測中央値)` と、PIT の中央値。
- 参考指標(正規基準): `z = (y − m) / (IQR / 1.349)` の平均と MAD ベースの尺度。DDM の予測分布が非正規の場合、IQR/1.349 を予測標準偏差と解釈できず、尺度の比は実現値の形状にも依存するため、**主診断には使わず、参考として併記する**。
- 局面ごとの中心のずれが打ち消し合う場合、全体では対称な超過に見える。H1 は、`k_c > 1` が D4 の群の内側でも一貫した符号で保たれるときに限り、整合的と扱う。

**D4 局面・時間依存**
- 群の定義(事前固定): ATR バケット 0〜19 を 5 群(各 4 バケット)にまとめた群、UTC の時間帯 3 区分(00–08、08–16、16–24)、月。
- 各群で、90% 区間の被覆率と `k_90`(上側・下側別を含む)を報告する。
- 検定の規則(事前固定):
  - **事前指定の対比**: ATR の最高群 − 最低群の 90% 被覆率の差(1 つ)、時間帯の 3 区分間の被覆率(max-t の対象)。
  - **全群の最大差統計量(max-t bootstrap)**: 各群の被覆率 `g_g` とプールした被覆率 `g` について、`T = max_g |g_g − g| / se_g`。週ブロック bootstrap の各標本で `T* = max_g |(g*_g − g*) − (g_g − g)| / se*_g` を再計算し、`p = P(T* ≥ T)`。観測結果から最大と最小の群を選んで通常の差の信頼区間を使うことはしない。
  - 最小セルのサイズは 100 原点。満たさない群は報告のみで検定から除く。
- **交絡の注意**: ATR バケット、時間帯、月は互いに独立ではない(高 ATR は特定の時間帯や月に偏る)。群別の結果だけから、ATR 依存、時間帯依存、時間ドリフトを切り分けず、因果的な解釈はしない。ATR × 時間帯の 2 元表(90% 被覆率と原点数)を、記述として併記する。

**D5 標本内の診断(解釈を限定)**
- 推定期間の原点で、同じ写像・アンサンブルの被覆率、`k_c`、D2 の非対称性を計算する。
- **推定窓との重複関係を記録する**: 写像の構築に使った窓(各バケット最大 300 窓、seed 20261117)と、推定期間の原点の関係。本番のサンプリング手順を参照用に再現できる範囲で、(a) 写像に使われた窓の原点、(b) 推定期間で写像に使われなかった原点、を分けて報告する(再現できない場合は、報告できない旨と理由を記録する)。
- 解釈の限定:
  - 推定期間でも不足: 標本内ですでに較正不足が観測される。
  - 推定期間は良好で評価期間は不足: 標本内適合と標本外較正に差がある。
  - いずれの場合も、初期状態、写像の推定、期間ドリフトのどれが原因かは確定しない。標本内の被覆率は、独立な汎化性能の評価ではない。

**D6 裾の診断**
- 分位点 1、5、25、75、95、99% ごとに、**観測された超過率と名目の超過率の差(パーセントポイント)**とその週ブロック bootstrap による不確かさを報告する(相対誤差の比較は用いない)。pinball 損失も併記する。
- D3 の `z` の尖度は参考。
- H3 は、中心部(25、75%)と裾(1、5、95、99%)の偏差パターンを総合的に解釈する探索的診断とし、単一の比較では確定しない。

**D7 ホライズン構造(記述的)**: h ごとの `k_c`、予測区間の幅の `sqrt(h)` スケーリングとの比較。h=4 が最悪である理由の記述。
**D8 数値安定性**: §4 の等価な式による、タイ件数と被覆率の変化の報告のみ。

### 5.2 検定の定義と多重比較(事前固定)
すべて探索的。**主な報告は Holm 調整後の p 値**とし、95% の週ブロック bootstrap 信頼区間は、効果量の不確かさの表示として併記する。調整後の p 値や CI だけで原因を確定しない。

| ファミリー | 帰無仮説 | 統計量 | 検定 | 検定数(Holm の単位) |
|---|---|---|---|---|
| FA(水準 c ごと、4 ファミリー) | 被覆率 = c | `t = (被覆率 − c) / se`、se は bootstrap の標準偏差 | 両側 bootstrap-t(`p = P(\|t*\| ≥ \|t\|)`、`t* = (被覆率* − 被覆率) / se*`) | 8(h × 期間) |
| FB | 90% 区間の下側の外れ率 = 上側の外れ率 | 外れ率の差 / se | 両側 bootstrap-t | 8 |
| FC | `P(y > 予測中央値)` = 0.5 | `(P − 0.5) / se` | 両側 bootstrap-t | 8 |
| FD(分位点 q ごと、6 ファミリー) | 超過率 = 名目 q | `(超過率 − q) / se` | 両側 bootstrap-t | 8 |
| FE | PIT の分散 = 1/12 | `(分散 − 1/12) / se` | 両側 bootstrap-t | 8 |
| FF(D4 の max-t) | 全群で被覆率が等しい | `T`(D4) | bootstrap の max-t(それ自体が族ごとの誤り率を制御) | 各(h、期間、群の種類)ごとに 1 |

- 週ブロック bootstrap: F1 と同じ ISO 週の分割、10,000 回、seed を固定。同一の resample を全ホライズン・全診断で共有する。F1 と同じく、隣接する週をまたぐ依存は保たない。
- 90% 区間の被覆率の不足が名目から **3 パーセントポイント以上**のものを、報告時の**注目基準**とする。統計的有意性や実用上の重要性を保証する閾値ではなく、判定の閾値でもない。
- 結果は、「どの仮説と整合するか」と「整合しないか」を、ホライズン・期間別の表で報告する。複数の仮説が同時に整合的であり得る。

## 6. 実装前のゲートと検証
実行の順序(どれかが失敗すれば診断本体を実行しない):
1. 入力ハッシュの照合(58 ファイルと生データ)。
2. 原点集合、実現値(`y = log C1 − log C0`)、バケット割り当てが、保存済みのスコアと一致することの確認(P1 で独立に確認した原点集合を使う)。
3. D2 の被覆率と、D3 以降で使う原点・予測分位点の整合性の確認: DDM の全原点で、アンサンブルから得た予測分位点と `y` による `hit*`・`pit_lo`・`pit_w` が、保存済みの値と一致すること(P1 の V9c と同じ原点・同じ式)。
4. **合成データによる単体テスト(必須)**: 診断コードを実データに適用する前に、次のケースで、診断が期待どおりの兆候を示し、誤った結論を出さないことを確認する。
   - 既知の分散不足(幅を一律に縮める): `k_c > 1`、両側対称の外れ。
   - 既知の中心のずれ(位置を一律にずらす): 符号の偏りと非対称な外れ。
   - 既知の裾の薄さ(裾だけを薄くする): 中心部の較正は保たれ、外側の分位点で超過率の差。
   - **中心のずれだけで U 字型の PIT が現れる条件**: 局面ごとに正負の中心のずれ(幅は正しい)を入れ、全体の PIT が U 字になっても、D4 の群別の診断が群ごとのずれの符号を示し、H1(分散不足)を単独で判定しないこと(D1 だけで H1 を誤判定しない)。
   - 較正済みの分布: すべての診断が名目値の付近で、検定の第一種の誤り率が名目に近いこと。
   - 乱択 PIT のタイ: 変動が別の列に出ること。
5. 実行コミットを記録し(p2_diagnostics に未コミットの変更がないことを確認)、出力は新しい作業ディレクトリに書く。既存成果物は変更しない。

診断コードは `backend/research/p2_diagnostics/` に置く。P1 の独立ライブラリ(`p1_verification/p1_lib.py`)の原点集合、ターゲット、バケット、分位点、点スコア関数は再利用してよい。F1 の本番の計算関数は使わない。
