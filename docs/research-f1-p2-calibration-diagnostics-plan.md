## 2A. 主診断の帰無仮説(v0.6 で明示)
予測分布の較正には、区別すべき 2 つの帰無仮説がある。バケット `b` の理想の予測分布を `F_b`、保存済みの有限アンサンブル(M = 1000 × 3 seed)の経験分布を `F̂_b` とする。
- **帰無 A(理想分布に対する較正)**: `y | b ~ F_b`。有限アンサンブルの誤差は、`F_b` を近似するときのモンテカルロ誤差。
- **帰無 B(保存済み予測に対する較正)**: `y | b ~ F̂_b`。保存済みのアンサンブルそのものを予測分布として評価する。アンサンブルの誤差は、雑音ではなく、実際に使われた予測分布の較正不足の一部。
**P2 の主診断は B の観点**(F1 で評価したのは保存済みの DDM 予測アンサンブルであり、F1 との連続性を保つ)。したがって、D1〜D8 の記述統計・効果量・図・信頼区間を中心に報告し、検定は補助とする。検定の p 値は、アンサンブルの標本誤差(同一バケットの原点で共有され、週ブロック bootstrap では捕捉されない)により名目より小さくなり得るため、**解釈に注意が必要**(検定の扱いは §6B の結果で決める)。**3 つの区別(混同しない)**:
- **科学的評価対象**: 保存済み DDM アンサンブルの較正(B の観点)。
- **検定の帰無値**: 現行の「被覆率 = 名目水準」などの名目値を使うか、経験分布の離散性・有限性を考慮した帰無値を使うかは**未決定**。§6B の結果を踏まえて別途決める。現行の名目値を変更する場合は、v0.7 として事前承認を受ける。
- **記述統計**: 実際の被覆率、PIT、`k_c` などは、帰無値の選択とは独立に常に報告する。
アンサンブルの標本誤差の大きさの目安として、seed 別(独立な 3 アンサンブル)の被覆率・`k_c` の範囲を報告する(D2、D3 に既に含む)。

## 2B. 評価の主従関係(v0.7 で固定)
- **主**: 記述統計・効果量・信頼区間(被覆率、外れ率、PIT、`k_c`、`P(y > m)`、超過率の差、群別の値、seed 別の範囲)。H1〜H5 の判断は、効果量、信頼区間、局面別の整合性、seed 間のばらつきを中心に行う。**有意性だけでは結論を出さない**。
- **補助**: p 値と Holm 調整後の p 値(探索的な補助指標)。
- **検定の帰無値**: 現行の名目値(被覆率 = c、`P(y > m)` = 0.5、PIT の分散 = 1/12 など)を維持する。ゲート 4b の B 条件の帰無値は名目値とほぼ一致した(FA90 0.9000、FC 0.5000、FE 0.08333)。ただし、保存済み経験分布に対する厳密な条件付き較正の検定とは呼ばない(有限アンサンブルの分位点補間や境界処理により、期待被覆率が名目値と一致しない場合があり、その差は必要に応じて併記する)。
- 週ブロック bootstrap は信頼区間の算出方法として維持する。ただし、有限アンサンブルの標本誤差(同一バケットの原点で共有)と、隣接する週をまたぐ依存を保たないという限界があり、**信頼区間が無条件に妥当と保証されたわけではない**。
- 新しい検定方式は導入しない。診断結果を見た後で、検定方式、帰無値、判定基準を変更しない。

## 5. 診断
### 5.1 診断項目
対象: DDM(3 seed の統合と seed 別)、h = 1、4、12、24、検証期間と final 期間(D5 は推定期間)。統計モデル(B0、B4、B7N、B8)との比較は、保存済みの PIT・hit・pinball のみ(D1、D2、D6 の一部)。B8 は DDM と同じ局面情報(ATR バケット)を使う対照。
D3 以降で使う DDM の予測分位点は、バケットごとの保存済みアンサンブルから、線形補間の分位点(P1 と同じ定義)で得る。

**D1 PIT の要約(整合的な兆候のみ)**
- PIT の平均、分散(一様分布なら 1/12)、20 ビンのヒストグラム、両端 5% の質量、KS 距離。
- ヒストグラムには、一様分布(各ビン 0.05)からの偏差と、**週ブロック bootstrap による各ビンの 95% 帯**を示す。タイの乱択の変動は別の列。
- 位置づけ: PIT の形状は H1(U 字・分散が 1/12 を上回る)や H2(平均が 0.5 からずれる)と**整合的な兆候**であって、十分条件ではない。局面によって中心が正負にずれると、中心のずれだけで全体の PIT が U 字になり得る。D1 だけで H1 や H2 を判断しない。

**D2 区間被覆率と非対称性**
- 50/80/90/95% の被覆率(F1 と同じ、境界を含む区間)。下側の外れ率(y < 下限)と上側の外れ率(y > 上限)を別々に報告する。
- 予測中央値に対する実現値の符号の偏り: `P(y > 予測中央値)`(0.5 が較正)。
- 位置づけ: H1 は「両側の外れ率がともに名目値を上回り、D3 の幅の較正係数が 1 を超える」ときの整合的な兆候。H2 は「外れ率の上下非対称、または符号の偏りが 0.5 からずれる」ときの整合的な兆候。

**D3 幅と中心の診断(分位点ベースを主、正規基準を参考)**
- 予測中央値 `m_i` と、水準 c ∈ {50, 80, 90, 95}% の予測区間の下限 `lo_i`、上限 `hi_i`(アンサンブルからの線形補間の分位点)を使う。原点ごとの**正規化した超過量**を次のとおり定義する。
  - `y_i > m_i` のとき `u_i = (y_i − m_i) / (hi_i − m_i)`(上側)。
  - `y_i < m_i` のとき `u_i = (m_i − y_i) / (m_i − lo_i)`(下側)。
  - `y_i = m_i` のとき `u_i = 0`(どちらの側にも数えない。件数を記録する)。
- **区間幅の較正係数 `k_c`**: プールした `u_i` の c 分位点(線形補間)。`k_c = 1` なら、予測区間の幅に対する実現値の乖離が名目どおり。`k_c > 1` は予測区間が実現値の乖離に対して狭いことを示す。
- **側別の係数 `k_c^上`、`k_c^下`**: 中央値より上(下)の観測を**条件とした** `u_i` の c 分位点(上側は `y_i > m_i` の `u_i`、下側は `y_i < m_i` の `u_i`)。較正されていれば、`P(y ≤ hi | y > m) = ((1+c)/2 − 1/2) / (1/2) = c` なので、どちらも 1 になる。各側の観測数が少ない(100 未満)セルは、`k_c^上`、`k_c^下` を報告のみとし、検定の対象にしない。
- **分母が 0 以下の場合**(`hi_i − m_i ≤ 0` または `m_i − lo_i ≤ 0`、アンサンブルが退化している場合): その原点・その側の `u_i` は定義しない(`u_i = +∞` とも `0` とも扱わず、除外)。除外した件数を記録し、(セル × 水準 × 側) の除外が観測数の 0.1% を超えたセルは、`k_c` を「推定不能」として報告する。
- 解釈の位置づけ: **`k_c` は区間幅の較正係数であって、分散の推定量ではない**。`k_c > 1` は、分散不足だけでなく、中心のずれや局面の混合でも生じる。H1 は、`k_c`、D2 の上下の外れ率、D4 の群内の中心の偏り(`P(y > m)` の群別の値)を**合わせた探索的な解釈**であり、`k_c` 単独では判断しない。
- 中心の診断: D2 の `P(y > m)` と、PIT の中央値。
- 参考指標(正規基準): `z = (y − m) / (IQR / 1.349)` の平均と MAD ベースの尺度。DDM の予測分布が非正規の場合、IQR/1.349 を予測標準偏差と解釈できないため、**主診断には使わず、参考として併記する**。
- 局面ごとの中心のずれが打ち消し合う場合、プールすると対称な超過に見える。H1 は、`k_c > 1` が D4 の群の内側でも一貫した符号で保たれるときに限り、整合的と扱う。
- 離散的な予測分布(価格刻みなどでタイが生じる場合)では、較正されていても `k_c = 1` が厳密には成立しないことがある。この影響を合成データテスト(§6)で確認し、実データの報告では、タイの割合を併記する。

**D4 局面・時間依存**
- 群の定義(事前固定): ATR バケット 0〜19 を 5 群(各 4 バケット)にまとめた群、UTC の時間帯 3 区分(00–08、08–16、16–24)、月。
- 各群で、90% 区間の被覆率 `g_g` と `k_90`(上側・下側別を含む)、`P(y > m)` を報告する。検定の対象は 90% 区間の被覆率のみ(`k_90` と `P(y > m)` は記述)。
- 検定の規則(事前固定):
  - **事前指定の対比**: ATR の最高群 − 最低群の 90% 被覆率の差(1 つ)。時間帯の 3 区分間は max-t の対象。
  - **全群の最大差統計量(max-t bootstrap)**: プールした被覆率を `g`、各群の被覆率を `g_g` として `T = max_g |g_g − g| / se_g`。
  - **標準誤差 `se_g` は、元データの週ブロック bootstrap(10,000 回)から一度だけ推定した `g_g − g` の標準偏差とし、以降は固定する**(各 bootstrap 標本の中で標準誤差を再推定する二段階の bootstrap は用いない)。
  - null 分布: 各 bootstrap 標本で `T* = max_g |(g*_g − g*) − (g_g − g)| / se_g`(固定した `se_g` を使う)。`p = (1 + #{T* ≥ T}) / (B + 1)`、B = 10,000(`≥` の比較は絶対誤差 1e-12 の許容を付ける)。
  - **検定対象群の固定(max-t の計算の前に確定)**: 次の順で対象群の集合 `G*` を一度だけ決め、以降は変えない。(i) 観測原点数が 100 以上の群。(ii) 元データの週ブロック bootstrap(10,000 回、検定と同じ標本)で、`n*_g = 0` となる標本の割合が 5% 以下の群(5% を超える群は記述統計のみ)。(iii) `se_g > 0` の群(`se_g = 0` の群は「判定不能」として記録し対象から除く)。`|G*| < 2` なら max-t は実行せず「判定不能」とする。
  - **bootstrap 標本で `G*` のいずれかの群が欠ける場合**(`n*_g = 0` で `g*_g` が定義できない): 群を動的に減らさず、その標本を**無効**として `T*` の分布から除き、無効率を記録する。無効率が 5% を超える場合は「判定不能」とする。有効標本数を `B_v` として `p = (1 + #{T* ≥ T}) / (B_v + 1)`。観測統計量 `T` と `T*` は、常に同じ集合 `G*` に基づく。
  - 最小セルのサイズは 100 原点。満たさない群は報告のみで検定から除く(上記 (i))。
- **交絡の注意**: ATR バケット、時間帯、月は互いに独立ではない(高 ATR は特定の時間帯や月に偏る)。群別の結果だけから、ATR 依存、時間帯依存、時間ドリフトを切り分けず、因果的な解釈はしない。ATR × 時間帯の 2 元表(90% 被覆率と原点数)を、記述として併記する。

**D5 標本内の診断(解釈を限定)**
- 推定期間の原点で、同じ写像・アンサンブルの被覆率、`k_c`、D2 の非対称性を計算する。
- **推定窓との重複関係を記録する**: 写像の構築に使った窓(各バケット最大 300 窓、seed 20261117)と、推定期間の原点の関係。本番のサンプリング手順を参照用に再現できる範囲で、(a) 写像に使われた窓の原点、(b) 推定期間で写像に使われなかった原点、を分けて報告する(再現できない場合は、報告できない旨と理由を記録する)。
- 解釈の限定:
  - 推定期間でも不足: 標本内ですでに較正不足が観測される。
  - 推定期間は良好で評価期間は不足: 標本内適合と標本外較正に差がある。
  - いずれの場合も、初期状態、写像の推定、期間ドリフトのどれが原因かは確定しない。標本内の被覆率は、独立な汎化性能の評価ではない。
  - **写像に使われなかった推定期間の原点も、同じ推定期間に属し、写像の推定に使った窓と時間的に近接・重なり得るため、完全に独立な評価集合とは扱わない**(報告ではこの注意を明記する)。

**D6 裾の診断**
- 分位点 1、5、25、75、95、99% ごとに、**観測された超過率と名目の超過率の差(パーセントポイント)**とその週ブロック bootstrap による不確かさを報告する(相対誤差の比較は用いない)。pinball 損失も併記する。
- D3 の `z` の尖度は参考。
- H3 は、中心部(25、75%)と裾(1、5、95、99%)の偏差パターンを総合的に解釈する探索的診断とし、単一の比較では確定しない。

**D7 ホライズン構造(記述的)**: h ごとの `k_c`、予測区間の幅の `sqrt(h)` スケーリングとの比較。h=4 が最悪である理由の記述。
**D8 数値安定性**: §4 の等価な式による、タイ件数と被覆率の変化の報告のみ。

### 5.2 検定の定義と多重比較(事前固定)
すべて探索的。**主な報告は効果量と 95% の週ブロック bootstrap 信頼区間**(§2B)とし、p 値と Holm 調整後の p 値は探索的な補助指標として併記する(v0.7 での位置づけの変更。v0.6.1 以前の「主な報告は Holm 調整後の p 値」を置き換える)。調整後の p 値や信頼区間だけで原因を確定しない。

**検定の方法(全ファミリー共通)**: 推定量 `θ̂`(被覆率、外れ率の差、`P(y > m)`、超過率、PIT の分散)について、帰無値 `θ0` に対する両側検定を、**元データの週ブロック bootstrap(10,000 回)の中心化した分布**で行う。
- `se = SD(θ*)`(元データの bootstrap から一度だけ推定して固定)。報告する統計量は `t = (θ̂ − θ0) / se`。
- `p = (1 + #{|θ* − θ̂| ≥ |θ̂ − θ0|}) / (B + 1)`、B = 10,000(有限回の再標本化を考慮し、`p ≥ 1/10,001`。比較は絶対誤差 1e-12 の許容付き。値が離散的で同値が多数あっても、`≥` の定義で保守的に数える)。
- 各 bootstrap 標本の中で標準誤差を再推定する二段階の bootstrap(nested bootstrap-t)は使わない。
- `se = 0`(bootstrap の分布が退化)の場合は検定を実行せず、**「判定不能」**とする(有意でも非有意でもない)。
- 標本内の分母が定義できない replicate(群の欠落など)は、その replicate を除外し、除外割合を記録する。除外が 5% を超える場合は「判定不能」。
- **Holm の検定数は、計画した検定の総数**(判定不能のセルも数える。保守的な扱い)。判定不能のセルは、調整後 p 値を `NA` とし、効果量(`θ̂`)のみ報告する。

| ファミリー | 帰無仮説 | 推定量 θ̂ | 検定数(Holm の単位) |
|---|---|---|---|
| FA(水準 c ごと、4 ファミリー) | 被覆率 = c | 被覆率 | 8(h × 期間) |
| FB | 90% 区間の下側の外れ率 = 上側の外れ率 | 外れ率の差 | 8 |
| FC | `P(y > 予測中央値)` = 0.5 | `P(y > m)` | 8 |
| FD(分位点 q ごと、6 ファミリー) | 超過率 = 名目 q | 超過率 | 8 |
| FE | PIT の分散 = 1/12 | PIT の分散 | 8 |
| FF(D4 の max-t) | 全群で被覆率が等しい | `T`(D4 の定義) | 各(h、期間、群の種類)ごとに 1(max-t が族ごとの誤り率を制御するため Holm は適用しない) |

- 週ブロック bootstrap: F1 と同じ ISO 週の分割、seed を固定。同一の resample を全ホライズン・全診断で共有する。F1 と同じく、隣接する週をまたぐ依存は保たない。
- 90% 区間の被覆率の不足が名目から **3 パーセントポイント以上**のものを、報告時の**注目基準**とする。統計的有意性や実用上の重要性を保証する閾値ではなく、判定の閾値でもない。
- 結果は、「どの仮説と整合するか」と「整合しないか」を、ホライズン・期間別の表で報告する。複数の仮説が同時に整合的であり得る。

| A | 理論 t(5) | バケット内で共有、M = 1000(v0.5 のケース 1 と同一の seed `[20261202, 1, 試行]`) | 名目 | 1000 | 既存結果(0.088、0.067、0.081、0.081、0.084)が**完全に再現**されること(再現できなければ、実装の問題として調査し、先へ進まない) |
| B | 各バケットの保存アンサンブル `F̂_b` から一様に 1 標本を抽出(実現値は常にアンサンブルの値でタイが生じる) | バケット内で共有、M = 1000(各試行で固定) | **`F̂_b` に対する厳密値**(下記) | 1000 | 保存済み予測に対する帰無条件の下での第一種の誤り |
| C | 理論 t(5) | **原点ごとに独立に生成**、M = 1000(共有なし) | 名目 | 1000 | 共有誤差の寄与 |
| D | 理論 t(5) | バケット内で共有、M = 4000 と 20000(2 水準) | 名目 | 1000 | 有限 M の寄与 |
| E | 条件 A と同じデータ(同じ seed) | 同上 | 名目 | **10000**(実データと同じ) | B_test の寄与(実データの設定での第一種の誤り) |

条件 B の帰無値(定義): 検定が実際に推定する統計量の母数として定義する。バケット `b` の保存アンサンブルの M 個の値(タイを含む)`v_1..v_M` について、実現値 `y` を `{v_k}` から一様に抽出するとき、`F̂_b` に対する各統計量の期待値を**全列挙**(k = 1..M のすべて)で計算し、原点数で重み付け平均して θ0_B とする。使う定義は本番コードと同一: 分位点は線形補間(`np.quantile`)、区間は境界を含む `lo ≤ y ≤ hi`、`y > m`、`y < 分位点`。
- FA(c): `mean_k [lo_c ≤ v_k ≤ hi_c]`。FB: `mean_k([v_k < lo_90] − [v_k > hi_90])`。FC: `mean_k [v_k > m]`。FD: `mean_k [v_k < q 分位点]`。
- FE: 検定の統計量は `mean(E2) − mean(E1)²`(`pit_moments`。E1、E2 は、各原点のタイ区間内の一様乱択に関する PIT の 1 次・2 次の条件付き期待値)で、これは「バケット混合のタイ乱択 PIT の母分散」の推定量である。条件 B で、同じ M 個の標本から一様に実現値を選びタイ区間内で一様乱択すると、乱択 PIT は厳密に一様で、母分散は 1/12 になる(中点を使う非乱択 PIT の分散は別の量で、この統計量とは異なる)。θ0_B(FE)も、同じ全列挙で `mean_k E2(v_k) − (mean_k E1(v_k))²` を計算して求め、1/12 との一致(絶対誤差 1e-12)を確認する。「離散一様の分散」とだけは定義しない。
- **全列挙の独立照合テスト(実行前の必須条件)**: 小さな合成アンサンブル(M = 50、3 バケット、タイを含む場合と含まない場合)で、(i) 上の θ0_B の計算と、(ii) P1 の独立実装(`p1_lib.point_scores`、`linear_quantile`、`searchsorted`)による素朴な二重ループの全列挙とを比較し、FA(50/80/90/95)、FB、FC、FD(各 q)、FE のすべてで絶対誤差 1e-12 以内で一致すること。不一致なら実装を調査し、条件 B を実行しない。
- 条件 B の結果は、名目の θ0 でも併記する(経験分布の離散性と名目値のずれの大きさの記録。合否には使わない)。

**報告する主要な比較結果(合否より優先)**: 各条件・各検定の棄却率とその Clopper–Pearson 95% 信頼区間、および**条件間の棄却率の差とその 95% 信頼区間**。条件 A に対する C、D(2 水準)、E の差は、**同じ実現値の乱数系列(条件 A と同じ `y`)と同じデータの対応比較**とし(条件 C・D は、実現値を条件 A の試行と同一にし、アンサンブルだけを差し替える)、対応のある 2 値の差の信頼区間(不一致の件数 b、c から `(b − c)/n ± 1.96·sqrt((b + c) − (b − c)²/n)/n`)と不一致件数を報告する。条件 B は実現値の生成法が異なるため対応比較はせず、独立な 2 標本の差(Newcombe の信頼区間)を参考として併記する。0.08 を境にした二値判定は併記するが、差の信頼区間が 0 を含む比較(例: A が 0.081、C が 0.079)は「ほぼ同程度」と記述する。

**事前固定した判定規則(合否ではなく、整合的な証拠の整理。因果の断定はしない)**: 各条件で FA90、FB、FC、FE のすべての棄却率が 0.08 以下なら「設定した基準内」とする(名目 5% の第一種の誤りが保証されたことを意味しない)。
1. 条件 A が再現されない場合: 実装を調査し、先へ進まない。
2. 条件 B が基準内: 「経験分布を条件とした帰無仮説の下では、棄却率が事前基準内に収まった。A との差は、理想分布と経験分布の違いが過剰棄却に寄与するという仮説と整合する。ただし、寄与の大きさや唯一の原因であることは確定しない」と記述する。「検定は有効」とは書かない。
3. 条件 C が基準内(かつ条件 A は基準外): 共有構造の寄与と整合する(原点ごとに生成すると標本誤差の相関構造も変わる点に注意)。
4. 条件 D の M = 20000 が基準内(かつ条件 A は基準外): 有限 M の影響と整合する(M の増加に伴い、分位点の近似やタイの発生も変わる点に注意)。
5. 条件 E が基準外: B_test = 10000 に増やしても基準外であることを示す。週ブロック bootstrap 自体が原因とは確定せず、調査対象とする。
6. 複数が成り立つ場合は、複数の要因が寄与し得ると報告し、寄与の割り当ては断定しない。
7. B・C・D のどれも基準内にならない場合: 検定方式の見直し(v0.7)を提案する。
この整理の結果に基づく、実データで採用する検定の帰無値や検定方式の選択(変更するか否か、内容)は、結果を報告したうえで別途承認を受ける。承認前に、新しい検定方式の実装も、実データの D1〜D8 の実行もしない。

## 9. 限界
- 診断は探索的で、final 期間は部分的に既知。
- DDM の予測分布は初期状態から始めたパスの分布(F1 の解釈上の制限 8)。D5 はこの影響の一部を示唆するが、切り分けは P3 の課題。

- 週ブロック bootstrap は、隣接する週をまたぐ依存を保たない。
- ATR、時間帯、月の交絡のため、局面別の結果から因果的な原因は特定できない。
- 検定の第一種の誤りは、合成データ(ケース 1、ゲート 4b)で名目 5% を超えた(最大 0.088)。原因は、アンサンブルの標本誤差の共有、理想分布と経験分布の違い、その他の要因と整合的だが、確定していない。p 値は探索的な補助指標としてのみ扱い、信頼区間の妥当性も保証されない。
