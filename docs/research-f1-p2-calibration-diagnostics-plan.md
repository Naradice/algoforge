# F1 後続 P2: DDM の被覆率・PIT の較正診断 — 実験計画(草案 v0.1、未承認)

位置づけ: F1(#889、inconclusive)の結果を受けた新しい研究課題。F1 の結果、判定、#889・#937・#938 は変更しない。P1(F1 の監査補強)とは別ノードで管理する。
実行は、この計画のレビューと承認の後。承認前に何も実行しない。

## 1. 問い
F1 の final 期間で、DDM の予測区間の実測被覆率は名目値を下回った(h=4 の 90% 区間で 0.808、50% 区間は h=1〜24 で 0.379〜0.422)。この較正不足は、次のどれによるか。
- **H1 分散不足**: 予測分布の幅が全体に狭い。
- **H2 中心のずれ**: 予測分布の位置が系統的にずれている。
- **H3 裾の形状**: 中心部の較正は近いが、外側(95%、99%)の裾が薄い。
- **H4 局面・時間依存**: 局面(ATR バケット、時間帯、月)によって較正が変わる。あるいは写像の推定期間(2016-08〜2020-08)と評価期間の間にドリフトがある。
- **H5 構造的な要因**: 推定期間の窓に対する、同じ写像の被覆率(標本内)でも名目値を下回る。初期状態から始めたパス(F1 の解釈上の制限 8)や、写像の構成に由来する可能性がある。

これらは排他的ではない。目的は、較正不足の主な形(どの方向にどれだけ)を記述し、次の実験(P3 の burn-in 感度分析の設計、再較正の要否)の入力にすること。**原因の確定的な主張や、DDM の改良は目的としない。**

## 2. 位置づけと制約
- 探索的な診断である。仮説は事前に固定するが、結果は確証的な主張にしない。final 期間は部分的に既知で、F1 の判定に使った期間であり、診断の結果を見て DDM や写像を変更する場合は、別の期間か別の評価で確認する(本計画の範囲外)。
- DDM のパラメータ、写像、アンサンブルは変更しない。新しい予測の生成・シミュレーションも行わない(既存のアンサンブルを使う)。
- 事後的な再較正(分散の拡大など)は本計画の範囲外。検討する場合は、検証期間で較正し final 期間で評価する別計画とする。
- P1 で発見した、実現値の算出式による PIT のタイ判定の違いに対処する(§4)。

## 4. 実現値とタイ判定の仕様(P1 の知見の反映)
- 実現値の算出式を固定する: **`y = log C1 − log C0`**(F1 の本番と同じ。`log(C1/C0)` ではない)。本計画のすべての診断(被覆率、PIT、分位損失)でこの式を使う。
- 厳密な等値判定が必要な量(`pit_w`、`hit` の境界)は、保存済みの `scores_*.npz` の値をそのまま使うか、同じ式の `y` で再計算する。
- 数学的に等価な式 `y = log(C1/C0)` による結果は、**数値安定性の感度分析として別に記録**する(タイの件数、被覆率の変化)。診断の結論には使わない。
- PIT の乱択(`pit = pit_lo + u·pit_w`)は、固定 seed で 100 回繰り返した平均と散らばりを報告し、決定的な範囲 `[pit_lo, pit_lo + pit_w]` による境界も併記する。タイの割合(DDM は約 0.3%)を明記する。
- 近似的なタイ判定は導入しない。

## 5. 診断項目と判断規則(結果を見る前に固定)
対象: DDM(3 seed の統合と seed 別)、h = 1、4、12、24、検証期間と final 期間。比較として、統計モデル B0、B7N、B8(ATR バケットの経験分布。DDM と同じ局面情報を使う対照)と B4 は、保存済みの PIT・hit・pinball のみで比較する(D1、D2)。
区間推定は、F1 と同じ週ブロック bootstrap(同じ ISO 週の分割、10,000 回、seed を固定)で行う。

| ID | 診断 | 内容 | 対応する仮説と判断規則 |
|---|---|---|---|
| D1 | PIT の要約 | PIT の平均(0.5 からのずれ)、分散(一様分布なら 1/12)、20 ビンのヒストグラム、両端 5% の質量、KS 距離 | H1: PIT 分散が 1/12 の CI を上回る(U 字)。H2: 平均が 0.5 の CI の外 |
| D2 | 区間被覆率 | 50/80/90/95% の被覆率と CI、下側・上側の外れ率を別々に | H1: 下側・上側とも名目より多い(対称)。H2: 片側に偏る(非対称) |
| D3 | 位置と尺度の分解 | 標準化誤差 `z = (y − 予測中央値) / (予測 IQR / 1.349)` の平均(位置)と MAD ベースの尺度。DDM はバケットごとのアンサンブルから | H1: 尺度の比が 1 より有意に大きい。H2: z の平均が 0 から有意にずれる |
| D4 | 局面・時間依存 | ATR バケットを 5 群にまとめた群別、時間帯(UTC の 6 区分)別、月別の被覆率(90%)と尺度の比。群間差の検定(週ブロック bootstrap) | H4: 群間の尺度の比の最大と最小の差の CI が 0 を含まない |
| D5 | 標本内の被覆率 | 推定期間の原点で、同じ写像・アンサンブルの被覆率(H5 の検査)。写像は推定期間の窓(各バケット最大 300 窓)から作られている | H5: 推定期間でも 90% の被覆率が名目値の CI を下回る。H4: 推定期間は名目値内で、評価期間のみ下回る |
| D6 | 裾の形状 | 1/5/95/99% 分位点の超過率と pinball 損失。D3 の z の尖度 | H3: 99%/95% の外れ率が中心部(50%)より名目値から相対的に大きく外れる |
| D7 | ホライズン構造 | h ごとの尺度の比、`sqrt(h)` スケーリングとの比較。h=4 が最悪である理由の記述 | 記述的(判断規則なし) |
| D8 | 数値安定性 | §4 の等価な式による、タイ件数と被覆率の変化 | 変化があれば報告のみ |

**判断規則の共通事項**: 「有意」は、週ブロック bootstrap の 95% CI に基づく(診断項目ごとの Holm 調整を、ファミリー(D1〜D6 内のホライズン × 期間)ごとに適用し、調整後の判断を主とする)。効果量の目安として、90% 区間の被覆率の不足が名目から 3 パーセントポイント以上の場合を「実質的」と呼ぶ(F1 の ±2% 規則とは別の、診断用の目安であり、判定の閾値ではない)。
仮説は排他的でないため、複数が同時に支持され得る。結果は「どの仮説と整合するか」と「整合しないか」を、ホライズン・期間別の表で報告する。

- 診断は探索的で、final 期間は部分的に既知。
