## 1. 問い

- **H2 中心のずれ**: 予測分布の位置が系統的にずれている。

## 5. 診断
### 5.1 診断項目
対象: DDM(3 seed の統合と seed 別)、h = 1、4、12、24、検証期間と final 期間(D5 は推定期間)。統計モデル(B0、B4、B7N、B8)との比較は、保存済みの PIT・hit・pinball のみ(D1、D2、D6 の一部)。B8 は DDM と同じ局面情報(ATR バケット)を使う対照。
D3 以降で使う DDM の予測分位点は、バケットごとの保存済みアンサンブルから、線形補間の分位点(P1 と同じ定義)で得る。

**D1 PIT の要約(整合的な兆候のみ)**
- PIT の平均、分散(一様分布なら 1/12)、20 ビンのヒストグラム、両端 5% の質量、KS 距離。
- ヒストグラムには、一様分布(各ビン 0.05)からの偏差と、**週ブロック bootstrap による各ビンの 95% 帯**を示す。タイの乱択の変動は別の列。
- 位置づけ: PIT の形状は H1(U 字・分散が 1/12 を上回る)や H2(平均が 0.5 からずれる)と**整合的な兆候**であって、十分条件ではない。局面によって中心が正負にずれると、中心のずれだけで全体の PIT が U 字になり得る。D1 だけで H1 や H2 を判断しない。

**D2 区間被覆率と非対称性**
- 50/80/90/95% の被覆率(F1 と同じ、境界を含む区間)。下側の外れ率(y < 下限)と上側の外れ率(y > 上限)を別々に報告する。
- 予測中央値に対する実現値の符号の偏り: `P(y > 予測中央値)`(0.5 が較正)。
- 位置づけ: H1 は「両側の外れ率がともに名目値を上回り、D3 の幅の較正係数が 1 を超える」ときの整合的な兆候。H2 は「外れ率の上下非対称、または符号の偏りが 0.5 からずれる」ときの整合的な兆候。

**D3 幅と中心の診断(分位点ベースを主、正規基準を参考)**
- 予測中央値 `m_i` と、水準 c ∈ {50, 80, 90, 95}% の予測区間の下限 `lo_i`、上限 `hi_i`(アンサンブルからの線形補間の分位点)を使う。原点ごとの**正規化した超過量**を次のとおり定義する。
  - `y_i > m_i` のとき `u_i = (y_i − m_i) / (hi_i − m_i)`(上側)。
  - `y_i < m_i` のとき `u_i = (m_i − y_i) / (m_i − lo_i)`(下側)。
  - `y_i = m_i` のとき `u_i = 0`(どちらの側にも数えない。件数を記録する)。
- **区間幅の較正係数 `k_c`**: プールした `u_i` の c 分位点(線形補間)。`k_c = 1` なら、予測区間の幅に対する実現値の乖離が名目どおり。`k_c > 1` は予測区間が実現値の乖離に対して狭いことを示す。
- **側別の係数 `k_c^上`、`k_c^下`**: 中央値より上(下)の観測を**条件とした** `u_i` の c 分位点(上側は `y_i > m_i` の `u_i`、下側は `y_i < m_i` の `u_i`)。較正されていれば、`P(y ≤ hi | y > m) = ((1+c)/2 − 1/2) / (1/2) = c` なので、どちらも 1 になる。各側の観測数が少ない(100 未満)セルは、`k_c^上`、`k_c^下` を報告のみとし、検定の対象にしない。
- **分母が 0 以下の場合**(`hi_i − m_i ≤ 0` または `m_i − lo_i ≤ 0`、アンサンブルが退化している場合): その原点・その側の `u_i` は定義しない(`u_i = +∞` とも `0` とも扱わず、除外)。除外した件数を記録し、(セル × 水準 × 側) の除外が観測数の 0.1% を超えたセルは、`k_c` を「推定不能」として報告する。
- 解釈の位置づけ: **`k_c` は区間幅の較正係数であって、分散の推定量ではない**。`k_c > 1` は、分散不足だけでなく、中心のずれや局面の混合でも生じる。H1 は、`k_c`、D2 の上下の外れ率、D4 の群内の中心の偏り(`P(y > m)` の群別の値)を**合わせた探索的な解釈**であり、`k_c` 単独では判断しない。
- 中心の診断: D2 の `P(y > m)` と、PIT の中央値。
- 参考指標(正規基準): `z = (y − m) / (IQR / 1.349)` の平均と MAD ベースの尺度。DDM の予測分布が非正規の場合、IQR/1.349 を予測標準偏差と解釈できないため、**主診断には使わず、参考として併記する**。
- 局面ごとの中心のずれが打ち消し合う場合、プールすると対称な超過に見える。H1 は、`k_c > 1` が D4 の群の内側でも一貫した符号で保たれるときに限り、整合的と扱う。
- 離散的な予測分布(価格刻みなどでタイが生じる場合)では、較正されていても `k_c = 1` が厳密には成立しないことがある。この影響を合成データテスト(§6)で確認し、実データの報告では、タイの割合を併記する。

**D4 局面・時間依存**
- 群の定義(事前固定): ATR バケット 0〜19 を 5 群(各 4 バケット)にまとめた群、UTC の時間帯 3 区分(00–08、08–16、16–24)、月。
- 各群で、90% 区間の被覆率 `g_g` と `k_90`(上側・下側別を含む)、`P(y > m)` を報告する。検定の対象は 90% 区間の被覆率のみ(`k_90` と `P(y > m)` は記述)。
- 検定の規則(事前固定):
  - **事前指定の対比**: ATR の最高群 − 最低群の 90% 被覆率の差(1 つ)。時間帯の 3 区分間は max-t の対象。
  - **全群の最大差統計量(max-t bootstrap)**: プールした被覆率を `g`、各群の被覆率を `g_g` として `T = max_g |g_g − g| / se_g`。
  - **標準誤差 `se_g` は、元データの週ブロック bootstrap(10,000 回)から一度だけ推定した `g_g − g` の標準偏差とし、以降は固定する**(各 bootstrap 標本の中で標準誤差を再推定する二段階の bootstrap は用いない)。
  - null 分布: 各 bootstrap 標本で `T* = max_g |(g*_g − g*) − (g_g − g)| / se_g`(固定した `se_g` を使う)。`p = (1 + #{T* ≥ T}) / (B + 1)`、B = 10,000(`≥` の比較は絶対誤差 1e-12 の許容を付ける)。
  - **検定対象群の固定(max-t の計算の前に確定)**: 次の順で対象群の集合 `G*` を一度だけ決め、以降は変えない。(i) 観測原点数が 100 以上の群。(ii) 元データの週ブロック bootstrap(10,000 回、検定と同じ標本)で、`n*_g = 0` となる標本の割合が 5% 以下の群(5% を超える群は記述統計のみ)。(iii) `se_g > 0` の群(`se_g = 0` の群は「判定不能」として記録し対象から除く)。`|G*| < 2` なら max-t は実行せず「判定不能」とする。
  - **bootstrap 標本で `G*` のいずれかの群が欠ける場合**(`n*_g = 0` で `g*_g` が定義できない): 群を動的に減らさず、その標本を**無効**として `T*` の分布から除き、無効率を記録する。無効率が 5% を超える場合は「判定不能」とする。有効標本数を `B_v` として `p = (1 + #{T* ≥ T}) / (B_v + 1)`。観測統計量 `T` と `T*` は、常に同じ集合 `G*` に基づく。
  - 最小セルのサイズは 100 原点。満たさない群は報告のみで検定から除く(上記 (i))。
- **交絡の注意**: ATR バケット、時間帯、月は互いに独立ではない(高 ATR は特定の時間帯や月に偏る)。群別の結果だけから、ATR 依存、時間帯依存、時間ドリフトを切り分けず、因果的な解釈はしない。ATR × 時間帯の 2 元表(90% 被覆率と原点数)を、記述として併記する。

### 5.2 検定の定義と多重比較(事前固定)
すべて探索的。**主な報告は Holm 調整後の p 値**とし、95% の週ブロック bootstrap 信頼区間は、効果量の不確かさの表示として併記する。調整後の p 値や CI だけで原因を確定しない。

**検定の方法(全ファミリー共通)**: 推定量 `θ̂`(被覆率、外れ率の差、`P(y > m)`、超過率、PIT の分散)について、帰無値 `θ0` に対する両側検定を、**元データの週ブロック bootstrap(10,000 回)の中心化した分布**で行う。
- `se = SD(θ*)`(元データの bootstrap から一度だけ推定して固定)。報告する統計量は `t = (θ̂ − θ0) / se`。
- `p = (1 + #{|θ* − θ̂| ≥ |θ̂ − θ0|}) / (B + 1)`、B = 10,000(有限回の再標本化を考慮し、`p ≥ 1/10,001`。比較は絶対誤差 1e-12 の許容付き。値が離散的で同値が多数あっても、`≥` の定義で保守的に数える)。
- 各 bootstrap 標本の中で標準誤差を再推定する二段階の bootstrap(nested bootstrap-t)は使わない。
- `se = 0`(bootstrap の分布が退化)の場合は検定を実行せず、**「判定不能」**とする(有意でも非有意でもない)。
- 標本内の分母が定義できない replicate(群の欠落など)は、その replicate を除外し、除外割合を記録する。除外が 5% を超える場合は「判定不能」。
- **Holm の検定数は、計画した検定の総数**(判定不能のセルも数える。保守的な扱い)。判定不能のセルは、調整後 p 値を `NA` とし、効果量(`θ̂`)のみ報告する。

| ファミリー | 帰無仮説 | 推定量 θ̂ | 検定数(Holm の単位) |
|---|---|---|---|
| FA(水準 c ごと、4 ファミリー) | 被覆率 = c | 被覆率 | 8(h × 期間) |
| FB | 90% 区間の下側の外れ率 = 上側の外れ率 | 外れ率の差 | 8 |
| FC | `P(y > 予測中央値)` = 0.5 | `P(y > m)` | 8 |
| FD(分位点 q ごと、6 ファミリー) | 超過率 = 名目 q | 超過率 | 8 |
| FE | PIT の分散 = 1/12 | PIT の分散 | 8 |
| FF(D4 の max-t) | 全群で被覆率が等しい | `T`(D4 の定義) | 各(h、期間、群の種類)ごとに 1(max-t が族ごとの誤り率を制御するため Holm は適用しない) |

- 週ブロック bootstrap: F1 と同じ ISO 週の分割、seed を固定。同一の resample を全ホライズン・全診断で共有する。F1 と同じく、隣接する週をまたぐ依存は保たない。
- 90% 区間の被覆率の不足が名目から **3 パーセントポイント以上**のものを、報告時の**注目基準**とする。統計的有意性や実用上の重要性を保証する閾値ではなく、判定の閾値でもない。
- 結果は、「どの仮説と整合するか」と「整合しないか」を、ホライズン・期間別の表で報告する。複数の仮説が同時に整合的であり得る。

## 6. 実装前のゲートと検証
実行の順序(どれかが失敗すれば診断本体を実行しない):
1. 入力ハッシュの照合(58 ファイルと生データ)。
2. 原点集合、実現値(`y = log C1 − log C0`)、バケット割り当てが、保存済みのスコアと一致することの確認(P1 で独立に確認した原点集合を使う)。
3. D2 の被覆率と、D3 以降で使う原点・予測分位点の整合性の確認: DDM の全原点で、アンサンブルから得た予測分位点と `y` による `hit*`・`pit_lo`・`pit_w` が、保存済みの値と一致すること(P1 の V9c と同じ原点・同じ式)。
4. **合成データによる単体テスト(必須)**: 診断コードを実データに適用する前に、次のケースで、診断が期待どおりの兆候を示し、誤った結論を出さないことを確認する。
   - **共通の設定(事前固定)**: 1 ケースあたり 3,000 原点、予測標本 M = 1000、53 週に均等に割り当て(週ブロック構造を再現)、予測分布は自由度 5 の Student-t を標準偏差 1 に規格化したもの(位置 0)。実現値は各ケースの「真の分布」から生成する。週ブロック bootstrap の回数 B_test = 1000。seed を固定(ケースごとに `default_rng([20261202, ケース番号, 試行番号])`)。
   - **試行回数**: 検出力のケースは各 200 試行、較正済みのケース(第一種の誤り)は 1000 試行。
   - **ケース**:
     1. 較正済み: 実現値の分布 = 予測分布。
     2. 分散不足: 実現値の尺度を予測の 1.25 倍。
     3. 中心のずれ: 実現値の位置を予測より +0.3 標準偏差。
     4. 裾の薄さ(中央 50% 区間は一致): 予測は t(5)(標準偏差 1)。実現値の分位点関数は、`0.25 ≤ p ≤ 0.75` では予測と同じ `Q_t(p)`、`p > 0.75` では `Q_t(0.75) + (Φ⁻¹(p) − Φ⁻¹(0.75))`、`p < 0.25` では対称(`Φ` は標準正規の分布関数)。25%・75% 分位点が一致するので中央 50% 区間の較正は保たれ、外側の裾だけが薄い(例: 99% 分位点は予測の約 2.61 に対し実現値は約 2.22)。
     5. **局面ごとの中心のずれで U 字型の PIT**: 原点を 2 つの局面に半々に分け、実現値の位置を ±0.5 標準偏差ずらす(幅は正しい)。各局面内でも予測の中央値は真の中央値からずれるので、群内の `k_90` が 1 になることは期待しない。
     6. 離散的な予測分布: 実現値と予測標本を 0.05 標準偏差の格子に丸める(タイが生じる)。
     7. 退化したアンサンブル: 較正済みのケースで、10% の原点の予測標本をすべて同一値にする(分母 0)。
   - **合否基準(すべて満たすこと)**:
     - ケース 1(第一種の誤り): FA(90%)、FB、FC、FE の補正前 p < 0.05 の棄却率が、それぞれ **0.08 以下**(1,000 試行。合否条件は上限のみ)。下限(0.03)は合否条件にせず、実測の棄却率と二項(Clopper–Pearson)95% 信頼区間を報告する。極端に保守的な検定で検出力が失われていないかは、ケース 2〜5 の検出力で別に確認する。`k_c`(c = 50、90)の平均が 1 ± 0.02 以内。
     - ケース 2: FA(90%) が補正前 p < 0.05 で棄却される割合が 0.90 以上。`k_90` の平均が 1.10 以上。FB(上下の非対称)の棄却率は 0.12 以下(上限のみ。下限は報告)。
     - ケース 3: FC の棄却率が 0.90 以上。FB の棄却率が 0.90 以上。
     - ケース 4: **検出力は合否に使わない**(FD(q = 1%、99%)の棄却率は報告のみ)。合否は方向と大きさの確認: 1% 分位点の下側超過率と 99% 分位点の上側超過率の試行平均が、それぞれ名目の 1% を下回り、理論値(約 0.33%。実現値の分位点関数から計算)の ±0.15 パーセントポイント以内。中央 50% 区間の被覆率の試行平均が 0.50 ± 0.01。FA(50%) の棄却率は 0.12 以下(中央 50% 区間が一致しているので過剰に棄却しないこと。上限のみ。下限は報告)。
     - ケース 5: FE(PIT の分散)の棄却率が 0.90 以上(U 字を検出)。D4 の群別の `P(y > m)` が群ごとに逆符号で、各群の FC(中心の偏り)の棄却率が 0.90 以上(局面別の中心の偏りを検出できること)。**H1 は機械的に支持・不支持を判定しない**(探索的な解釈であり、原因の自動分類は目的ではない)。その代わり、次を確認する: (a) コードの出力が、`k_c` と並べて群別の `P(y > m)`・中心の偏りの検定結果・上下の外れ率の差を必ず出力すること。(b) 報告書の解釈規則(`k_c > 1` は分散不足・中心のずれ・局面の混合のいずれでも生じ、`k_c` と PIT の U 字だけでは H1 を確定しない)を、このケースの出力に当てはめて確認すること(局面別の中心の偏りが検出され、中心補正後の `k_90` が補正前より 1 に近づくことを記録。補正後の値は合否に使わない)。群内の `k_90` の値は合否に使わない。参考値として、群内の実現値から群ごとの中央値のずれを引いた中心補正後の `k_90` を計算して報告する(位置のずれが幅の診断に与える影響の確認用。合成データ内の診断であり、実データの予測分布の再較正ではない)。
     - ケース 6: `k_c`(c = 50、90)の平均が 1 ± 0.05 以内。実データの報告用に、タイの割合と `k_c` のずれを記録する。
     - ケース 7: 出力に NaN・∞ がない。除外した原点の件数が正しく記録される(10% ± 1%)。0.1% 超の除外で `k_c` が「推定不能」と報告される。
     - 乱択 PIT のタイ: 変動が別の列に出る。
     - 例外処理: `se = 0`、群の欠落(bootstrap 標本)、観測数不足の群に対し、「判定不能」または除外が、仕様どおりに記録される(別の小さな合成データで確認)。
   - **基準未達の扱い**: 合成データテストは、理論的に予測できる性質を診断コードが再現するかの検査であり、結果を調整するためのものではない。(a) 診断コードが本計画の仕様と食い違う(独立に手計算した小さな例や参照実装と一致しない等、実装の誤りが確認された)場合に限り、コードを修正して再テストする。(b) 実装が仕様どおりと確認されたのに検出力などの基準に届かない場合(検出力の不足そのものは実装不具合と見なさない)は、検定方法・統計量・基準・seed を変更せず、その結果をそのまま報告して計画の再審査に回す(実データの診断には進まない)。いずれの場合も、試行の結果、使用した seed、コードのコミット、修正の理由を記録する。
5. 実行コミットを記録し(p2_diagnostics に未コミットの変更がないことを確認)、出力は新しい作業ディレクトリに書く。既存成果物は変更しない。

診断コードは `backend/research/p2_diagnostics/` に置く。P1 の独立ライブラリ(`p1_verification/p1_lib.py`)の原点集合、ターゲット、バケット、分位点、点スコア関数は再利用してよい。F1 の本番の計算関数は使わない。

## 9. 限界
- 診断は探索的で、final 期間は部分的に既知。
- DDM の予測分布は初期状態から始めたパスの分布(F1 の解釈上の制限 8)。D5 はこの影響の一部を示唆するが、切り分けは P3 の課題。

- 週ブロック bootstrap は、隣接する週をまたぐ依存を保たない。
- ATR、時間帯、月の交絡のため、局面別の結果から因果的な原因は特定できない。
