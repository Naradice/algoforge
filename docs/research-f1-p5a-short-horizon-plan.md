## 1. 目的

P4 で、同じ ATR バケット情報だけの経験分布(E1a)が、推定期間のみの当てはめで final の h1・h4 を較正し(被覆率 0.909/0.901、DDM は 0.850/0.807)、CRPS も約 2.2〜2.4% 小さかった。**DDM の予測分布は、同じ情報で作れる分布より、h1・h4 で狭く(特に ATR 群 3 の被覆率 0.736)、バケット間の幅の関係もずれている。** P5-A は、この差が**尺度(幅)の問題か、形状の問題か、ホライズン方向の関係の問題か、候補パラメータの選び方の問題か**を、保存済みのアンサンブルだけで切り分ける。再較正モデルの採用は目的としない。

## 2. 設計の前提となる事実

1. DDM の予測分布は、ATR バケット(20)ごとのアンサンブル(各 1,000 経路、3 seed、各経路は h=1/4/12/24 の累積対数収益)。保存済み(C0s、C0、P3 の変種)。P3 の `.npz` には**各経路の試行 ID**があり、F1 の生成式(`cands[attempt % len(cands)]`)により、**各経路がどの候補 (delta, wma) で作られたか**を復元できる(バケットごとに 8 候補)。
2. マッピング(`ddm_mapping.json`)は、各バケットで、推定期間の実現値の 1,000 行(M1 の前向き窓)の統計量(標準偏差、歪度、尖度、自己相関、ボラティリティ・クラスタリング)に合うシミュレーション条件(候補)を選ぶ。バケットごとに `best_std_ratio` と `out_of_range` が記録されている。**マッピングは 60 分足の複数ホライズンの累積収益分布には直接合わされていない。**
3. P2 の記録: DDM の 90% 区間幅は h1 を 1 として h4/h12/h24 で 1.87/3.84/6.41(`sqrt(h)` なら 2/3.46/4.90)。k90 は h1・h4 で 1 を超え(1.2/1.4)、検証の h12・h24 で 1 未満(0.90/0.72)。**ホライズンごとに幅の過不足の符号が変わる**。
4. E1a の推定期間(標本内)の被覆率は構成上 0.90。DDM は推定期間でも h1・h4 で 0.836/0.803(P4)。つまり、**この不足は期間のドリフトではなく、推定期間でも存在する**。
5. 検証・final のバケット別の原点数は少ない(P4)。期間外の評価は ATR 群(5)単位とし、バケット単位の詳細は推定期間でのみ行う。

## 3. 仮説(互いに排他的でない)

| 記号 | 仮説 | 観測上の兆候 |
|---|---|---|
| S1 | **尺度**: DDM の分布は、バケット × ホライズンごとの尺度の係数でほぼ説明できる | 中央値まわりの上下側の分位点の比 `r(p)` が、p によらずほぼ一定(尺度の変換だけで差が閉じる) |
| S2 | **形状**: 尺度を合わせても、中心と裾の関係が合わない | `r(p)` が p とともに系統的に変わる(例: 内側の区間が狭く裾が広い) |
| S3 | **ホライズン方向の関係**: ホライズン間の幅の増え方(分散-時間の関係)が実現値と違う | 幅の対数をホライズンの対数に対して見た傾きが、DDM と実現値(E1a)で異なる |
| S4 | **候補パラメータの選び方**: 8 候補の混合の重み、または候補自体が、バケット内の分布に合っていない | 候補ごとの分位点が大きくばらつき、混合の幅が E1a より狭い。単一の候補、または少数の候補で E1a に近づく |
| S5 | **マッピングの目的関数のずれ**: M1 窓の統計量に合わせているため、60 分足のホライズン別分布がずれる | バケット別の幅の不足が `best_std_ratio`、`out_of_range` などと系統的に関係する(20 バケットの記述のみ) |

## 4. 分析計画(保存済み結果の再利用のみ)

### A. 分位点関数の比較(診断の中心)

バケット × ホライズンで、DDM(C0s、3 seed)と E1a(推定期間)の分位点関数を比較する。

- 比較する p: 0.01, 0.025, 0.05, 0.10, 0.25, 0.50, 0.75, 0.90, 0.95, 0.975, 0.99。
- 指標: (a) **位置のずれ** `(med_DDM − med_E1a) / IQR_E1a`(IQR_E1a が 0 以下なら未定義)。(b) 上側・下側それぞれの**尺度比** `r_±(p) = |Q_DDM(p) − Q_DDM(0.5)| / |Q_E1a(p) − Q_E1a(0.5)|`(上側は p > 0.5、下側は p < 0.5)。(c) **形状の指標**: 上側は `r_+(p) / r_+(0.75)`、下側は `r_-(p) / r_-(0.25)`(それぞれ内側の四分位に対する裾の相対比)。上側と下側は**別々に比較し、非対称性を保持する**(平均しない)。
- **未定義の扱い**: 分母 `|Q_E1a(p) − Q_E1a(0.5)|`(形状指標では基準の `r_+(0.75)`、`r_-(0.25)` も)が `1e-9 × IQR_E1a` 以下なら、その比は**未定義**とし、**0 や 1 に置き換えない**(表では「未定義」と表示し、件数を報告する)。p = 0.5 は位置のずれにのみ使い、比には使わない。未定義のバケット・ホライズンは、集計(群別の中央値など)から除き、除いた数を併記する。
- 不確かさ: E1a の分位点は推定期間の原点の週ブロック bootstrap(B=2,000)、DDM は 3 seed の範囲を併記する(区間は記述的。アンサンブルと推定の誤差を分けて示す)。
- 出力: バケット別(推定期間のみ)、ATR 群別(推定・検証・final)。h1・h4 を主表、h12・h24 を補助表とする。

### B. ホライズン方向の関係(S3)

バケット別・ATR 群別に、90% 幅の対数 vs ホライズンの対数の傾き(h1→h4、h4→h12、h12→h24 の区間ごと)を、DDM、E1a、実現値の y の分位点幅(各期間)で比較する。DDM の傾きと実現値の傾きの差を記述する。

### C. 簡単な変換による診断(推定期間のみで固定した係数)

次の変換で、DDM が E1a にどこまで近づくかを見る。**係数は推定期間のデータだけで決め、検証・final で期間外の確認をする。final の結果で変換や係数を変えない。**

| 変換 | 内容 | 自由度 |
|---|---|---|
| T0 | 変換なし(DDM) | — |
| T1 | ホライズン共通の尺度係数 `s_h`(DDM のバケット中央値のまわりに拡大・縮小) | 4 |
| T2 | バケット × ホライズンの尺度係数 `s_{b,h}` | 80 |
| T3 | ホライズンごとの PIT 再較正(推定期間の PIT の経験分布 `G_h` を全バケットでプールし、予測 CDF を `G_h(F_DDM)` に置き換える) | 4 つの関数 |
| T4 | バケット × ホライズンの PIT 再較正(`G_{b,h}`) | 80 の関数。**E1a とほぼ同じ情報量の参考(上限ではない)** |

- 係数の決め方(事前固定): T1・T2 は、推定期間の平均 CRPS を最小にする倍率(格子 0.50〜2.00、刻み 0.01)。T3・T4 は推定期間の PIT の経験分布。
- 評価: 検証・final(ATR 群別・プール)の被覆率(50/80/90/95%)、k90、平均 CRPS、DDM・E1a に対する相対 CRPS(週ブロック bootstrap の記述的な区間)。**「差が閉じた割合」`(CRPS_DDM − CRPS_T)/(CRPS_DDM − CRPS_E1a)` は、分母が小さいときに不安定なので、分母が小さい(1% 未満)セルでは表示せず、差そのものを示す。**
- これは診断であり、再較正モデルの提案・採用ではない。

**読み方の表(自動判定には使わない)**

### D. 候補パラメータの診断(S4・S5)

- 保存済みの試行 ID から候補を復元し、バケット別・候補別に、各ホライズンの分位点幅を E1a と比較する(1 候補あたり約 375 経路、3 seed の合計)。候補間のばらつきと、混合の幅が E1a より狭いかどうかを記述する。
- **部分アンサンブルの選択規則(事前固定。探索の自由度を持たせない)**:
  - 単一候補: 8 候補すべてを評価し、**推定期間の CRPS が最小の 1 候補**を選ぶ。
  - 2 候補: 8 候補から 2 候補を選ぶ**全 28 組**を評価し、推定期間の CRPS が最小の 1 組を選ぶ。**混合の重みは 50:50 に固定**(各候補の経路を同数にそろえる)。
  - 選択は**バケット別・ホライズン別**に、推定期間のデータのみで行い、検証・final では選択を固定する。
  - **元の 8 候補の混合(現在の DDM)を必ず対照**として並べる。
  - 候補ごとの経路数が有限(1 候補あたり約 375 経路、3 seed の合計)であるため、選ばれた候補の推定期間 CRPS の改善には標本誤差と選択の偏り(最良の選択による楽観)が含まれる。候補選択の安定性として、**seed 別(3 seed)に同じ選択をした場合に、選ばれる候補が一致するか**を報告し、推定期間の CRPS の改善と、検証・final の改善を分けて示す。
  - 診断であり、採用ではない。候補数や組み合わせの追加探索はしない。
- バケット別の幅の不足の指標(例: h1 の 90% 幅比)と、`best_std_ratio`、`out_of_range`、`n_windows_available` との関係を 20 バケットの散布として記述する(順位相関は記述のみ。検定しない)。

## 5. 事前ゲート(失敗したら停止して報告)

1. 入力の同一性: 生データのハッシュ、P3・P4 の保存値(DDM の指標、E1a の被覆率・CRPS)の再現。
2. 分位点・変換の実装: 実装の検証と、数値近似の誤差の評価を**分けて**行う。
   - 2a(厳密一致): 既知分布(合成データ)で、分位点の比の実装を検証。**T1 は `s=1` のとき、元のアンサンブルをそのまま使うため、元の DDM と厳密に一致する**(CRPS を 1e-12 の精度で再現)。
   - 2b(恒等変換の一致): T3・T4 で `G(u) = u`(恒等関数)を与えたとき、**変換後の CDF と分位点が元の分布と一致する**ことを検証する。CRPS は、**変換前と変換後で同じ数値表現(同じ標本、同じ積分手順)を用いた場合**に限り、1e-12 の厳密一致を要求する。
   - 2c(近似誤差の評価): 標本ベースの CRPS と、分位点格子(経験 CDF の補間)による近似 CRPS を比較する場合は、**事前に固定した許容値**(標本ベース CRPS に対する相対誤差 1e-3)を用い、誤差は記録する。許容値を超えても 2a・2b の失敗とはせず、その格子は結果の表で近似であることを明記する(超過の件数を報告)。
3. 候補の復元: 試行 ID から復元した候補の列が、F1 の生成式と一致する(バケットごとの先頭 100 件以上)。復元した候補別の経路数が約 1/8 ずつになる。
4. 推定期間のみでの当てはめ: T1〜T4 と候補選択の係数が、検証・final のデータを乱数で置き換えても変わらない。
5. T3・T4 の単調性: 変換後の CDF が単調である。

## 6. 報告の規則

- 期間別・ホライズン別・ATR 群別の表を主とする。各セルの n、週数、除外したセルを示す。バケット単位は推定期間のみ。
- p 値で判断しない。効果量と記述的な区間を示し、E1a の推定誤差(週ブロック bootstrap)と DDM の seed 間の範囲を分けて表示する。
- 「整合的」と原因の確定を区別する。E1a が DDM より良いことは、DDM の構造的な限界の確定ではない。候補、パラメータ選択、学習目的、生成分布の形状は、この分析では識別できない可能性がある。
- final の結果で、変換、格子、基準を変更しない。F1 の判定期間は部分的に既知である。

## 6B. 結果の解釈で区別すること

- **尺度の不足と形状の不一致**: T2 で CRPS が改善しても、分布形状の不一致が消えたとは限らない。分析 A の分位点比(上下側別の形状指標)と併せて判断する。
- **候補選択と候補自体の表現力**: 部分アンサンブルで改善した場合、現在の混合重みが適切でない可能性は示されるが、候補の生成機構そのものが適切かどうかは判断できない。
- **ホライズン方向の不一致と期間変化**: h12・h24 の実現値分布は期間で大きく変わっている。ホライズン方向の傾きが DDM と実現値で異なる場合、それが DDM 固有の時間スケールの問題か、市場分布の期間差かを、推定期間の傾きと検証・final の傾きを分けて示すことで区別する。
