## 1. 目的

P3 で、初期状態の経過(バーンイン)とショックの時間構造を操作しても、ATR 群間の較正差と、h12/h24 の期間差は大部分が残った。P4 は、**この ATR 依存・期間依存がどの仮説に整合するか**を、保存済みの結果だけで切り分ける。因果の確定、再較正、モデルの採用判断は目的としない。

## 2. 設計の前提となる事実(いずれも保存済みの記録から)

1. DDM の予測分布は、各原点の **ATR バケット(20)だけ**で決まる。予測はバケットごとに共通のアンサンブルで、データ同化や他の条件づけはない。ATR 群は 5 つ(バケット 4 つずつ)。
2. バケットの境界は推定期間の分位点で決まる。**期間によって ATR の構成が大きく異なる**(ホライズン 12 の例):

| 期間 | n | ATR 群 0〜4 の比率 |
|---|---|---|
| 推定 | 21,958 | 0.203 / 0.203 / 0.200 / 0.201 / 0.193 |
| 検証 | 5,353 | 0.404 / 0.254 / 0.191 / 0.111 / 0.041 |
| final | 5,463 | 0.170 / 0.146 / 0.167 / 0.193 / 0.324 |

3. バケット別の原点数は、推定期間で 約 900〜1,230、**検証期間で最小 20〜30**(高 ATR のバケット)、final で 150〜710。ホライズン、期間によって大きく異なる。バケット × 時間帯(3 区分)にすると final h12 の 60 セル中 42 が 100 件未満。
4. 原点は連続した足(間隔 1)で、窓が強く重なる。実質的な標本数は原点数ではなく、週数(検証・final とも 53 週)に近い。P2 と同じく、週ブロック bootstrap の区間は記述的な情報とし、p 値では判断しない。
5. P2 の既報: 同じ ATR 群でも期間で被覆率が違う(検証 h24 の ATR 群別は 0.967〜0.986、final h24 は 0.859〜0.920)一方、h1 の ATR 群別パターンは検証と final で似ている。**プールした期間差には、構成の違いで生じる部分と、同一群内の変化による部分が混ざっている可能性がある**(確認が必要。この計画の A1・A2)。
6. F1 の判定に使われた final 期間は、すでに部分的に既知である。P4 でも final の結果で手法や基準を調整しない。

## 3. 仮説(互いに排他的でない)

| 記号 | 仮説 | 観測上の兆候(整合的なもの。確定ではない) |
|---|---|---|
| HA | **構成の変化**: 期間間の較正差は主に ATR 群の比率の変化によって生じる | 群内の較正が期間間で近く、構成を揃えるとプールした期間差が縮む |
| HB | **群内の時間的変化**: 同じバケット内で、実現値の条件付き分布が期間で変わる | 群内の較正が期間間で異なる。推定期間で較正済みの経験分布も final で外れる |
| HC | **条件づけ情報の不足**: ATR だけでは区別できない状態(時間帯、直近のボラティリティ比、直近の方向性など)で将来分布が変わる | 同じバケット内で、事前指定の追加変数により較正やスコアが系統的に変わる |
| HD | **バケット内の分布形状の表現力不足**: 同じ条件づけ情報(バケットだけ)で、DDM より良い分布が存在する | 推定期間の標本内でもバケット内の形状がずれる(内側だけ不足など)。バケット別の経験分布のほうが、同じ情報で DDM より較正・CRPS が良い |

P2 で見えた「対称な幅の不足」「h24 の内側だけ不足(HD と整合的)」「上方向の中心のずれ」は、これらのどれと整合的かを、下の分析で記述する。

## 4. 分析計画(すべて保存済みの結果の再利用。DDM の新規生成はしない)

### A. 構成と群内の変化の分解

- **A1 分解**: 厳密な分解の対象は、**群別指標の構成比による加重平均が全体の指標と一致する 90% 被覆率と平均 CRPS(原点ごとの CRPS の平均)だけ**とする。期間 p の指標を、群別の指標 `c_g^p` と構成比 `w_g^p`(その期間の原点数の比)に分け、期間間の差を「構成の寄与 `Σ(w^f − w^v)·c`」と「群内の寄与 `Σ w·(c^f − c^v)`」に分解する。基準の取り方による順序差が出るので、**2 通りの順序と、その平均(Shapley 型)を併記**する。比較: 検証 → final、推定 → 検証、推定 → final。ホライズン別(h1/h4/h12/h24)。
- **k90 の扱い**: k90 は残差の分位点から求める非線形な統計量で、群別の値を構成比で加重平均しても全体の値に一致しない。そのため A1 の分解の対象にせず、**群別・期間別の記述比較(A2 の表)に限る**。他の非加法的な指標(PIT 分散など)も同様に記述のみとする。
- **A2 群内の比較**: ATR 群別・期間別の PIT 分布、被覆率、k90、`P(y>m)`、実現値 y の分位点(5, 25, 50, 75, 95%)を表にする。群内で期間をまたいだ y の分位点比を併記し、HB(実現値側の変化)と DDM 予測側の問題を区別する。
- セル規則: 分解は **5 つの ATR 群**(バケット単位では原点数が不足するため)を主とする。バケット別(20)は、原点数が 100 件以上かつ 10 週以上のセルだけ記述し、それ未満は表に n を示して評価しない。セルを無理に補完しない。

### B. 同じ ATR 情報による経験分布ベースラインとの比較

DDM と同じ情報(ATR バケット)だけを使う代替の予測分布(経験分布ベースライン)を、事前に固定した 3 種類で作る。これは**DDM の性能上限ではなく**、同じ情報を使う別の予測分布との比較である。当てはめは次の 2 つで、**別の実験として扱い、結果を混ぜない**。

| 実験 | 当てはめ | 評価 | 解釈 |
|---|---|---|---|
| B-1 | 推定期間のみ | 検証・final | 期間をまたいだ固定モデルの性能 |
| B-2 | 推定+検証期間 | final のみ | 新しい期間の情報を追加した場合の性能変化 |

B-2 では、**検証期間の末尾にもパージを適用**し、final の将来情報(前向きの結果)が当てはめに混入しないことを、原点の範囲で確認する。

- **E1a**: バケット別の y の経験分位点(各バケットの推定期間の y を、そのまま予測分布とする)。
- **E1b**: 位置・尺度型。バケット別の中央値と IQR で y を標準化し、全バケット共通の標準化分布を用いる。
- **E1c**: 近接バケット間の平滑(隣り合う 3 バケットで y をプールした経験分位点)。
- **パージ**: 当てはめ区間の末尾 `60h` 本の足に重なる原点は除外する(前向きの結果が評価区間に重なるため)。CLAUDE.md の walk-forward ルールに従う。
- 比較対象: DDM(C0s の 3 seed 平均、`C0` の保存値と一致を確認済み)、F1 の統計モデル(保存済みの CRPS、PIT。群別比較に必要な情報が保存されていない場合は、再生成せず、利用できる集計範囲での参考比較にとどめる)、P3 の保存済みアンサンブル(C2(60)、C3。任意の D)。ベースライン同士の最良選択は評価に使わず、3 種類すべてを報告する(best-of-N の評価を避ける)。
- 出力: 期間 × ホライズン × ATR 群の CRPS、被覆率(50/80/90/95%)、k90、`P(y>m)`、PIT 分散。DDM に対する相対差と、週ブロック bootstrap の記述的な区間。

**読み方の表(自動判定には使わない)**

| 観測 | 整合的な仮説 |
|---|---|
| E1 が検証・final で較正済みで、DDM が較正されない | HD(バケット内の形状・幅の表現力) |
| E1 も final で同様に外れ、群内で y の分位点が期間で動く | HB(群内の時間的変化) |
| 構成を揃えるとプールの期間差が縮み、群内の指標が近い | HA |
| E1 が推定期間の標本内でも DDM より良い | HD と整合的(ただし E1 は標本内なので、独立な評価ではない。E1 は DDM の性能上限ではない) |

### C. 追加の条件づけ情報の余地(事前指定した 3 変数、1 つずつ)

原点時点で使える情報だけで作る変数を、**3 つに限定し、定義と区切りを推定期間だけで固定する**:

1. 時間帯(UTC 00–08、08–16、16–24。P2 と同じ)。
2. 直近 12 本の実現ボラティリティと ATR の比(推定期間の 3 分位で区切る)。
3. 直近 12 本の符号付き収益(推定期間の 3 分位で区切る)。

- 各変数を **バケットに 1 つだけ追加**した経験分布(E1a と同じ作り方)を作り、E1a に対する較正・CRPS の変化を報告する(効果量と記述的な区間)。複数変数の組み合わせ、相互作用の探索、変数の追加はしない。
- **公平比較**: 追加変数モデルと E1a は、**同じ評価原点集合**で比較する。疎なセルを評価から除外した場合は、E1a 側も同じ原点集合に揃えて比較する(除外した原点の数と割合を併記)。各セルについて、推定期間の標本数、評価原点数、週数を表に併記する。
- **読み方(自動判定には使わない)**: E1a より CRPS が改善した場合は「ATR 以外の情報に予測上の価値がある可能性」。改善しない場合は「情報が無価値とは限らず、セル分割による標本数の減少が影響している可能性」。特定の ATR 群でだけ改善した場合は「条件づけ情報の価値が局面に依存する可能性」。細分化による標本数の減少と、追加情報による改善を混同しない。
- 変数の定義が原点時点までの情報だけを使っていることを、P3 の gate 6 と同様の将来情報なしの検査で確認する(原点以降の足を変えても値が変わらないこと)。
- 区切りで 1 セルあたり約 400 件以上(推定期間)を確保できることを事前に確認し、検証・final で 100 件未満のセルは評価しない。

### D. P3 の DDM 変種の再利用(任意。追加の DDM 生成はしない)

A・B の分解と比較を、P3 の保存済みアンサンブル(C2(60)、C3 など)にも適用し、ショック時計のリセットが、構成の寄与・群内の寄与のどちらに効いたかを見る。DDM の新規生成は行わない。

## 5. 事前に確認するゲート(失敗したら停止して報告)

1. **入力の同一性**: F1 の入力ハッシュ、P2 の原点集合・y・バケット対応が P2 の保存値と一致する(P2・P3 の既存ゲートの再利用)。DDM の C0s・C0 の指標が P3 の保存値を再現する。
2. **分解の恒等性**: A1 の 2 つの順序で、構成の寄与 + 群内の寄与 = 期間間の差が、数値誤差(1e-12)の範囲で成り立つ。**対象は加重平均が成立する 90% 被覆率と平均 CRPS のみ**(k90 など非加法的な指標には適用しない)。
3. **基準の実装の確認**:
   - **E1a**: 経験分位点の順位と標本内被覆率の整合性を検証する(分位点の定義と有限標本の丸めの範囲内)。
   - **E1b・E1c**: 構成した分布の分位点の順序(単調性)、CDF の単調性、CRPS 実装の一致を検証する。E1b・E1c の標本内被覆率は**記録するが、名目値との一致を PASS 条件にしない**(E1c は隣接バケットのプール、E1b は共通の標準化分布を使うため、バケット別の標本内被覆率が名目値に一致する保証がない)。
   - 公平な CRPS が、独立な実装(順位ベースの式と総当たり)で一致する。
4. **パージの確認**: 当てはめに使う原点の前向きの窓が評価区間に重ならないことを、原点の範囲で検査する。
5. **将来情報なしの検査**: 追加変数 3 つについて、原点以降の足を乱数で置き換えても値が変わらない。

## 6. 報告の規則

- 期間別・ホライズン別・ATR 群別の表を主とし、期間をまとめた平均だけで結論しない。各セルの n、週数、除外したセルを必ず示す。
- p 値で判断しない。効果量、群別の値、記述的な区間を主とし、週ブロック bootstrap の区間はアンサンブルの標本誤差を含まない旨を併記する。
- 「HA〜HD のどれが支持された」と断定せず、「整合的/整合的でない」を表で示す。複数の仮説が同時に成り立つ場合は、そのまま記録する。
- final 期間の結果で、基準、変数、区切りを変更しない(F1 の判定期間は部分的に既知)。
- 内部の seed 間の安定性と、市場環境への頑健性を区別して書く。

## 11. 限界

- 原点が連続し窓が重なるため、実質的な標本数は週数に近い。検出できる差は限られる。
- 経験分布ベースライン(E1)は、DDM の性能上限ではなく、同じ ATR 情報を使う別の予測分布である。推定期間の標本内の結果は独立な評価ではなく、検証・final で評価した結果だけを独立な情報として扱う。
- 同一の期間・入力マッピングの再利用であり、他の期間・市場への一般化は示さない。
- 追加変数 3 つで見つからなくても、条件づけ情報の余地がないとは言えない。
