## 1. 研究目的と検証仮説

### 1.1 目的
DDMv3 のパラメータを動かしたときに、生成される市場の統計的形状(統計量のベクトル)が取り得る範囲(到達可能領域)を、**seed 間のばらつきを考慮して**推定する。次に、その領域に近い統計量を持つ実市場の窓を、**事前に固定した規則**で抽出する。最後に、マッチングに使っていない統計量で、DDM と実市場の間に残る差異を、**条件付き分布・関係の差**として評価する。

### 1.2 検証仮説(すべて記述・比較の仮説。結果を見て変更しない)

- **H1(到達可能領域の形。尺度に依存しない統計量のベクトルに限る)**: 現行の 2 パラメータ(delta、wma、`num_agent=300`、ショックなし)の到達可能領域では、自己相関・尖度・ボラティリティ・クラスタリングが連動して動き、実市場の統計量のベクトルは領域の外側または境界の近くに位置する。根拠(既存 [R]): アトラス 170 点で `acf_1` の範囲は −0.62〜+0.10、実市場(P5-B の窓)は約 −0.01〜−0.04。P5-B 第 3 段階で、std 帯と `acf_1` 帯を同時に満たす点は 20 バケットすべてで 0 点。
- **H1s(補助。尺度)**: 尺度に依存しない統計量のベクトルを揃えた点で、DDM の標準偏差(任意単位)は、実市場の標準偏差に対して**1 つの定数倍で対応できる範囲**にあるか。DDM と実市場の単位が異なる(§5)ため、std は主分析に入れない。
- **H2(追加パラメータの効果)**: `num_agent`(A2-0 を通過した場合)、定率ショック、スプレッド帰還、観測の集約幅を動かすと、到達可能領域は、(a) 実市場の統計量のベクトルを含む方向に広がるか、(b) 広がらず、領域の外側という結果が頑健に残る。どちらかは事前に予想しない。
- **H3(条件付き残差)**: 実市場の窓のうち DDM の到達可能領域に入るものについて、マッチング用の統計量を揃えても、評価用の統計量には、**ノイズの床(実市場同士の期間間変動)を超える差**が残る。残差が小さい統計量と大きい統計量が分かれる。
- **H4(帰属)**: 残る差は、(i) 構造的な制約(どのパラメータでも到達できない)、(ii) 探索していないパラメータの不足、(iii) 市場状態の違い(定常性・日中季節性)のうち、どれと整合的かを、アブレーションで部分的に切り分けられる。**整合的であることと原因の確定は区別する。**

### 1.3 時間スケールの規約(主目的の固定)
本研究の主目的は**「統計的形状の比較」**である: 各系列を、それぞれの**基底足**(DDM: TPC 約定 = 1 本、実市場: 1 分 = 1 本)で観測し、本数で定義した窓・ラグ(1,000 本、`acf_1`、`volclust_50`、VR(20) など)で統計量を計算する。**DDM の 1 本と実市場の 1 本が同じ実時間を表すとは仮定せず、DDM の内部時計と実市場の経過時間の対応も固定しない。**そのうえで、時間幅の違いの影響を (i) 集約プロファイル(各系列を基底足の 2・4 倍に集約したときの統計量の変化)、(ii) 単位の組み合わせの感度分析(§6.6)、で評価する。
**「実時間スケールの比較」(DDM の内部時計と実市場の経過時間を対応付けて比較する)は、別の研究上の問いであり、本計画の範囲外**とする。取引活動量・取引間隔の統計量も、実時間のクロックの規約(T1 #895)が前提となるため、本計画から**除外**する(今後の別計画の候補)。

### 1.4 結論の制限(事前に固定)
統計量が一致しても、**DDM の市場生成機構が実市場を再現したとは結論しない。**示せるのは、選んだ統計量について、選んだ DDM のパラメータ族が、実市場とどの範囲で整合的かだけである。

## 4. 対象パラメータと探索範囲の決め方

### 4.1 実装を確認した事実(`backend/data/collectors/ddm_simulator.py`、`backend/calibrate_ddm.py`、`backend/research/p3_burnin/p3_sim.py`)
- `delta` はモデルのパラメータそのものではない。アトラスでは、各エージェントの `dealer_sensitive` の一様分布の範囲 `[-3.5, -1.5]` を `delta` だけ平行移動したもの。**物理的な意味は未確立**(#883)。
- `wma` は価格変化の加重移動平均の窓の長さ(整数)。**重みは各インスタンスで一様乱数から引かれる**ため、seed 間変動に重みの抽選も含まれる。
- 価格は `trade_unit=0.001` の整数倍に丸められる(`(ask+bid)/2 // trade_unit * trade_unit`)。したがって約定価格は**整数のティック**として厳密に保存できる。
- 価格単位: `initial_price=100`、`trade_unit=0.001`、`spread=1.0`、`min/max_volatility=0.01/0.02`、1 ローソク足 = 20 約定(アトラス、P3)。単位は実市場の pip に較正されていない。
- 既定で無効の機構(すべて opt-in): スプレッド帰還、ロスリミット、外生ショック(定率)、指数減衰。

### 4.3 A1 の設計(確定)
- **探索点**: 16 delta × 11 wma = **176 点**(`num_agent=300`、ショックなし)。
- **seed**: 各点 10 seed。seed 集合を **SA(5 seed、選択用)**と **SB(5 seed、評価用)**に固定する。seed 番号の規則は `seed = 100_000 × set_id + point_id × 10 + k`(set_id: SA=1、SB=2、k=0..4)として、実行前にコードと共にコミットする。
- **約定数**: 各 run **10 万約定**(TPC=20 で 5,000 足。1,000 本の窓を 5 つ、4,000 本の窓を 1 つ取れる)。燃焼期間は置かない(P3 で初期過渡の影響が小さいことを確認済み [R]。§12)。
- **計算量**: 176 点 × 10 seed × 10 万約定 = **1.76 億約定**。1 約定あたり約 0.16 ミリ秒(P3 の実測: 約 4.5 CPU 秒/28,820 約定、300 エージェント)から、**約 7.6 CPU 時間**。壁時間は 18 ワーカーで約 25 分。この見積りは外挿で、**±50%** の不確実性がある(`wma ≤ 3` などの発散する run は、停止までの時間が長い可能性がある)。**予算の上限は 2 倍(15.2 CPU 時間)**とし、超えた場合は停止して報告する。
- **seed の役割**: SA は、到達可能領域の推定・M の距離・マッチング(点の選択)に使う。SB は、**評価用**(E の評価、領域の安定性の確認)に使う。**C では追加の DDM 生成をしない。**

**A2-0(条件付きで、小規模)**:
- 点: (delta, wma) の 3 点(A1 の格子から、**実市場のデータを見る前に**、A1 の統計量の範囲を 3 分位する規則で機械的に選ぶ。具体的な規則はコードと共にコミット)。`num_agent` ∈ {150, 300, 600}。各 5 seed × 10 万約定。計 3 × 3 × 5 = 45 run、約 0.2 CPU 時間(300 は A1 の SA を再利用するため新規は 30 run。150 は 0.5 倍、600 は 2 倍のコスト)。
- **有界性の合否**(既存のスクリーニング基準を踏襲): 全 run で価格が有限かつ正。スピアマン相関の絶対値 ≤ 0.3、純変動率の絶対値 ≤ 15%。基準を超えた run があれば、同一条件で 3 seed を追加して再確認し、再び超えた場合は、その `num_agent` を A2 から除外する(特に 600)。
- **統計量への影響の判定**: 3 点それぞれで、`num_agent` を変えたときの M の各成分の変化が、同一 `num_agent` の seed 間 SE の **3 倍を超える**場合を「動く」とする(基準は固定)。**M のいずれかの成分が、3 点のうち 2 点以上で「動く」なら、`num_agent` を A2 の軸に入れる。そうでなければ 300 に固定し、軸を落とす**(これは「軸を落とす」という結論であり、失敗ではない)。
- std は M・E に入れないが、**水準の変化の記述**として別に報告する(#877 の記述の検証)。

### 4.5 保存形式(確定)
- **各 run の約定単位の価格系列を、整数ティック(`price / trade_unit` を丸めた `int32`)で保存**する。1 run = 10 万約定 = **約 0.4 MB**(圧縮前)。TPC 別の終値は、保存した系列から**厳密に再構成**できる(グループの最後の約定価格)。
- run ごとの付随データ(JSON): パラメータ、seed、成功・発散の別、発散時の約定数、所要時間、コードのコミット。
- **既存の `simulate_ohlc()`(20 約定ごとの終値のみ返す)は使わない**。`DDMv3.simulate(n_trades)["price"]` を直接呼ぶ薄いラッパーを新設する(DDM の実装は変更しない)。
- 保存容量: A1 は 1,760 run で **約 0.7 GB**、A2 は 480 run で約 0.2 GB、A3 は 768 run で約 0.3 GB。合計 **約 1.2 GB**(圧縮前)。書き込みは run 完了ごとに 1 ファイルで、I/O は計算時間に対して無視できる。
- 発散した run: 既存の挙動に従い例外として記録し、再試行はしない(`wma ≤ 3` で多い)。発散率は点ごとに記録する。

### 4.6 A3(条件付き)の設計と、減衰型ショックの扱い
- **減衰型ショック(`decay_tau=300` ステップ、floor=0)は、複数窓の設計では初期の過渡にしか効かない**(確率が `exp(−step/τ)` で下がり、10 万約定では最初の数千ステップを過ぎると実質ゼロ)。`v3_shock` データソースの定率(0.0015)とは別物で、F1 の P3/P5 で用いた設定(確率 0.002、サイズ 0.3、τ=300)は、**予測の 1,440 足の窓の冒頭**に効く用途のものである。したがって、A3 の主軸は**定率ショック**とし、減衰型は主軸にしない(必要な場合は、最初の窓だけを対象とする小規模なアブレーションで別に扱う)。
- **設計**: 実市場のデータに依存しない規則で選んだ **8 つの基点**(A1 の M 空間での最遠点サンプリング)× **Sobol 列 32 点**(定率ショック確率 [0, 0.003]、サイズ [0.1, 0.6]、スプレッド帰還 `a` [0, 0.25] の 3 次元)× 3 seed = **768 run**(約 3.3 CPU 時間、各 10 万約定)。範囲・点数・seed・乱数の種は実行前にコミットする。

## 6. 実市場データの選定・分割方法

### 6.1 対象(既存の資源。**新規収集はしない**)
- **主**: USDJPY の 1 分足(既存の `usdjpy_1min_volatility.parquet`(SHA-256 `c25eb572…`)と HistData)。どちらをどの範囲で使うかは確認事項(§12)。
- **副(Stage D)**: HistData の他の 8 通貨ペア。通貨ペアを変えた再現性の確認のみ。

### 6.2 期間の分割(既存の分割を継承。週の偶奇で追加分割)
P1〜P5 で使った期間: 推定期間 2016-08-31〜2020-08-31、検証期間 2020-09-01〜2021-08-31、final 期間 2021-09-01〜2022-08-31。
- **推定期間**は、ISO 週番号の**偶奇**で 2 つに分ける(決定的な規則)。
  - **R-A(奇数週)**: caliper・窓間 SD・マッチング規則の確定と、DDM との比較(C の主比較)に使う。
  - **R-B(偶数週)**: **ノイズの床の算出専用**。R-A のデータは使わず(ただし M-近傍の参照側として R-A の窓は使う)、R-B で規則・パラメータを選ばない。
- **検証期間**: 固定済みの規則(caliper、距離、分割、ノイズ床の判定基準)の**再現確認**のみに使う。ノイズ床の算出には使わない。
- **final 期間**: 本計画では使わない。

### 6.3 時間窓
- **主窓長 L = 1,000 本**(アトラスと同じ)。**窓は重ならない**(stride = L)。窓は、開始時刻の属する週に割り当て、**週境界を跨ぐ窓は除外**する(週末・休日を含むため)。重なりのある窓は記述用の補助に限り、独立標本とは扱わない。
- **副窓長 L = 4,000 本**: VR(60)・`acf_20` の推定精度のための**感度分析に固定**(独立した分析対象ではなく、主分析と同じ規則を、窓長だけ変えて適用する)。DDM 側は A1 の run の最初の 4,000 足、実市場側は重ならない 4,000 分の窓。
- **除外規則(結果を見る前に固定)**: 欠損、ゼロリターンのバーの割合が閾値を超える窓(HistData はフラットなバーが多い。P4 でフラットブロックの ATR=0 を経験済み)。閾値はコードの実行前に保存する。除外数は層別に報告する。

### 6.4 市場状態の分類
- **主**: 推定期間の ATR(既存の定義)の分位点(既存と同じ 20 バケットの境界)を**層別変数(攪乱要因)**として使う。マッチングの目的変数にはしない。
- **日中季節性**: 時間帯(1 時間ごと)で層別した窓数と統計量の分布を記録し、時間帯を揃えた比較を頑健性の確認に使う。
- **補助(探索のみ)**: M の空間でのクラスタ。結論には使わない。

### 6.5 データ品質と異常値
異常値の**除去はしない**(重い裾が主題)。外れ値の影響は、頑健な指標と、上位 1% の窓を除いた感度分析で確認する。統計量の推定誤差は、窓内ブロックブートストラップ(iid 近似は重い裾・クラスタリングで過小評価するため)で推定する。

### 6.6 比較可能性(時間スケール・単位の組み合わせ)
- 主: **DDM の TPC=20 と実市場の 1 分足**を組み合わせる(**慣習的な対応であり、実時間の対応ではない**。§1.3)。
- 感度分析: DDM の TPC ∈ {10, 20, 40} × 実市場の足 ∈ {1, 2, 5 分} の 9 通りの組み合わせで、到達可能な窓の割合がどう変わるかを報告する(**探索的。主結果の選択には使わない**)。

## 7. マッチング方法と残差評価方法

### 7.1 統計量の分離と依存関係(主分割 PA に固定)
統計量を、**マッチング用 M**と**評価用 E**に互いに素に分け、事前に固定する。

| 分割 | M | E | 位置づけ |
|---|---|---|---|
| **PA(主・固定)** | `acf_1`、尖度、`volclust_50` | `acf_5`、`acf_20`、VR(20)、VR(60)、歪度 | **主分析。主結論はこの分割のみ。**VR(5) は `acf_1` から機械的に決まるため E に入れない |
| PB(感度) | `acf_1`、`volclust_50` | 尖度(と頑健な裾の指標)、歪度、`acf_5`、`acf_20`、VR(20)、VR(60) | **感度分析のみ。**主結論の選択には使わない |
| PC(感度) | VR(20)、尖度 | `acf_1`、`acf_5`、`acf_20`、`volclust_50`、歪度 | **感度分析のみ** |

**E の各統計量と M の依存関係**(「独立した評価」ではなく、「M を条件とした関係」を調べる):

| E | M との数学的・統計的な関係 | 解釈 |
|---|---|---|
| `acf_5` | `acf_1` と同じ過程の自己相関の別のラグ。過程の形(減衰の速さ)を反映し、`acf_1` と統計的に相関する | M を揃えたとき、自己相関の**減衰の形**が同じか |
| `acf_20` | 同上。ラグが遠く、推定誤差の割合が大きい | 同上(推定誤差が大きいため、判定は慎重に) |
| VR(20) | ラグ 1〜19 の自己相関の加重和で、**`acf_1` を含む**(数学的な関係) | M(`acf_1`)の寄与を除いた、**中間ラグの構造**の差 |
| VR(60) | ラグ 1〜59 の加重和で、`acf_1` を含む | 同上、より長い範囲(L=1,000 では推定誤差が大きく、L=4,000 の感度分析で補う) |
| 歪度 | 尖度と、重い裾では連動する(統計的な関係) | 尖度を揃えたときの、分布の**非対称性**の差 |

**結果の表現**: PA の残差を、**「DDM の再現性を独立に示す証拠」とは呼ばない**。「M を条件としたときの E の**条件付き分布、および E | M の関係**の、DDM と実市場の差」として報告する。VR(20) など M と数学的に関係する E は、その関係を明記する。

### 7.2 マッチングの手順

1. **DDM 側の各パラメータ点 θ**: **SA の seed**から、窓(1 run あたり 5 つ)ごとに M を計算し、run ごとの平均を取り、点の M ベクトル `M(θ)` を seed 平均で、seed 間 SE を **run 単位**(窓は run 内で相関するため)で算出する。
2. **資格条件(seed ノイズの扱い。caliper の拡張ではなく資格として扱う)**: 点 θ が**判定可能**であるのは、すべての M 成分 j について `SE_seed,j(θ) ≤ c_j / 2`(c_j は下記の成分 caliper)のとき。そうでない点は「**判定不能**」として、到達可能な窓の数には含めず、**判定不能な点の割合を報告**する。**事前のフォールバック規則**: 尖度の成分で判定不能な点が A1 の全点の 50% を超える場合、M の尖度を、頑健な裾の指標(分位点比)に置き換える(置き換えは A1 の結果のうち、この割合だけで機械的に決まる。実市場のデータは見ない)。
3. **caliper(成分ごと。主)**: `c_j = 0.5 × SD_j`。`SD_j` は **R-A の実市場の窓間 SD**(M 成分 j の、重ならない窓の標準偏差)。実市場の窓 w が点 θ に**到達可能(成分ごとの判定)**⇔ すべての j で `|M_j(w) − M_j(θ)| ≤ c_j`(**箱型**)。
4. **標準化ユークリッド距離(感度分析。主の判定より厳しい)**: `z_j = (M_j(w) − M_j(θ)) / SD_j` として、`‖z‖₂ ≤ 0.5` を、別の到達可能の判定として**別に報告**する(箱型 `|z_j| ≤ 0.5` より狭い領域)。**2 つの判定を混同しない。**マハラノビス距離は使わない(範囲の絞り込み)。
5. **到達可能な窓の割合**: R-A の実市場の窓のうち、**判定可能な DDM の点の 1 つ以上に、箱型で到達可能な窓**の割合を、主要評価指標として、(i) 全体、(ii) ATR 層別、(iii) 時間帯別に報告する。**どの M 成分が到達を妨げているか**(その成分だけ caliper を外すと到達可能になる窓の割合)も報告する。
6. **評価の seed**: **E の評価には SB の seed を使う**(M の距離で点を選んだ SA の seed とは別。選択バイアスの抑制)。C では**追加の DDM 生成をしない**。

### 7.3 残差評価とノイズの床

- **主指標**: 各 E の統計量 j について、標準化した差 `d_j = (E_DDM − E_real) / σ_j`。**σ_j は、M-近傍の実市場の窓間 SD**(標準誤差ではない)。
- **不確実性を 2 層に分ける**(合算しない): (a) DDM 側: 点の seed 間ばらつき(SB の seed を単位)、(b) 実市場側: 窓間(週ブロックのブートストラップ)。期間間の変動は、下記のノイズ床と検証期間で別に扱う。
- **ノイズの床(実市場同士。R-B を使う)**:
  - **構成**: R-B の各窓 w' について、**R-A の窓のうち、M が箱型 caliper 以内にあるもの**を参照集合とし、E の差 `d_j^rr = (E(w') − E(参照集合の平均)) / σ_j` を計算する(DDM との比較と同じ形)。
  - **判定基準**: 各 E について、`|d_j^rr|` の **95 パーセンタイル**を「ノイズの床」とする。DDM との差 `|d_j|` がこの値を超える場合に、**ノイズの床を超える残差**とする。
  - この値は、**DDM の結果を見る前に計算して、コミットで固定**する。R-A の窓は参照側にのみ使い、閾値の選択には R-B の窓だけを使う。**検証期間はノイズ床の算出に使わない。**
  - 同一週のブロックを R-A/R-B に分けることで、隣接する窓の自己相関による漏れ込みを抑える(週境界で窓を切る)。
- **検証期間(再現確認)**: 推定期間で凍結した規則(caliper、距離、分割 PA、ノイズ床の閾値)を、検証期間の窓にそのまま適用し、(i) 到達可能な窓の割合、(ii) PA の E の残差の符号・大きさが一致するかを報告する(§10)。
- **p 値は主判定に使わない。**確認的な比較(PA の E の 5 つ)にのみ、Holm 補正を適用した区間を併記する。PB・PC と他のすべては探索として扱う。
- **E | M の関係の比較**: 実市場の窓で E を M に回帰した関係(ノンパラメトリック)と、DDM で同じ関係を描き、**関係そのものの違い**(傾き・曲率)を比較する。

## 8. 対照群・アブレーション・検証用データの設計

- **探索 / 検証の分離**: 領域の推定・距離・caliper・分割・ノイズ床の閾値の確定は推定期間のみ。確定したら**コミットして凍結**。検証期間で同じ手順を適用する。
- **対照 1(実市場同士)**: §7.3 のノイズの床。
- **対照 2(DDM 同士・陽性対照)**: パラメータの異なる 2 つの DDM を M でマッチさせたとき、E が異なるか(DDM 内でも E | M が変わるなら、実市場との差の解釈が変わる)。A1 の SB のみで実行でき、追加生成は不要。
- **対照 3(単純な生成過程。予備的)**: (a) 尖度を合わせた iid Student-t、(b) GARCH(1,1)-t(推定期間で当てはめ)。M をマッチさせた後の E の残差を DDM と並べる。
- **アブレーション**: 機構を 1 つずつ加え・外す(A3 の主効果の再利用)。
- **時間窓・集約幅の変更**: L=1,000 vs 4,000(感度分析)、TPC と実市場の足幅の 9 通り(§6.6)、集約プロファイル。
- **seed**: SA と SB を入れ替えた再計算(領域の境界・到達可能な窓の割合の安定性)。

## 12. 未確定事項・実験開始前に確認すべき事項

**v0.2 で確定した事項(レビューで異論があれば指摘をお願いします)**: A1 は 176 点 × 10 seed × 10 万約定。TPC は {10, 20, 40}、約定単位の整数ティックを保存。主目的は統計的形状の比較で、実時間の対応と活動量は範囲外。M・E の分割は PA を主に固定。caliper は成分ごとの箱型を主に、ユークリッド距離を感度分析に。ノイズ床は R-B で算出。減衰型ショックは A3 の主軸にしない。

**引き続き確認が必要な事項**:
1. **`delta` の定義**: アトラスの `delta`(`dealer_sensitive` の範囲の平行移動)を探索変数として使い続けてよいか。範囲の幅を動かす場合は別計画。
2. **単位・尺度**: std を M・E に入れず H1s の補助とする方針でよいか。ショックのサイズは「`spread=1.0`・`initial_price=100` の尺度で較正」されているため、それらを動かす場合は再較正が必要。
3. **実市場データの範囲**: `usdjpy_1min_volatility.parquet` の期間・欠損・フラットバーの割合は未確認。HistData の他の通貨ペアの使用範囲。期間分割(推定・検証・final)を、これまでと同じにしてよいか。final 期間を本計画で使わない方針でよいか。
4. **`num_agent`**: A2-0 の 3 点の選択規則と、「動く」の基準(seed 間 SE の 3 倍)でよいか。高い側(500〜5000)の有界性の既存の結果は保存されていない。
5. **初期過渡**: A1 は燃焼期間なしでよいか(P3 の結果は予測分布への影響についてのもので、M・E への影響は未確認)。必要なら、最初の 1 つの窓を除外する規則を事前に入れる。
6. **DDM の乱数**: `random` と `numpy` の両方に seed を設定する(`calibrate_ddm.py`)。ビット一致の再現性の確認(P5-B 第 2 段階と同じ基準)を行うか。`wma` の重みが seed ごとに抽選される点は、seed 間変動に含めてよいか。
7. **計算予算**: 最小経路で約 7.6 CPU 時間(壁時間 約 25 分)、全体で約 13.7 CPU 時間の上限(各段階 2 倍)でよいか。
8. **Study Manager の登録**: 承認後に、どの Goal の下に登録するか(#885 または新しい Goal)。
9. **R-A/R-B の分け方**: ISO 週の偶奇でよいか(別の決定的な規則を希望するか)。
10. **PB・PC**: 感度分析としての定義でよいか。
