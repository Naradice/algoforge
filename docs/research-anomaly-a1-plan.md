## 1. 問いと位置づけ

予測分布から見て直前の 1 時間がどれだけ外れていたかを、価格だけの単純な基準に足すと、次の 1 時間の急変動の始まりを、同じ警報率でより多く検出できるか。

- 結果は、この定義の急変動の事前予測についての、事前登録した判定。「市場異常の検知」一般の結果ではない。
- 精度の見込みは §6。**判定保留になる可能性が高いことを承知して行う。**

## 2. 対象

| 項目 | 内容 |
|---|---|
| 原点 | 行 0 から 60 本ごとのブロックの最後の行(F1 と同じ)。更新間隔 1 時間 |
| 有効な原点 | ブロックが連続(300 秒超の欠損なし)、直前の原点から連続、ブロックの実現分散が正、次の 60 本が連続して同じ期間内 |
| ラベル | `V(t, 60)`(次の 60 本の 1 分対数収益の 2 乗和)> **3.50644102796436×10⁻⁶**(推定期間の 95% 点。A0 で確定) |
| イベント | 陽性の原点の行の差が 240 以下なら 1 つ。開始は最初の陽性の原点 |
| 検出 | イベントの開始の原点で警報が出ている |
| 推定 | 2016-08-31〜2020-08-31 |
| 検証 | 2020-09-01〜2021-08-31 |
| **評価** | **2026-12-01〜2030-05-31(42 か月)**(ファイルの時刻 = ブローカー時間)。終了日は固定し、途中で延長・短縮しない |
| 履歴(モデルの拡大窓のみ) | 2022-09-01〜2026-11-30。使用済み・利用不明の期間を含むが、評価より過去の学習データとしてのみ使う |
| 2021-09-01〜2022-08-31 | 履歴の一部。判定には使わない |

**除外(時刻だけで決め、イベントを作る前に適用する)。** 直前の原点が有効でない原点。直前の窓・原点のブロック・ラベルの窓に、日曜の日付の行を含む原点(感度として除かない場合も報告)。

## 3. データ

| 項目 | 内容 |
|---|---|
| 取得元 | OANDA 証券の MT5 ティック `ticks_USDJPY-oj5k_YYYY-MM.zip`(マイページから。**取得は利用者の操作**) |
| 1 分足 | 各分の**最後の ASK**を終値とする。ティックのない分は作らない。時刻はブローカー時間のまま |
| 系列の構成 | 既存の主系列(SHA-256 `c25eb572…a828`、2022-08-31 17:59 まで)は変えず、その後ろに新しい行を足す(ブロック番号と乱数を保つ) |
| 必要なファイル | 照合用 2022-08(取り直し)、履歴 2022-09〜2026-11(51 本)、評価 2026-12〜2030-06(43 本。ファイルは日本時間の月で区切られるため、末尾に 1 本余分に要る) |
| 保管 | `L:\data\fx\anomaly_a1_forward\` に取得したまま置き、読み取り専用にする。リポジトリには台帳(ファイル名、取得日、バイト数、SHA-256、行数、先頭と末尾の時刻、重複、欠損、日曜の行数)だけを入れる |
| 期末までに読むもの | 評価期間のファイルは、**日付と時刻の列だけ**(台帳の作成)。価格は読まない、描かない、集計しない。**イベント数も確認しない** |

履歴のファイルは公開が打ち切られる可能性があるので、承認後早めに取得する。評価のファイルは毎月、前月分を取得する。

**データの検査(失敗したら停止して報告)。**

| 検査 | 合格 | 時期 |
|---|---|---|
| 取り直した 2022-08 から作る 1 分足が、主系列の同じ範囲と時刻・終値とも一致 | 完全一致 | 取得後すぐ |
| 欠けた月がない | 必要なファイルがすべてある | 評価の前 |
| 日曜の行を除いた週の最初の行が月曜 00:00〜00:29(時刻の基準が変わっていない) | 履歴と評価のそれぞれで 95% 以上の週 | 評価の前 |
| 作成した 1 分足の行の時刻の逆行・重複(同じ分が 2 つのファイルにないことを含む) | 0 | 評価の前 |

ティックには同じ時刻の行が通常あるので停止の理由にしない。ティックの時刻の逆行は台帳に記録して報告する。

配信元がサーバー時刻、通貨ペアの名称、ファイル形式を変えたことが分かった場合も停止する。

## 4. スコア(すべて原点 t までの情報)

| 名前 | 定義 |
|---|---|
| 不適合度 S(主) | `|2u − 1|`。u は、直前の原点の B7N(HAR-RV、正規イノベーション)の 1 窓先分布による、直前の窓の収益の乱択 PIT |
| 基準の候補 | ① 直近 1 ブロックの実現分散、②③④ 直近 4・24・120 の有効ブロックの平均実現分散、⑤ 直近ブロックの ATR(59 の絶対差の平均)、⑥ 直近の窓の絶対収益、⑦ ③ × 時刻の係数 |
| 対照 C | 直前の窓の絶対収益 ÷ その窓より前の 24 個の有効な窓の収益の標準偏差 |

- ブロックの実現分散は、ブロック内の 59 の収益の 2 乗和。
- ⑦の係数は、原点の月の開始より前のデータで、ブロックの終わりのニューヨーク現地時刻(ファイルの時刻 − 7 時間)ごとの平均ブロック分散 ÷ 全体平均。原点の時刻 + 1 時間の現地時刻の値を使う。
- **PIT の作り方は F1 のコード(`db0926f` の `f1_models`・`f1_run`)と同じ:** 状態は各月の開始より前のデータで作る。予測の標本は(モデル, ブロック番号)を seed とする 1,000 本。実現値は `log C1 − log C0`。乱択は(99, モデル, h, 月, 年)を seed とし、F1 の原点の集合の順に割り当てる。除外はその後に適用する。
- 基準 B は、①〜⑦のうち検証期間の検出率(警報率 0.05)が最大のもの。同点は番号の小さい方。

## 5. 組み合わせ・指標・判定

| 項目 | 内容 |
|---|---|
| 組み合わせ | 正則化なしのロジスティック回帰。入力は 2 つのスコアそれぞれの推定期間の経験分布関数の値。目的は原点ごとの陽性。推定期間(2017-09〜2020-08)で当てはめて凍結 |
| 警報 | 評価期間の原点のうち、スコアの大きい順に `floor(α × 原点数)` 個。同点は時刻の早い順。主 α = 0.05、感度 0.02・0.10 |
| 主比較 | `Δ` = 検出率(B+S)− 検出率(B)。`Δc` = 検出率(B+C)− 検出率(B) |
| 区間 | 週ブロック(原点の時刻 + 6 時間の ISO 週)のブートストラップ 10,000 回、百分位の両側 95%、seed 20261301。反復ごとに警報の順位を取り直す |
| δ_A | **0.05** |
| 支持 | `Δ` の下限 > δ_A かつ `Δ − Δc` の下限 > 0 |
| 上乗せなし | `Δ` の区間が ±δ_A 内 |
| 保留 | 上記以外。実現したイベントが N_min = 100 未満の場合を含む(値は計算して報告する) |

支持は 2 つの下限を両方要求するので、多重性の調整はしない。主比較は 1 つ。

## 6. 精度の見込み(仮定による計算)

イベント数は、推定・検証の 5 年の 12 か月ごとの件数(226・104・55・67・30)から見込む。2 方式の検出が食い違う割合 d を 0.05・0.10・0.20 とした `Δ` の 95% 区間の半幅(イベントの依存は無視。依存があれば広がる)。

| 発生率の想定 | 42 か月のイベント | 半幅 | 支持に必要な `Δ` の点推定 |
|---|---|---|---|
| 5 年の中央値(年 67) | 約 235 | ±0.029・±0.040・±0.057 | 約 0.08〜0.11 |
| 5 年の最小(年 30) | 約 105 | ±0.043・±0.060・±0.086 | 約 0.09〜0.14 |

- 最小の発生率が続く場合、下限 100 に対する余裕は小さい。これより静かなら 100 に届かず判定保留になる。**期間は延ばさない。**
- 件数が足りても、効果が小さければ判定保留になる。この 2 点を承知して行う。
- 「上乗せなし」は半幅が δ_A より小さい場合にしか出ない。

- ライブラリは F1 と同じ版(`arch==8.0.0`、numpy 2.3.3、scipy 1.17.1、pandas 3.0.1、statsmodels 0.14.6)を使う。版が違って再現できなければ停止する。

## 8. 副次(判定に使わない)

- スコア単独の比較(S、C、①〜⑦)
- ロジスティック回帰と `HistGradientBoostingClassifier`(既定値、seed 20261302)。特徴は直近 24 ブロックの収益、①〜④、ニューヨーク現地の時刻と曜日。推定期間で当てはめ。これに S を足した上乗せ

## 10. 解釈の限界

- 閾値、組み合わせ、基準の選定は 2016〜2021 年で決める。5〜14 年離れた期間に適用するので、実現イベント数も性能も大きく変わりうる。
- 検出するのはイベントの始まりで、全方式で検出率が低くなりうる。組み合わせは原点ごとの陽性で当てはめるため、目的と指標は完全には一致しない。
- 終値は ASK。気配の幅の変化がラベルとスコアに入る。
- 前向きなのは A1 の設定に対してである。市場の出来事は研究者の目に触れ、他の研究や運用は同じ期間を使いうる。凍結後は設定を変えない。
- B7N の予測の単位は 60 本で、毎分の検知や超短期への結論は出せない。
- A0 の選定は 95% 点と最小間隔 240 本に依存する。
