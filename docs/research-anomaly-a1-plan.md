# A1 実験計画(案)v0.1: 直前 1 時間の予測分布の不適合度は、次の 1 時間の急変動の予測に上乗せを持つか

- 状態: **下書き。未承認。実行していない。** A0(#897)の成果物。仮説 #896、親 Goal #887。
- 評価の型は A0 の手順書(`research-anomaly-a0-protocol.md`、`12c98bf` でイベント数を数える前に固定)の §6。本書は、選んだ候補への当てはめと、A0 で分かった事項への対応を足したもの。
- 結果の位置づけ: **指定した期間での探索的な分類。** 評価期間は繰り返し使われている。

## 1. 問い

予測分布から見て直前の 1 時間がどれだけ外れていたかを、価格だけの単純な基準に足すと、次の 1 時間の急変動の始まりを、同じ警報率でより多く検出できるか。

## 2. 対象(A0 の選定: 分類 4、候補 C-M1)

| 項目 | 内容 |
|---|---|
| 系列 | `usdjpy_1min_volatility.parquet` の `close`(SHA-256 `c25eb572…a828`)。時刻はニューヨーク時間 + 7 時間 |
| 原点 | 60 本ごと(F1 と同じ)。更新間隔 1 時間 |
| ラベル | `V(t, 60)`(次の 60 本の実現分散)> 3.506×10⁻⁶(推定期間の 95% 点。A0 で確定) |
| イベント | 陽性の原点の行の差が 240 以下なら 1 つ。開始は最初の陽性の原点 |
| 検出 | イベントの開始の原点で警報が出ている |
| 推定 / 検証 / 評価 | 2016-08-31〜2020-08-31 / 2020-09-01〜2021-08-31 / 2021-09-01〜2022-08-31 |
| イベント数 | 推定期間 454(原点 24,380)。評価期間の見込み 114(下の除外後 約 113)。下限 N_min = 100 |

## 3. 評価期間のデータの扱い(A0 で見つかった事項)

- 2021-06-27 以降、主系列には**日曜 22・23 時(ファイルの時刻。ニューヨークの日曜 15・16 時で市場の開始前)の足**がある。推定期間にはほとんどない(11 行)。中身は調べていない。
- **主の扱い:** 直前の窓・原点のブロック・ラベルの窓のいずれかに、日曜の日付の行を含む原点を除く。時刻だけで決まる。
- **感度:** 除かない場合も報告する。判定には使わない。
- 不適合度には直前の原点が有効である必要がある。評価期間の原点は 6,123 → 両方の条件で 6,049。
- 推定期間・検証期間にも同じ除外を適用する。

## 4. スコア(すべて原点 t までの情報)

| 名前 | 定義 |
|---|---|
| 不適合度 S(主) | `|2u − 1|`。u は、原点 t−60 の B7N(HAR-RV、正規イノベーション)の 1 窓先分布による、窓 (t−60, t] の収益の乱択 PIT。検証・評価は F1 の保存値(`pit`)。推定期間は同じコードで生成 |
| 基準の候補 | ① 直近 1 ブロックの実現分散、②③④ 直近 4・24・120 の有効ブロックの平均実現分散、⑤ 直近ブロックの ATR、⑥ 直近の窓の絶対収益、⑦ ③(24 ブロックの平均)× 次の窓の時刻の係数(係数 = 原点の月の開始より前のデータの、ニューヨーク現地時刻別の平均ブロック分散 ÷ 全体平均) |
| 対照 C | 直前の窓の絶対収益 ÷ その窓より前の 24 個の有効な窓の収益の標準偏差 |

- ブロックの実現分散は、ブロック内の 59 の収益の 2 乗和。
- 基準 B は、①〜⑦ のうち検証期間の検出率(警報率 0.05)が最大のもの。同点は番号の小さい方。**評価期間のラベルを読む前に B を固定して commit する。**

## 5. 組み合わせ・指標・判定

| 項目 | 内容 |
|---|---|
| 組み合わせ | 正則化なしのロジスティック回帰。入力は 2 つのスコアそれぞれの推定期間の経験分布関数の値。目的は原点ごとの陽性。推定期間(最初の 12 か月を除く)で当てはめ、凍結 |
| 警報 | 評価期間の原点のスコア順位の上位 5%(感度 2%・10%) |
| 主比較 | `Δ` = 検出率(B+S)− 検出率(B)。`Δc` = 検出率(B+C)− 検出率(B) |
| 区間 | 週ブロック・ブートストラップ 10,000 回、両側 95%、seed 20261301。反復ごとに順位の閾値を取り直す |
| δ_A | **0.05(提案値。承認で確定)** |
| 支持 | `Δ` の下限 > δ_A かつ `Δ − Δc` の下限 > 0 |
| 上乗せなし | `Δ` の区間が ±δ_A 内 |
| 保留 | 上記以外。評価期間の実現イベントが 100 未満の場合を含む(値は計算して報告する) |

**精度の見込み(仮定による計算で、データからではない)。** イベント 113、2 方式で検出が食い違う割合 d を 0.05・0.10・0.20 と仮定すると、`Δ` の 95% 区間の半幅はおよそ ±0.04・±0.06・±0.08(イベントの依存は無視。依存があれば広がる)。δ_A = 0.05 では、支持には `Δ` の点推定がおよそ 0.09〜0.13 必要で、「上乗せなし」は d が小さい場合しか出ない。**判定保留になる可能性が高い。**

## 6. 副次(判定に使わない)

- スコア単独の比較(S、C、①〜⑦)
- 線形(ロジスティック)と勾配ブースティング(`HistGradientBoostingClassifier` の既定値、seed 20261302)。特徴は直近 24 ブロックの収益、①〜④、ニューヨーク現地の時刻と曜日。推定期間で当てはめ。これに S を足した上乗せ

- 次の窓の超過確率(変動の予測であって不適合度ではない)
- PR-AUC、誤警報率、過去の閾値(直近 12 か月の上位 5%)での検出率と実際の警報率、検出の重なり、B7N の校正
- 層別: ニューヨーク現地の時間帯(0–8、8–16、16–24)、ATR 5 群

## 8. 解釈の限界

- 評価期間は探索的で、2022 年は変動が大きい局面。推定期間の閾値を使うため、実現イベント数は見込みと大きく違いうる(超過が続くと 1 つにまとまり、減ることもある)。
- 検出するのはイベントの**始まり**で、直前は陽性でない。変動の持続性が効きにくく、全方式で検出率が低くなりうる。組み合わせは原点ごとの陽性で当てはめるため、目的と指標は完全には一致しない。
- B7N の予測の単位は 60 本で、毎分の検知や超短期への結論は出せない。
- A0 の選定は、95% 点と最小間隔 240 本に依存する(99% 点や 1,440 本では、どの候補も N_min に届かない)。
- 上乗せが支持されても、「市場異常の検知」ではなく、この定義の急変動の事前予測についての結果である。
