## 1. 判定

前提は両方の比較で成立した(依存なし基準の効果の下端はすべて 0.03 超)。

| 条件 | 固定時間の持続 `G_X` [95%] | 依存なし基準 `G_RWX` | 残る割合 `ρ_X` [95%] | base との差 `Δ_X` [97.5%] | 判定 |
|---|---|---|---|---|---|
| base(全員逆張り) | 0.045 [0.040, 0.050] | 0.155 | 0.29 [0.26, 0.32] | — | — |
| zero(項なし) | 0.105 [0.097, 0.112] | 0.161 | 0.65 [0.62, 0.68] | **+0.36 [+0.30, +0.42]** | **打ち消しが大きく減る** |
| mix(半々) | 0.094 [0.084, 0.105] | 0.159 | 0.59 [0.53, 0.64] | +0.30 [+0.23, +0.36] | 打ち消しが大きく減る |

**仮説の結論(`Δ_zero` で決める): 支持。**

### この「支持」の強さについて

仮説の文は「逆張りのトレンド項が**主な原因**」だが、事前の規則は「差が 0.2 を超える」で、**主な原因であることまでは示していない**(規則と文の強さが合っていなかった。計画の書き方の問題である)。

- base で失われる割合は 1 − 0.29 = 0.71。
- 項を取って戻るのは 0.36。
- **項がなくても 0.35 は失われたままである。**

戻る分と残る分は同じ程度で、「大きな原因の 1 つ」と読むのが妥当である。この比較は結果を見た後の読み方で、判定には使っていない。

## 3. 副次指標(判定しない)

時計が順序ありの場合(括弧内は並べ替え)。

| 条件 | F | 60 秒足の分散比 Σr²/ΣQ | 約定数の四分位ごと(少 → 多) | 尖度 |
|---|---|---|---|---|
| base | 0.045 (0.000) | 0.18 (0.19) | 0.38 / 0.24 / 0.19 / 0.12 | 0.7 |
| zero | 0.110 (0.005) | 0.63 (0.71) | 0.86 / 0.78 / 0.72 / 0.51 | 1.0 |
| mix | 0.095 (0.002) | 0.59 (0.67) | 0.82 / 0.78 / 0.68 / 0.46 | 1.3 |

| 条件 | 約定ごとの収益の自己相関(ラグ 1 / 2 / 3 / 4 / 5) | 20 約定足のラグ 1 | 価格の範囲(全 run の最小〜最大) |
|---|---|---|---|
| base | −0.15 / −0.12 / −0.12 / −0.12 / −0.12 | −0.28 | 100.36〜101.99 |
| zero | −0.05 / −0.02 / −0.01 / −0.01 / −0.01 | −0.21 | 100.89〜101.10 |
| mix | −0.07 / −0.02 / −0.01 / −0.01 / −0.01 | −0.24 | 100.85〜101.15 |

- base の値 `ρ` = 0.29 は、別の seed の DP2(約 0.26)と近い。
- 逆張りの項は、参照する 5 約定の範囲で負の自己相関を作っていて、項を取るとラグ 2〜5 の値はほぼ消える。
- zero と mix でも、約定数が多い足ほど打ち消しが強い。
- zero と mix は、価格の動く範囲が base より狭い。20 約定足の負の自己相関も残る。**60 秒より長い足での打ち消しは調べていない。**

## 4. 読み方

**言えること**

- この変更モデルでは、逆張りのトレンド項を取る、または半分を追随にすると、60 秒足に残る時計の持続の割合が大きく増えた(0.29 → 0.65、0.59)。固定時間の持続そのものも 0.045 から 0.105、0.094 に増えた。

**限界**

- 項がなくても打ち消しは残る。その原因(売買の成立の仕組みなど)は特定していない。
- 依存なしの基準(約 0.16)にも届かず、時計の持続が長いラグで続くわけでもない。
- zero と mix の差は比べていない。
- 結合なし、参照は直近 5 約定、係数の大きさは [1.5, 3.5]、時計 K-long、60 秒足に限る。全員追随は調べていない。
- 合成データだけで、実市場の仕組みについての主張はしない。不確かさは seed 間のものだけである。
