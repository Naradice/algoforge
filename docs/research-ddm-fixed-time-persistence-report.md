## 4. 読み方

**言えること**

- この時計は、約定間の依存がなければ、60 秒足に 0.17 の持続を生む。
- 結合なしの DDM では、その約 4 分の 3 が失われた(主な原因)。
- 結合ありの DDM では 0.006 まで下がる。結合による追加の損失(割合 0.22)の大きさは、基準に対して判定できなかった。

**副次の値の読み方(判定ではない。計画 §5 で先に書いた目安との照合)**

- A: U では、約定数が多い足ほど分散比が小さい(0.41 → 0.12。順序あり)。足の中で値動きが打ち消し合う、という目安と合う。U の √Q の持続(0.53)は RW(0.57)に近いので、失われ方は「約定の 2 乗値動きの合計」から「足の正味の値動き」の段階にある。
- B: 約定数と 1 約定あたりの値動きの順位相関は、U の +0.18 に対し C は −0.12 だった。約定が少ない足ほど 1 約定の値動きが大きい、という目安と合う。C では √Q の持続自体が 0.13 に下がる。
- この順位相関は、依存のない RW でも 0 にならない(+0.18)。値は系列の間の比較にだけ使う。

**限界**

- A は約定の順序に関する依存の全体を指す。**逆張りのトレンド項が原因だとは特定していない**(項を変えた条件がない)。
- どう直せば固定時間の足に持続が出るかは調べていない。
- RW でも 0.17、ラグ 20 で 0.11 で、実市場の分足の値(Study Manager #32、定義が違う: ラグ 5 で 0.29)より小さい。時計の記憶の長さにも限りがある。
- この変更モデル、時計 K-long、60 秒足に限る。実市場の仕組みについての主張はしない。
- 不確かさは seed 間のものだけである。
- この仮説は DP1 の副次結果を見た後に立てた(別の seed で調べた)。
