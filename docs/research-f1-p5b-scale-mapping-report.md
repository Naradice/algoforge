# F1 後続 P5-B: ATR バケット別の尺度対応(M1 統計量 → 60 分足の予測分布)の機構の識別 — 第 1 段階の結果報告

- 対象計画: `docs/research-f1-p5b-scale-mapping-plan.md` v0.2(コミット 5277e17、承認済み)。承認範囲: 第 1 段階(事前ゲート、分析 A〜E)。**第 2 段階(経路の再生成)は承認対象外で、実施していない。**
- 実行コード: `backend/research/p5b_scale/`(コミットしてから実行)。結果: `backend/research/p5b_scale/results/`(`gates.json`、`analysis.json`、`p5b_tables.md`)。
- 保存済みのアンサンブル(C0s、C3)、マッピング、アトラス、生データだけを使用。DDM・マッピング・アトラスの改修、尺度係数の最適化、新規アンサンブルの生成はしていない。F1〜P5-A の既存結果は変更していない。p 値による判断はしていない。
- 「整合的」は観測の記述であり、原因の確定ではない。分解は代数的な恒等式であり、**M1 項と M3 項の内訳は仮定 A_config(アトラスの std を、アンサンブル設定の M1 std の代理として使う)に依存する**。

## 0. 要約

1. **事前ゲートはすべて通過した**(§1)。マッピングの再現(窓ごとの標準偏差が `real_stats` と一致、std 優先の選択規則が 20 バケット × 8 候補と順序まで一致)も確認した。
2. **ショックあり・なしの保存済みアンサンブルの観測差(C0s と C3)は、ATR にほぼ依存しない**: 90% 幅の比は h1 で 1.20〜1.40(バケット間の順位相関 0.00)、h4 で 1.09〜1.46(0.05)。M2 の仮説(ショックの絶対サイズが一定なので低 ATR ほど相対的な寄与が大きい)は、この観測差では**支持されない**。ATR 依存は**ショックなしの C3 でも同じ強さで残る**(C3 の 90% 幅/E1a の比はバケット 0 で 1.15、バケット 16 で 0.39。順位相関 −0.995)。
3. **M1(アトラスの被覆)**: アトラスの有効点 170 のうち最小の std は 1.29×10⁻⁴ で、**バケット 0〜13 の実現値の M1 std(7.4×10⁻⁵〜12.5×10⁻⁵)はアトラスの最小値を下回る**(14 バケット)。実現値の std の ±10% 以内にアトラス点があるのはバケット 11 以降で、バケット 0〜5 は ±25% 以内にも 1 点もない。バケット 0〜13 では、std 優先の shortlist(30 点)がすべて実現値の std より大きい。8 候補の std の対数比の平均は、バケット 0 で +0.60(約 1.8 倍)、バケット 8 で +0.23、バケット 15〜18 で約 −0.01〜−0.02。**符号は DDM が広い側**(`best_std_ratio` は符号を持たなかった)。
4. **M3(時間集約)**: 仮定 A_config のもとで、C3 の暗黙の分散比 VR_C3 は、バケット 0〜16 で h1〜h24 を通して 0.20〜0.57(h1 は 0.21〜0.49、h4 は 0.22〜0.39)で、実現値の VR_real(0.48〜1.23)より低い。8 候補の M1 の acf_1 は平均 −0.28〜−0.37 で、実現値の −0.01〜−0.04 と大きく違い、尖度は 3.3〜7.5(バケット 19 のみ 12.8)で実現値の 13〜20 より低い。**DDM の M1 収益は強い負の 1 次自己相関を持ち、60 分足に集約すると分散が小さくなる**ことと整合的。
5. **分解**(バケット 0〜16、対数比 log(sd_C0s/sd_E1a) = M1 + M3 + M2): M1 は ATR とともに +0.55(バケット 0)から約 −0.06(バケット 16)へ単調に低下する(順位相関 −0.99)。M3 の平均は −0.50〜−0.64(h1〜h24)、M2 の平均は +0.24(h1)〜+0.60(h24)。**全体の ATR 依存の傾きのうち、M1 項が占める割合は h1 で 65%、h4 で 84%、h12 で 121%、h24 で 142%、M3 項は 43%、5%、0%、−65%、M2 項は −8%、11%、−21%、23%**(傾きの比。記述のみ)。ただし、**M1 と M3 の内訳は A_config に依存**し、両者の和は変わらない。
6. **最上位 ATR バケット(17〜19)は別の挙動**: VR_C3 が 1.6〜2.0 と 1 を超え(M3 項が +0.2〜+0.6)、全体の比が +0.2〜+0.5(DDM が広い側)。アトラスの高 std 側は点が疎で、shortlist の std の範囲が広い(バケット 19 で対数比 −0.33〜+0.28)。
7. **M5(バケット定義と前向き窓)**: ATR の中央値と前向き窓の標準偏差の両対数の傾きは 0.53(20 バケット)。バケット内の、原点ごとの現在の ATR と前向き窓の標準偏差の順位相関は 0〜0.17(バケット 19 のみ 0.45)。前向き M1 std はバケット内で ATR とほとんど関連せず、バケットの水準に回帰している。
8. **候補集合の被覆(E)**: C0s の h1 で E1a の 90% 幅が候補の範囲内にあるのは 20 バケット中 13、C3 では 7。C0s のバケット 11〜16(C3 ではバケット 4〜16)は、8 候補すべてが E1a より狭い。
9. **次の研究に向けて**: ATR 依存の主な部分は、**ショック条件の違いではなく、M1 マッピング(アトラスの被覆と、acf・尖度が合わない候補)と時間集約**の側にある。M1 項と M3 項の内訳を確定するには A_config の検証(第 2 段階)が要るが、**M1 項のうち「アトラスの最小 std が実現値の std を超える」点は、A_config に依存しないアトラスの性質**である。

## 1. 実行の記録

- 事前ゲート(`results/gates.json`)すべて PASS: 1 生データのハッシュ、P5-A の保存値(E1a の幅、8 候補混合の幅、候補別の幅)を 1e-12 で再現。2 マッピングの再現(使用した 300 窓が欠損なく推定期間内で終わる、窓の標準偏差(ddof = 0)が `real_stats['std']` と 1e-9、累積和による分散が直接計算と 1e-9、std 優先の選択が保存された候補と順序まで一致)。3 アトラスの照合(160 候補が一意に存在し std と seed 間の std が有限)。4 候補復元(C0s・C3 の 3 seed、試行 ID の規則、候補の経路数の割合 0.10〜0.15)。5 分解の恒等性(80 セル、残差 1e-12 未満)と定義の一致。6 将来情報なし(マッピング窓、推定期間の全原点の窓、y の窓が検証期間の開始前に終わる。検証・final の文脈用の窓は各期間内に限定)。
- `√V_real,M1 / real_std`(窓の分散の平均の平方根と、マッピングの標準偏差の平均の比)は、バケットにより 1.04〜1.12。両者の違いは主に「分散の平均」と「標準偏差の平均」の違いで、分解には前者を使った。
- 実装上の判断(計画の趣旨の範囲内): 
  - **窓の定義**: マッピングの窓は `[60j, 60j+1000]` 行(ATR を測るブロック自体を含む)。`V_real,M1` の主定義は、同じ 300 窓の分散の平均。推定期間の全原点の窓での値(√V の比で最大 +14%)を別に併記した。
  - 候補の分散は `σ²_atlas,c = std_c² + (std_std_across_seeds,c)²`、混合は等重み(候補内分散に基づく代理量)。アトラスに候補別の平均がないため、候補間の平均の違いは含まれない(アンサンブル側で候補の平均の絶対値/標準偏差の最大は 0.13)。
  - C0s・C3 の分布は 3 seed をプール(各バケット 3,000 経路)。分解の信頼区間は E1a の y の分散の週ブロック bootstrap(B = 2,000、記述的)で、M1 項と M2 項は点推定(M1 項の不確かさの目安として、バケット 0 の h1 では、窓の分散の標準誤差の相対値(σ に換算)が約 2%、アトラスの seed 間の標準誤差が約 3%)。
  - h12・h24 の VR_real は前向き 1,000 本の分散で規格化した指標(同一時間範囲の分散比ではない)。h1・h4 を主とする。

## 8. 限界

- 仮定 A_config(アトラスの std がアンサンブル設定の M1 std の代理)は第 1 段階では検証できない。M1 項と M3 項の内訳、VR_C3 の値は、この仮定に依存する。アトラスは 1,000 足、アンサンブルは 1,441 足で、初期の過渡の扱いも違う。
- アトラスの σ² は seed ごとの分散の平均の復元値で、5 seed の標本誤差がある。候補間の平均の違いは含まれない(アンサンブルでは小さいことを確認)。
- 使用した 300 窓は、バケット内の全原点の部分標本。√V の全原点版との差は、バケット 15・16 で +9%・+14%、他は ±4% 以内。M1 項の定量値は、この定義に敏感(バケット 15・16)。
- 順位相関は n = 17〜20 の記述で、検定していない。傾きの比(M1 の 142% など)は、他項が逆符号の傾きを持つときに 100% を超える。
- C0s と C3 の差は観測差で、純粋なショック効果ではない。
- 実現値の VR は期間・ATR 群に依存し、推定期間の値が他の期間に当てはまるとは限らない。
- 同一の期間・入力マッピングでの診断で、他の期間・市場への一般化は示さない。final 期間は F1 の判定に使われた期間で、部分的に既知(P5-B では final の結果で基準を変えていない)。
