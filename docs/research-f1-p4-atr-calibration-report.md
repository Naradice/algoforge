## 0. 要約

1. **事前ゲートはすべて通過した**(入力同一性、分解の恒等性、経験分布の実装、パージ、将来情報なし)。
2. **A(構成と群内の変化)**: 検証 → final の 90% 被覆率の低下(h1/h4/h12/h24 で −3.2/−5.4/−6.9/−7.9pp)のうち、**構成の変化で説明できるのは h1 だけ**(構成の寄与 −3.8pp、群内 +0.5pp)。h4〜h24 は群内の寄与が大半(−4.4/−7.0/−7.7pp)で、構成の寄与は 0 付近(h12・h24 は符号が基準の取り方で変わる)。
3. **B(ATR バケットだけの経験分布との比較)**: 推定期間のみで当てはめた経験分布(E1a・E1b・E1c)は、final の h1・h4 で 90% 被覆率が 0.90〜0.91 に較正され、DDM より平均 CRPS が約 2.2〜2.5% 小さい。**DDM の h1・h4 の区間幅不足と ATR 群依存は、同じ ATR 情報だけの別の分布で、期間をまたいでも大きく減る**。推定期間の標本内でも同様(DDM 0.836/0.803、経験分布 0.90)。h12・h24 では差が小さく(final h24 の CRPS −0.35%、区間が 0 を含む)、経験分布も検証期間で過剰被覆、final で不足し、DDM と同じ期間差を示す。
4. **C(追加情報)**: 3 変数(時間帯、ボラティリティ比、直近収益)の追加は、E1a に対して一貫した CRPS の改善を示さなかった(検証の h1・h4 の時間帯のみ −0.4〜−0.7%、final では消える)。ただし評価原点の 28〜82% がセル規則で除外されており、**情報に価値がないとは言えない**。
5. **D(P3 変種)**: C2(60) と C3 でも、検証 → final の h4〜h24 の被覆率低下は群内の寄与が大半で、ショックの時間構造を変えても残る。final の h1・h4 では、経験分布が C2(60) より CRPS で 1.4〜1.9% 小さい。
6. **仮説との整合(§6)**: 構成の変化(HA)は h1 の期間差とだけ整合。群内の時間的変化(HB)は h12・h24 の期間差と整合的で、h1・h4 では主因として必要ない。条件づけ情報の不足(HC)は、今回の 3 変数と評価条件では支持されなかった。**同じ ATR 情報による別の分布が h1・h4 で較正される結果は、DDM のバケット内の分布の幅・形状(HD)と整合的**。ただし、経験分布が DDM より良いことは、DDM の構造的な表現力不足の確定ではない。
7. **解釈上の注意**: Shapley 型の分解は期間差の算術的な分解で、因果効果の識別ではない。B-1 と B-2 の差は、学習データ量の増加と時間的な分布変化の両方を含む。

## 1. 実行の記録

- 事前ゲート(`results/gates.json`)すべて PASS: 1a 生データのハッシュ、1b DDM(C0s)の指標が P3 の保存値を 1e-12 で再現、1c 公平 CRPS(セルごとに標本数が違ってよい実装)が既存実装と一致、2 分解の恒等性(90% 被覆率と平均 CRPS、2 つの順序と Shapley、全体の差は直接の差と一致)、3a CRPS 実装が総当たりと一致、3b E1a の標本内被覆率と順位の整合性(各バケットで 50%・90% が名目値から 0.01 以内)、E1b・E1c の分位点の単調性と CRPS の一致(標本内被覆率は記録のみ)、4 パージ(B-1・B-2 とも当てはめ原点の前向きの窓が評価期間の開始前に終わり、原点は互いに素で時間順)、5 条件づけ変数が原点時点の情報だけで決まる(原点以降の行を書き換えても不変)。
- 計画の曖昧さについての実装上の判断(計画の趣旨の範囲内):
  - 「直近 12 本」は **60 分足 12 本(M1 の 720 行)**。ボラティリティ比は「直近 720 行の平均絶対変化 ÷ 現在ブロックの ATR」、直近収益は `log C_t − log C_{t−720}`。窓に欠損(ギャップ)がある原点、ブロックの ATR が 0 の原点は変数が未定義で、C の評価から除く。
  - 3 分位は **ATR バケットごとに、推定期間(h1 の原点)から**求めた(バケット間の交絡を避けるため)。時間帯は UTC の 3 区分。
  - 経験分布の被覆率・PIT は、2,000 点の分位点格子から計算し、CRPS は実際の標本から計算した。DDM は C0s の 3 seed(各 1,000 点)を seed ごとに評価して平均した。
  - B-1 の当てはめは推定期間の全原点(各ホライズン)。推定期間での評価は標本内であり、独立な評価ではない。
  - C の当てはめ・比較条件: 各変数でバケット×3 区分(計 60 セル)の経験分布を推定期間で作る。**評価では、推定のセルが 100 件未満、または評価期間のセルが 100 件未満の原点を、条件づけ・E1a の両方で除外した**(計画 §4C)。除外率は表 C に併記。
  - D は A と B を P3 の保存済み C2(60)、C3 に再適用した(C は未実施)。
- 週ブロック bootstrap の区間は、アンサンブルの標本誤差を含まない記述的な区間(B=2,000)。

## 7. 限界

- 原点が連続して窓が重なるため、実質的な標本数は週数(検証・final で 53 週)に近い。区間は記述的で、アンサンブルの標本誤差を含まない。
- 経験分布ベースラインは DDM の性能上限ではなく、同じ ATR 情報による別の予測分布である。推定期間の標本内結果は独立な評価ではない。
- C は 3 変数、1 つずつ、60 セルでの評価で、評価原点の大半が除外された。追加情報の余地を否定しない。
- 検証期間の高 ATR 群は原点が少ない(h1 で 272、週数 48)。記述のみとした。
- final 期間は F1 の判定に使われた期間で、部分的に既知。P4 では final の結果で手法・基準を変更していない。
- 同一の期間・入力マッピングでの結果で、他の期間・市場への一般化は示さない。DDM は C0s の 3 seed(各 1,000 点)。
