## 4. 読み方

- **言えること:** この 50 か月、この定義と警報率では、S を足しても検出率は 5 ポイント以上は増えなかった(区間の上端は 4.0 ポイント)。
- **上乗せがゼロという意味ではない。** 点推定は +0.9 ポイント(801 イベント中 7 件)で、区間は +4.0 ポイントまでを含む。基準の検出率 13.1% に対する +4 ポイントは相対で約 3 割になる。δ_A = 0.05 は、基準の検出率に比べて大きい値だった(事前に固定した値で、変えない)。
- 年ごとの Δ はすべて小さい正の値だが、区間は計算しておらず、判定に使わない。
- 警報率 0.02 では Δ − Δc の下端が 0 を超えるが、Δ 自体はほぼ 0 である。複数の感度の 1 つで、多重性は調整していない。上乗せの根拠にしない。
- どの方式もイベントの大部分を検出できていない(主比較で約 86〜88% を見逃す)。

## 5. 事前の見込みの誤り

- 計画 §4 の見込みは 125〜279 イベントだったが、**実際は 801** で、範囲を大きく超えた。見込みは 2016〜2021 年の年ごとの発生率(30〜226)を前提にしており、この期間には当てはまらなかった。
- 固定の絶対閾値なので、陽性の原点は 8.3%(推定期間は 5%)で、区間により 3.1〜12.2% と大きく違う。「急変動」は、年によっては閾値を決めた期間よりかなり頻繁な出来事になっている。
