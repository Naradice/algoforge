## 1. 要約

1. **V0(代理量の妥当性)は不合格。** `VRproxy(60)` は、DDM の 32 観測すべてで 0 以下(−1.74〜−0.15)であり、実測の `VR_win(60)`(0.03〜0.55)と大きさが合わない。順位相関は 0.94 と高い(単調な関係はあるが、大きさは再現しない)。実現値側の 4 バケットは 25% 以内(e = 0.03〜0.18)。**計画の規則に従い、`VRproxy` に基づく領域分類・点数集計・順位・比較(A3・B3・CF1 の `VRproxy` 列)は実施・報告しない。時間集約についての主張は、`acf_1`・`acf_5` の個別値の記述に限る。**
2. **問 1(A3): 全 20 バケットで、std 帯(実現値の窓間変動 ±1 SD、または ±25%)と `acf_1` 帯を同時に満たすアトラスの点は 0 個。** `acf_1` 帯だけを満たす点は各バケットに 16〜23 個あるが、std が合わない。std ±25% の点が 1 個以上あるのはバケット 6 以上で、0 個のバケットは 0〜5。
3. **問 2(B3): 現行の選択規則の 30 点の短リストに、`acf_1` 帯の点は全 20 バケットで 0 個。** 短リスト内の `|Δacf_1|` の最小は 0.17〜0.24 で、全有効点の最小(0.000〜0.007)とは大きく違う。選択された 8 点の `acf_1` は実現値より平均 0.24〜0.35 低い。CF1(`acf_1` 優先の診断)では、選ばれる 8 点の std 比の中央値(アトラス/実現)が 3.4〜11.4 になり、現行の 8 点との重なりは全バケットで 0。
4. **問 3(C3): 尖度が高い点ほど seed 間のばらつきが大きく、アンサンブルの分散がアトラス由来の値を上回る。** 有効 170 点のうち尖度 8 超が 79 点で、`std_std/std` の中央値は 0.53(尖度 4.5 以下の 82 点では 0.05)。32 観測のうち尖度 8 超の 7 観測では、`log(V_ens/σ²_atlas)` の中央値が 1.73、他の 25 観測では 0.05。アトラスの seed 間 SD は、同じ種類の量である保存経路の経路間 SD(1,000 本の窓の std)の 0.09〜0.75 倍(中央値 0.37)。

候補空間の不足(`acf_1` が合う点の std が合わない)と、選択規則が選ばなかったことは区別できる: アトラスには `acf_1` の合う点があるが std が合わず、std で絞る現行の短リストには `acf_1` 帯の点がなく、`acf_1` で絞る CF1 では std が大きく外れる(両立する点がない)。**したがって、現行の選択の `acf_1` の不一致は、この 170 点の候補空間の中では、規則の選び方より、候補空間そのものに std と `acf_1` を同時に満たす点がないことと整合的である**(原因の確定ではない。アトラスの範囲外に両立する点があるかは、本段階では調べていない)。

## 3. V0: 代理量の検証

比較単位は 32 個の `(bucket, delta, wma)` 観測(独立標本ではない)。重複した `(delta, wma)` は 13 観測(異なる候補は 19)。基準(32 観測中 28 観測以上が 25% 以内、順位相関 0.90 以上、偏りの中央値 ±0.10、DDM の 4 バケット、実現値の 4 バケットがすべて 25% 以内)は事前に固定したとおり適用した。**32 観測すべてで代理量が 0 以下のため `e = log(VRproxy/VR_win)` は未定義であり、範囲外として数えた。**順位相関(0.94。重複除去後 0.98)と実現値側の 4 バケット(範囲内)は基準を満たすが、全体は不合格。補足(C0s、参考のみ): 同様に 32 観測すべてで代理量が 0 以下、順位相関 0.96。

副次指標(経路ごとの代理量と実測値の対数比の中央値、合否には使わない)は、代理量が 0 以下のため**対数が未定義であり、32 観測すべて(C3・C0s とも)で値なし**(`analysis3.json` の `median_per_path_log_ratio` は null)。

解釈上の注意: 代理量の不一致の原因(ラグ 1・5・20 の線形補間とラグ 21 以降を 0 とする仮定が DDM の自己相関の形に合わない可能性)は、本段階では調べていない(追加の分析は計画の範囲外)。DDM の自己相関は第 2 段階で測定済み(ラグ 1 が −0.25〜−0.29)であり、実現値側で代理量が妥当に見えることは、DDM 側での妥当性を意味しない。

## 4. 結果の解釈と限界

- A3 の帯は「実現値の窓間変動に対する帯」(300 窓、重なりあり、ddof = 1)であり、信頼区間・被覆確率ではない。std ±25% は相対誤差の基準を併記したもの。
- A3・B3 の点数は、アトラスの 170 点(delta と wma の格子の有効点)に対する数であり、アトラスの外の領域は含まない。**アトラスが覆っていないこと**(帯の中に点がない)と、**選択規則が選ばなかったこと**(帯の中に点があるが 8 点に入らない)は区別して読む。本結果では、std 帯と `acf_1` 帯を同時に満たす点がそもそもない。
- CF1 は、`acf_1` 優先の代替選択規則の診断であり、採用候補ではない。規則の変更は推奨しない。
- C3 の seed 間 SD はアトラスの 5 seed の `np.nanstd`(ddof = 0)で、seed 間 SD 自体が不安定。経路間 SD は 1 候補約 125 経路の SD(ddof = 1)。構成(300 エージェント、衝撃なし)は同じだが、取引数・窓の定義は完全には同一でない。比と相関は記述であり、予測式・因果の主張ではない。
- 32 観測は 4 バケット・seed 1 に限られる。バケット 17・18 は含まれない。C0s の結果は補助で、C3 と混合していない。
- 位置ブロック別 std(収益 1〜100、101〜200、201〜1,000 本)の最大/最小比は、尖度 8 超の候補で 1.10〜1.23、他の候補では 1.00〜1.11(1 観測を除き 1.08 以下)。
